# Контекст

На прошлой лекции появился язык кванторов, и стало видно, что почти любое математическое утверждение имеет вид $\forall s\, P(s)$ (раздел [-@sec:lec02:arguments]). Если объектов $s$ бесконечно много, проверить $P(s)$ для каждого по отдельности нельзя, а «произвольный объект», о котором ничего не известно, часто ничего и не даёт доказать. В этой лекции на одном примере — строках, базовом типе данных программирования — показано, как это преодолевают: объект определяют тем, *как он строится*, и тогда утверждения обо всех объектах доказываются индукцией по построению, а функции задаются рекурсией. Принцип индукции для натуральных чисел, который будет в лекции 5, — частный случай того же приёма.

# После прочтения ты сможешь

- записать строку через конструкторы $[\,]$ и $:$ и по рекурсивному определению вычислить $\mathrm{lh}$, $\mathrm{app}$, $\mathrm{rev}$ на конкретной строке шаг за шагом;
- доказать равенство или неравенство конкретных строк с помощью аксиом (A1) и (A2);
- доказать утверждение обо всех строках индукцией: выписать предикат $P(s)$, базу, переход и указать, где использовано предположение индукции;
- выбрать переменную индукции в утверждении с несколькими строками — по аргументу, по которому идёт рекурсия;
- дать рекурсивное определение новой функции на строках и доказать её свойство;
- доказать утверждение без индукции — разбором случаев «строка пуста / непуста» или сведением к уже доказанным леммам;
- опровергнуть общее утверждение о строках контрпримером и найти ошибку в неверном «доказательстве» по индукции.

# Теория

## Что такое строка {#sec:lec03:strings}

Интуитивно *строка* (список, слово; string) — это конечная последовательность символов произвольной природы: $[x, y, x]$, $[4, 12, 2, 3]$, $[\text{Сократ}, \text{Платон}, \text{Аристотель}]$. Квадратные скобки и запятые отделяют символы друг от друга: если ясно, что $x$ и $y$ — отдельные символы, первую строку можно записать и как $xyx$. Строки рассматриваются над произвольным, но фиксированным набором символов $A$, который называется *алфавитом* (alphabet). Например, $[4, 12, 2, 3]$ — строка над алфавитом $\N = \{0, 1, 2, \dots\}$ (в курсе $0 \in \N$, замечание [-@rem:lec01:nat]). Алфавитом может быть и набор строк над другим алфавитом. Особо выделяется вырожденный объект — *пустая строка* $[\,]$, не содержащая ни одного символа.

Для человека этого описания достаточно. Но попробуем доказать с его помощью хоть что-нибудь, например, что строка, перевёрнутая дважды, совпадает с исходной. Что такое «конечная последовательность», что значит «перевернуть», почему утверждение верно для *всех* строк, если их бесконечно много? Если писать программу «с нуля», без готового типа «массив», возникают те же вопросы. Ответ — заменить вопрос «что такое строка» вопросом «как строку построить».

## Индуктивное определение {#sec:lec03:inductive}

Каждая строка либо пуста, либо получается из более короткой строки $s'$ добавлением символа $x$ слева. Это записывают как $x : s'$. Например,
$$[4, 12, 2] = 4 : [12, 2] = 4 : (12 : [2]) = 4 : (12 : (2 : [\,])).$$
Забудем про «последовательности» и сделаем это наблюдение определением.

::: {.definition #def:lec03:string title="строка над алфавитом"}
Множество $S(A)$ *строк над алфавитом* $A$ задаётся правилами построения:

1. $[\,] \in S(A)$ — пустая строка является строкой;
2. если $s \in S(A)$ и $x \in A$, то $x : s \in S(A)$; символ $x$ называется *головой* (head) строки $x : s$, а строка $s$ — её *хвостом* (tail).

Других строк нет: каждая строка получена из $[\,]$ конечным числом применений правила 2. Символически: $[\,] \in S(A)$ и $\forall s\, \forall x\, \bigl((s \in S(A) \wedge x \in A) \to x : s \in S(A)\bigr)$.
:::

Знаки $[\,]$ и $:$ ничем не определяются: это исходные «кирпичи», в программировании их называют *конструкторами* (constructors) типа данных «строка». Определения такого вида — «через построение» — называются *индуктивными* (inductive definition). Привычная запись возвращается сокращением
$$[x_1, x_2, \dots, x_n] := x_1 : (x_2 : (\dots : (x_n : [\,]) \dots)).$$
Скобки в правой части можно опускать, восстанавливая их справа налево: $x_1 : x_2 : [\,]$ означает $x_1 : (x_2 : [\,])$. Строение строки удобно изображать деревом (рис. [-@fig:lec03:tree]).

::: {.remark #rem:lec03:why-finite title="зачем «других строк нет»"}
Оба правила нужны. Без правила 1 строить не из чего: правило 2 требует уже готовую строку, и множество строк оказалось бы пустым. Фраза «других строк нет» запрещает «бесконечные» объекты. В языке Haskell, например, можно написать `ones = 1 : ones` и получить бесконечный список единиц $\omega$ с $\omega = 1 : \omega$: у него есть голова и хвост, но построить его из $[\,]$ за конечное число шагов нельзя. Длина такого объекта должна была бы удовлетворять равенству $\ell = 1 + \ell$, которое не выполняется ни для какого натурального $\ell$. Наши строки — только конечные. Как это требование записать аксиомой, показано ниже, в разделе [-@sec:lec03:induction].
:::

::: {.remark #rem:lec03:corner tag="корнер-кейс"}
Если алфавит пуст, правило 2 неприменимо, и $S(\varnothing)$ состоит из одной строки $[\,]$. Если алфавит сам состоит из строк, символом может быть и пустая строка: $[[\,]] = [\,] : [\,]$ — строка длины $1$ над алфавитом $S(A)$, её единственный символ — $[\,]$. Строки $[\,]$ и $[[\,]]$ различны: первая пуста, у второй есть голова. Такое же различие между «ничем» и «коробкой, в которой лежит ничто» встретится в следующей лекции у множеств.
:::

## Аксиомы равенства строк {#sec:lec03:axioms}

Чтобы что-то доказывать о строках, нужно знать, когда две строки равны. Примем два свойства, которые интуитивно бесспорны.

::: {.axiom #ax:lec03:a1a2 title="аксиомы (A1) и (A2)"}
Для всех $x, y \in A$ и $s, t \in S(A)$:

- (A1) $[\,] \ne x : s$ — пустая строка отлична от любой непустой;
- (A2) $x : s = y : t \iff (x = y \wedge s = t)$ — строки, построенные конструктором $:$, равны тогда и только тогда, когда равны их головы и равны их хвосты.
:::

Направление «$\Leftarrow$» в (A2) — общее свойство равенства: из одинаковых частей одним способом получается одно и то же. Содержательно направление «$\Rightarrow$»: по строке однозначно восстанавливаются голова и хвост. Обе аксиомы нельзя выбросить. Если «строкой» считать только её длину ($[\,] := 0$, $x : s := 1 + s$), то (A1) выполнена ($1 + s \ne 0$), а (A2) нет: $[1] = 1 = [2]$, хотя $1 \ne 2$. Если все строки считать одним и тем же объектом, нарушится (A1), и окажется $[1, 2] = [1, 2, 3]$.

::: {.example #ex:lec03:neq}
Докажите, что $[1, 2] \ne [1, 2, 3]$ (алфавит $\N$).

*Ответ:* следует из (A2), применённой дважды, и (A1).

*Решение.* Рассуждаем от противного: предположим, что $[1, 2] = [1, 2, 3]$, то есть $1 : [2] = 1 : [2, 3]$. По (A2) хвосты равны: $2 : [\,] = [2] = [2, 3] = 2 : [3]$. Ещё раз по (A2): $[\,] = [3] = 3 : [\,]$. Но по (A1) $[\,] \ne 3 : [\,]$. Утверждение $[\,] = 3 : [\,]$ оказалось и истинным, и ложным, а так не бывает. Значит, предположение неверно и $[1, 2] \ne [1, 2, 3]$.
:::

Такой приём называется *доказательством от противного*: предполагаем отрицание того, что нужно доказать, и выводим противоречие — утверждение вместе с его отрицанием (ср. со схемой доказательства несуществования, замечание [-@rem:lec02:nonexistence]). Педантичный читатель заметит, что кроме (A1) и (A2) использованы свойства равенства (если $u = v$ и $v = w$, то $u = w$) и сама логика: $P$ и $\neg P$ не могут быть истинны одновременно. В задачах про алфавит $\N$ используются и известные свойства чисел, например $0 \ne 1$.

## Принцип индукции {#sec:lec03:induction}

Аксиомы (A1), (A2) позволяют сравнивать конкретные строки, но о *всех* строках с ними ничего интересного не докажешь. Нужен ещё один принцип, и одного оказывается достаточно.

Пусть $P(s)$ — унарный предикат с предметной областью $S(A)$, то есть свойство строк, и мы хотим доказать $\forall s\, P(s)$. Возьмём произвольную строку $t$. По определению [-@def:lec03:string] она либо равна $[\,]$, либо имеет вид $x : t'$. Ясно, что для $\forall s\, P(s)$ необходимо $P([\,])$. Если $t = x : t'$, то $t'$ — снова «произвольная» строка, она либо пуста, либо равна $x' : t''$, и так далее; через конечное число шагов дойдём до $[\,]$. Отсюда идея: если $P([\,])$ верно и свойство $P$ сохраняется при каждом шаге построения, то оно верно для каждой строки.

::: {.axiom #ax:lec03:induction title="принцип индукции для строк (ПИ)"}
Для каждого унарного предиката $P$ на $S(A)$:
$$\Bigl(P([\,]) \wedge \forall s\, \forall x\, \bigl(P(s) \to P(x : s)\bigr)\Bigr) \to \forall s\, P(s).$$
:::

Утверждение $P([\,])$ называется *базой индукции* (base case), утверждение $\forall s\, \forall x\, (P(s) \to P(x : s))$ — *индукционным переходом* или *шагом индукции* (inductive step). Посылка $P(s)$, когда из неё выводят $P(x : s)$, называется *предположением индукции* (inductive hypothesis). Доказательство по (ПИ) называют *индукцией по построению* или индукцией по $s$.

Принцип индукции не выводится из (A1), (A2), его приходится принимать как аксиому. Убедиться в его правдоподобии помогает следующий пример.

::: {.example #ex:lec03:unfold}
Пусть $A = \N$ и выполнены база $P([\,])$ (посылка 1) и переход $\forall s\, \forall x\, (P(s) \to P(x : s))$ (посылка 2). Тогда $P([1, 2, 3])$ можно вывести и без (ПИ):

| | Утверждение | Почему |
|:-:|:--------------|:--------|
| $1$ | $P([\,])$ | посылка 1 |
| $2$ | $P([\,]) \to P(3 : [\,])$ | посылка 2 при $s = [\,]$, $x = 3$ |
| $3$ | $P(3 : [\,])$ | из $1$ и $2$ |
| $4$ | $P(3 : [\,]) \to P(2 : (3 : [\,]))$ | посылка 2 при $s = [3]$, $x = 2$ |
| $5$ | $P(2 : (3 : [\,]))$ | из $3$ и $4$ |
| $6$ | $P(2 : (3 : [\,])) \to P(1 : (2 : (3 : [\,])))$ | посылка 2 при $s = [2, 3]$, $x = 1$ |
| $7$ | $P(1 : (2 : (3 : [\,])))$ | из $5$ и $6$ |

Строка $[1, 2, 3]$ ничем не особенна: так можно получить $P(s)$ для любой конкретной строки $s$, только вывод удлиняется вместе с $s$. Принцип индукции «упаковывает» бесконечно много таких выводов неограниченной длины в одно доказательство.
:::

::: {.remark #rem:lec03:ip-axiom title="почему (ПИ) — отдельная аксиома"}
Возьмём алфавит $A = \{1\}$ и к обычным конечным строкам добавим один лишний объект $\omega$, положив $1 : \omega := \omega$ (бесконечный список из замечания [-@rem:lec03:why-finite]). Аксиомы выполнены: $1 : s \ne [\,]$ для всех $s$, в том числе для $\omega$, и из $1 : s = 1 : t$ следует $s = t$. Предикат $P(s)$: «$1 : s \ne s$» удовлетворяет базе ($1 : [\,] \ne [\,]$ по (A1)) и переходу (если $1 : (1 : s) = 1 : s$, то по (A2) $1 : s = s$; по контрапозиции из $P(s)$ следует $P(1 : s)$). Но $P(\omega)$ ложно. Значит, (ПИ) в этом мире не выполнен, хотя (A1) и (A2) выполнены. Принцип индукции и есть формальная запись фразы «других строк нет».
:::

Сначала — метод целиком на простом утверждении, которое заодно формально исключает объекты вида $\omega$.

::: {.proposition #prop:lec03:cons-neq title="строка не равна своему хвосту"}
Для всех $s \in S(A)$ и $y \in A$ выполнено $y : s \ne s$.
:::

Инстанция: $1 : [1, 2] = [1, 1, 2] \ne [1, 2]$ — это видно и без индукции, по (A2) и (A1), как в примере [-@ex:lec03:neq]. Индукция нужна, чтобы получить неравенство сразу для всех строк.

::: proof
Индукция по $s$ для предиката $P(s)$: «$\forall y\, (y : s \ne s)$».

*База:* $P([\,])$, то есть $y : [\,] \ne [\,]$ для каждого $y$, — это (A1).

*Переход.* Возьмём произвольные $s$ и $x$ и предположим $P(s)$: $y : s \ne s$ для всех $y$. Докажем $P(x : s)$: $y : (x : s) \ne x : s$ для всех $y$. Пусть, напротив, $y : (x : s) = x : s$ для некоторого $y$. По (A2) $y = x$ и $x : s = s$. Но предположение индукции при $y := x$ даёт $x : s \ne s$ — противоречие.

По (ПИ) $P(s)$ верно для всех $s$.
:::

Заметим, что в $P(s)$ стоит квантор $\forall y$. Если бы $P(s)$ говорил только про фиксированный символ $y_0$, предположение индукции дало бы $y_0 : s \ne s$, а в переходе нужно $x : s \ne s$ для головы $x$ новой строки. Предикат индукции должен быть достаточно общим, чтобы предположение индукции подошло там, где его применяют.

::: {.remark #rem:lec03:circle tag="частое заблуждение"}
«*Индукция — порочный круг: в переходе мы предполагаем $P(s)$, то есть как раз то, что нужно доказать.*» Нет. В переходе доказывается *импликация* $P(s) \to P(x : s)$ для произвольных $s$ и $x$, а не $P(s)$. Импликация может быть истинна, даже когда посылка ложна, так что, доказав её, мы ещё ничего не утверждаем о самом $P(s)$. Вывод $\forall s\, P(s)$ делает принцип индукции, а не переход. Порочным кругом было бы предположить $\forall s\, P(s)$ — «утверждение верно для всех строк» — и вывести из этого $P(x : s)$: так «доказывается» что угодно.
:::

## Рекурсивные функции {#sec:lec03:recursion}

Принцип доказательства есть, нужны утверждения, к которым его применять. В программировании над строками определяют множество функций, и доказывать их свойства — естественная задача. Функции, как и доказательства, удобно задавать по индуктивному определению строк. Начнём с длины: хотим $\mathrm{lh}([\,]) = 0$, $\mathrm{lh}([8]) = 1$, $\mathrm{lh}([3, 11]) = 2$ и так далее.

::: {.definition #def:lec03:lh title="длина строки"}
*Длина* $\mathrm{lh}\colon S(A) \to \N$ задаётся правилами
$$\mathrm{lh}([\,]) = 0, \qquad \mathrm{lh}(x : s) = 1 + \mathrm{lh}(s) \quad \text{для всех } x, s.$$
:::

Мы принимаем без доказательства, что функция с такими двумя свойствами существует и единственна. Говорят, что $\mathrm{lh}$ *определена рекурсией* по строкам (defined by recursion): чтобы получить $\mathrm{lh}(x : s)$, мы «возвращаемся» к предыдущему значению $\mathrm{lh}(s)$. В семинарских листках та же функция обозначается $\mathrm{len}$.

::: {.remark #rem:lec03:well-defined title="почему рекурсия задаёт функцию"}
Правило $\mathrm{lh}(x : s) = 1 + \mathrm{lh}(s)$ применимо однозначно, потому что по (A2) непустая строка однозначно разбирается на голову и хвост, а по (A1) пустая строка не попадает под второе правило. Если бы строки были «мешками» символов и $[1, 2] = [2, 1]$, то «функция» $\mathrm{first}(x : s) = x$ давала бы на одной строке два значения: $1 = \mathrm{first}([1, 2]) = \mathrm{first}([2, 1]) = 2$.
:::

::: {.example #ex:lec03:lh}
Определение вычислительно эффективно — это рецепт подсчёта:
$$\mathrm{lh}([3, 11]) = \mathrm{lh}(3 : (11 : [\,])) = 1 + \mathrm{lh}(11 : [\,]) = 1 + (1 + \mathrm{lh}([\,])) = 1 + (1 + 0) = 2.$$
:::

Вторая функция — *конкатенация* (append, concatenate), «склейка» двух строк. Хотим, например, $\mathrm{app}([1, 3, 2], [3, 2]) = [1, 3, 2, 3, 2]$ и $\mathrm{app}([5, 8], [\,]) = [5, 8]$, $\mathrm{app}([\,], [5, 8]) = [5, 8]$.

::: {.definition #def:lec03:app title="конкатенация"}
$$\mathrm{app}([\,], t) = t, \qquad \mathrm{app}(x : s, t) = x : \mathrm{app}(s, t) \quad \text{для всех } x, s, t.$$
:::

Рекурсия здесь идёт по *первому* аргументу: функция идёт вдоль строки $s$ и копирует её символы, а когда $s$ кончается, подставляет $t$ целиком (рис. [-@fig:lec03:app]).

::: {.example #ex:lec03:app}
Вычислите $\mathrm{app}([1, 2], [3])$.

*Ответ:* $[1, 2, 3]$.

*Решение.* Применяем второе правило, пока первый аргумент не станет пустым, затем первое:
$$\mathrm{app}(1 : (2 : [\,]), [3]) = 1 : \mathrm{app}(2 : [\,], [3]) = 1 : (2 : \mathrm{app}([\,], [3])) = 1 : (2 : [3]) = [1, 2, 3].$$
Последнее равенство — сокращённая запись: $[3] = 3 : [\,]$, поэтому $1 : (2 : (3 : [\,])) = [1, 2, 3]$.
:::

## Свойства конкатенации {#sec:lec03:app-props}

По определению $\mathrm{app}([\,], s) = s$. А что можно сказать про $\mathrm{app}(s, [\,])$? Для конкретной строки: $\mathrm{app}([1, 2], [\,]) = 1 : \mathrm{app}([2], [\,]) = 1 : (2 : \mathrm{app}([\,], [\,])) = 1 : (2 : [\,]) = [1, 2]$. В общем случае нужна индукция.

::: {.lemma #lem:lec03:app-nil title="правая единица"}
Для каждой строки $s$ выполнено $\mathrm{app}(s, [\,]) = s$.
:::

::: proof
Индукция по $s$; $P(s)$ — равенство $\mathrm{app}(s, [\,]) = s$. Нужно доказать $P([\,])$ и $\forall s\, \forall x\, (P(s) \to P(x : s))$.

*База:* $\mathrm{app}([\,], [\,]) = [\,]$ по первому правилу определения $\mathrm{app}$.

*Переход.* Возьмём произвольные $s$, $x$ и предположим $\mathrm{app}(s, [\,]) = s$ (если посылка ложна, импликация истинна и доказывать нечего). По определению $\mathrm{app}(x : s, [\,]) = x : \mathrm{app}(s, [\,])$, а по предположению индукции это $x : s$. Так как $s$ и $x$ произвольны, переход доказан, и по (ПИ) $\forall s\, P(s)$.
:::

Равенство $\mathrm{app}([\,], t) = t$ — определение, а $\mathrm{app}(s, [\,]) = s$ — теорема с индукцией: несимметрия возникает потому, что рекурсия идёт по первому аргументу. Пустая строка играет для $\mathrm{app}$ ту же роль, что $0$ для сложения: $n + 0 = n = 0 + n$. Насколько далеко идёт аналогия? Сложение ассоциативно: $n + (m + l) = (n + m) + l$.

::: {.lemma #lem:lec03:app-assoc title="ассоциативность конкатенации"}
Для всех $s, t, r \in S(A)$ выполнено $\mathrm{app}(s, \mathrm{app}(t, r)) = \mathrm{app}(\mathrm{app}(s, t), r)$.
:::

Инстанция: при $s = [1]$, $t = [2]$, $r = [3]$ обе части равны $[1, 2, 3]$: слева $\mathrm{app}([1], [2, 3])$, справа $\mathrm{app}([1, 2], [3])$.

::: proof
*Идея:* (ПИ) говорит об унарных предикатах, а в равенстве три строки. Две из них фиксируем, индукцию ведём по третьей — по $s$, потому что именно по первому аргументу раскрывается $\mathrm{app}$ в обеих частях.

Фиксируем произвольные $t$, $r$; $P(s)$ — равенство $\mathrm{app}(s, \mathrm{app}(t, r)) = \mathrm{app}(\mathrm{app}(s, t), r)$.

*База:* обе части $P([\,])$ равны $\mathrm{app}(t, r)$ по определению: $\mathrm{app}([\,], \mathrm{app}(t, r)) = \mathrm{app}(t, r)$ и $\mathrm{app}(\mathrm{app}([\,], t), r) = \mathrm{app}(t, r)$.

*Переход.* Пусть $P(s)$ верно для произвольных $s$, $x$. Тогда
$$\begin{aligned}
\mathrm{app}(x : s, \mathrm{app}(t, r)) &= x : \mathrm{app}(s, \mathrm{app}(t, r)) && \text{определение } \mathrm{app}\\
&= x : \mathrm{app}(\mathrm{app}(s, t), r) && \text{предположение индукции}\\
&= \mathrm{app}(x : \mathrm{app}(s, t), r) && \text{определение } \mathrm{app} \text{ справа налево}\\
&= \mathrm{app}(\mathrm{app}(x : s, t), r) && \text{определение } \mathrm{app}.
\end{aligned}$$
По (ПИ) $P(s)$ верно для всех $s$; так как $t$, $r$ произвольны, лемма доказана.
:::

::: {.remark #rem:lec03:which-var tag="подводный камень"}
Выбор переменной индукции решает всё. Попробуем доказать ассоциативность индукцией по $t$. База $\mathrm{app}(s, \mathrm{app}([\,], r)) = \mathrm{app}(s, r) = \mathrm{app}(\mathrm{app}(s, [\,]), r)$ проходит (с леммой [-@lem:lec03:app-nil]). В переходе слева получаем $\mathrm{app}(s, \mathrm{app}(x : t, r)) = \mathrm{app}(s, x : \mathrm{app}(t, r))$, и дальше хода нет: для $\mathrm{app}(s, x : u)$ с неизвестной строкой $s$ правила нет, ведь рекурсия раскрывает только первый аргумент. То же с индукцией по $r$. Общее правило: *индукцию ведут по тому аргументу, по которому идёт рекурсия в определениях участвующих функций*.
:::

Сложение коммутативно: $n + m = m + n$. Для конкатенации аналогия ломается.

::: {.example #ex:lec03:noncomm}
Неверно, что $\mathrm{app}(s, t) = \mathrm{app}(t, s)$ для всех $s$, $t$.

*Решение.* Отрицание утверждения с $\forall$ — утверждение с $\exists$ (утверждение [-@prop:lec02:quant-neg]), поэтому достаточно одного контрпримера, и индукция не нужна. Над $\N$: $\mathrm{app}([1], [2]) = 1 : \mathrm{app}([\,], [2]) = [1, 2]$ и $\mathrm{app}([2], [1]) = [2, 1]$. Если бы $[1, 2] = [2, 1]$, то по (A2) было бы $1 = 2$. Значит, $\mathrm{app}([1], [2]) \ne \mathrm{app}([2], [1])$.
:::

Отдельные пары строк всё же перестановочны: $s$ и $[\,]$ (по лемме [-@lem:lec03:app-nil]), $s$ и $s$, а также, например, $[1]$ и $[1, 1]$ — обе склейки равны $[1, 1, 1]$. Опровергнуть нужно было именно «для всех».

Операции $\mathrm{app}$ на строках и $+$ на числах не просто похожи — их связывает длина.

::: {.proposition #prop:lec03:lh-app title="длина конкатенации"}
$\mathrm{lh}([\,]) = 0$ и $\mathrm{lh}(\mathrm{app}(s, t)) = \mathrm{lh}(s) + \mathrm{lh}(t)$ для всех $s, t \in S(A)$.
:::

Пример: $\mathrm{lh}(\mathrm{app}([1, 3, 2], [3, 2])) = \mathrm{lh}([1, 3, 2, 3, 2]) = 5 = 3 + 2$. Функции, которые так переводят одну операцию в другую ($\mathrm{app}$ в $+$, $[\,]$ в $0$), в математике называются *гомоморфизмами*.

::: proof
Первое равенство — определение $\mathrm{lh}$. Второе — индукция по $s$ при фиксированном $t$. *База:* $\mathrm{lh}(\mathrm{app}([\,], t)) = \mathrm{lh}(t) = 0 + \mathrm{lh}(t) = \mathrm{lh}([\,]) + \mathrm{lh}(t)$. *Переход:* если $\mathrm{lh}(\mathrm{app}(s, t)) = \mathrm{lh}(s) + \mathrm{lh}(t)$, то
$$\mathrm{lh}(\mathrm{app}(x : s, t)) = \mathrm{lh}(x : \mathrm{app}(s, t)) = 1 + \mathrm{lh}(\mathrm{app}(s, t)) = 1 + (\mathrm{lh}(s) + \mathrm{lh}(t)) = \mathrm{lh}(x : s) + \mathrm{lh}(t),$$
где в последнем шаге использованы ассоциативность сложения чисел и определение $\mathrm{lh}$.
:::

Для чисел из $n + m = n + l$ следует $m = l$. Для строк верен аналог.

::: {.lemma #lem:lec03:cancel-left title="сокращение слева"}
Для всех $s, t, r \in S(A)$: если $\mathrm{app}(s, t) = \mathrm{app}(s, r)$, то $t = r$.
:::

Пример: из $\mathrm{app}([1, 2], t) = [1, 2, 3]$ следует $t = [3]$, ведь $\mathrm{app}([1, 2], [3]) = [1, 2, 3]$ (пример [-@ex:lec03:app]).

::: proof
Фиксируем $t$, $r$ и ведём индукцию по $s$ для предиката $P(s)$: «$\mathrm{app}(s, t) = \mathrm{app}(s, r) \to t = r$». *База:* из $\mathrm{app}([\,], t) = \mathrm{app}([\,], r)$ по определению получаем $t = r$. *Переход:* предположим $P(s)$ и пусть $\mathrm{app}(x : s, t) = \mathrm{app}(x : s, r)$. По определению это $x : \mathrm{app}(s, t) = x : \mathrm{app}(s, r)$, откуда по (A2) $\mathrm{app}(s, t) = \mathrm{app}(s, r)$, и по предположению индукции $t = r$.
:::

А вот сокращение справа — из $\mathrm{app}(t, s) = \mathrm{app}(r, s)$ следует $t = r$ — прямой индукцией доказывать неудобно: рекурсия раскрывает $t$ и $r$ по-разному, и приходится разбирать случаи. Ниже оно будет получено обходным путём, через переворот строки (задача [-@prob:lec03:cancel-right]).

Многие простые доказательства опираются на индуктивное определение, но не на индукцию.

::: {.lemma #lem:lec03:app-empty title="пустая конкатенация"}
Для всех $s, t \in S(A)$: если $\mathrm{app}(s, t) = [\,]$, то $s = [\,]$ и $t = [\,]$.
:::

Инстанция: равенство $\mathrm{app}(s, [2]) = [\,]$ невозможно ни при какой строке $s$ — вторая строка непуста. Длина подсказывает то же (утверждение [-@prop:lec03:lh-app]), но доказательство ниже обходится без неё.

::: proof
По определению [-@def:lec03:string] каждая строка либо равна $[\,]$, либо имеет вид $x : r$. Разберём оба случая для $s$ (такой приём называется *доказательством разбором случаев*, proof by cases).

Если $s = [\,]$, то $[\,] = \mathrm{app}([\,], t) = t$, то есть и $t = [\,]$.

Если $s = x : r$, то $[\,] = \mathrm{app}(x : r, t) = x : \mathrm{app}(r, t)$, что запрещено (A1). Этот случай невозможен: мы получили противоречие, а из ложного утверждения следует что угодно (импликация с ложной посылкой истинна), в частности $s = [\,]$ и $t = [\,]$.

В каждом возможном случае $s = t = [\,]$, значит, это верно всегда.
:::

::: {.remark #rem:lec03:cases-vs-ind}
Разбор случаев «$s = [\,]$ или $s = x : r$» — это индукция без предположения индукции: в случае $x : r$ ничего не известно про $r$. Если для этого случая ничего про $r$ и не нужно, как в лемме [-@lem:lec03:app-empty], индукция избыточна. Если же нужно знать что-то про хвост, как в лемме [-@lem:lec03:app-nil], разбора случаев не хватает.
:::

## Переворот строки {#sec:lec03:rev}

Ещё одна полезная функция — *переворот* (reverse): $\mathrm{rev}([1, 2, 3]) = [3, 2, 1]$.

::: {.definition #def:lec03:rev title="переворот строки"}
$$\mathrm{rev}([\,]) = [\,], \qquad \mathrm{rev}(x : s) = \mathrm{app}(\mathrm{rev}(s), [x]) \quad \text{для всех } x, s.$$
:::

Голова $x$ уходит в конец: сначала переворачиваем хвост, затем приписываем к нему справа строку из одного символа $[x]$. Наивное правило $\mathrm{rev}(x : s) = x : \mathrm{rev}(s)$ не годится: индукцией по $s$ из него получается $\mathrm{rev}(s) = s$ для всех $s$, то есть функция ничего не переворачивает. Приписывать символ справа можно только через $\mathrm{app}$ — отдельного конструктора «добавить в конец» нет. Проверим на примере: $\mathrm{rev}([3]) = \mathrm{app}(\mathrm{rev}([\,]), [3]) = \mathrm{app}([\,], [3]) = [3]$, затем $\mathrm{rev}([2, 3]) = \mathrm{app}([3], [2]) = 3 : \mathrm{app}([\,], [2]) = [3, 2]$ и
$$\mathrm{rev}([1, 2, 3]) = \mathrm{app}(\mathrm{rev}([2, 3]), [1]) = \mathrm{app}([3, 2], [1]) = 3 : (2 : \mathrm{app}([\,], [1])) = [3, 2, 1].$$

Переворот относится к конкатенации так же, как транспонирование к умножению матриц в курсе алгебры, $(AB)^T = B^T A^T$, или обращение к умножению чисел: $\frac{1}{pq} = \frac1q \cdot \frac1p$ при $p, q \ne 0$. Например, $\mathrm{rev}(\mathrm{app}([1, 2], [3, 4])) = [4, 3, 2, 1] = \mathrm{app}(\mathrm{rev}([3, 4]), \mathrm{rev}([1, 2]))$: множители меняются местами.

::: {.proposition #prop:lec03:rev-app title="переворот конкатенации"}
Для всех $s, t \in S(A)$ выполнено $\mathrm{rev}(\mathrm{app}(s, t)) = \mathrm{app}(\mathrm{rev}(t), \mathrm{rev}(s))$.
:::

::: proof
*Идея:* индукция по $s$ — первому аргументу $\mathrm{app}$ и аргументу $\mathrm{rev}$, по которым идёт рекурсия; в базе понадобится лемма [-@lem:lec03:app-nil], в переходе — лемма [-@lem:lec03:app-assoc].

Фиксируем $t$. *База:* $\mathrm{rev}(\mathrm{app}([\,], t)) = \mathrm{rev}(t) = \mathrm{app}(\mathrm{rev}(t), [\,]) = \mathrm{app}(\mathrm{rev}(t), \mathrm{rev}([\,]))$; второе равенство — лемма [-@lem:lec03:app-nil], третье — определение $\mathrm{rev}$.

*Переход.* Пусть $\mathrm{rev}(\mathrm{app}(s, t)) = \mathrm{app}(\mathrm{rev}(t), \mathrm{rev}(s))$. Тогда
$$\begin{aligned}
\mathrm{rev}(\mathrm{app}(x : s, t)) &= \mathrm{rev}(x : \mathrm{app}(s, t)) && \text{определение } \mathrm{app}\\
&= \mathrm{app}(\mathrm{rev}(\mathrm{app}(s, t)), [x]) && \text{определение } \mathrm{rev}\\
&= \mathrm{app}(\mathrm{app}(\mathrm{rev}(t), \mathrm{rev}(s)), [x]) && \text{предположение индукции}\\
&= \mathrm{app}(\mathrm{rev}(t), \mathrm{app}(\mathrm{rev}(s), [x])) && \text{ассоциативность } \mathrm{app}\\
&= \mathrm{app}(\mathrm{rev}(t), \mathrm{rev}(x : s)) && \text{определение } \mathrm{rev}.
\end{aligned}$$
Ассоциативность в четвёртом шаге — лемма [-@lem:lec03:app-assoc]. По (ПИ) равенство верно для всех $s$, а $t$ было произвольным.
:::

Для чисел и матриц $(p^{-1})^{-1} = p$ и $(A^T)^T = A$. У строк то же самое.

::: {.corollary #cor:lec03:rev-rev title="двойной переворот"}
Для каждой строки $s$ выполнено $\mathrm{rev}(\mathrm{rev}(s)) = s$.
:::

Инстанция: $\mathrm{rev}(\mathrm{rev}([1, 2, 3])) = \mathrm{rev}([3, 2, 1]) = [1, 2, 3]$.

::: proof
Сначала заметим, что $\mathrm{rev}([x]) = \mathrm{app}(\mathrm{rev}([\,]), [x]) = \mathrm{app}([\,], [x]) = [x]$. Индукция по $s$. *База:* $\mathrm{rev}(\mathrm{rev}([\,])) = \mathrm{rev}([\,]) = [\,]$. *Переход:* если $\mathrm{rev}(\mathrm{rev}(s)) = s$, то
$$\mathrm{rev}(\mathrm{rev}(x : s)) = \mathrm{rev}(\mathrm{app}(\mathrm{rev}(s), [x])) = \mathrm{app}(\mathrm{rev}([x]), \mathrm{rev}(\mathrm{rev}(s))) = \mathrm{app}([x], s) = x : s.$$
Второе равенство — утверждение [-@prop:lec03:rev-app], третье — предположение индукции, четвёртое — определение $\mathrm{app}$: $\mathrm{app}(x : [\,], s) = x : \mathrm{app}([\,], s) = x : s$.
:::

Это и есть утверждение, с которого началась лекция: дважды перевёрнутая строка совпадает с исходной. Доказательство заняло две строки, но опирается на всю цепочку: определение, (ПИ), леммы [-@lem:lec03:app-nil] и [-@lem:lec03:app-assoc], утверждение [-@prop:lec03:rev-app].

::: {.remark #rem:lec03:naturals title="связь с натуральными числами"}
Возьмём алфавит из одного символа $A = \{1\}$. Строки над ним — $[\,]$, $[1]$, $[1, 1]$, … — устроены как натуральные числа: $[\,]$ играет роль $0$, приписывание $1 : s$ — роль перехода от $n$ к $n + 1$, функция $\mathrm{lh}$ взаимно однозначно сопоставляет строке число, а $\mathrm{app}$ переходит в сложение (утверждение [-@prop:lec03:lh-app]). Принцип индукции для таких строк превращается в принцип математической индукции: «если $P(0)$ и из $P(n)$ всегда следует $P(n + 1)$, то $P(n)$ для всех $n \in \N$». Его, а также сильную индукцию и принцип наименьшего числа, изучим в лекции 5; техника «база — переход — где применено предположение индукции» остаётся той же. Индуктивные определения и рекурсия встретятся и дальше: так задаются формулы логики, деревья, многие последовательности.
:::

# Практика

::: {.problem #prob:lec03:eq-neq}
Над алфавитом $\N$ докажите формально, что $[1, 2, 3] \ne [1, 3, 4]$ и $[1 + 2, 1 + 1] = [5 - 2, 2]$ (здесь $1 + 2$ — другое имя символа $3$).
:::

::: answer
Первое — от противного через (A2) и $2 \ne 3$; второе — свойство равенства: равные головы и равные хвосты дают равные строки.
:::

::: solution
*Неравенство.* Пусть $[1, 2, 3] = [1, 3, 4]$, то есть $1 : [2, 3] = 1 : [3, 4]$. По (A2) хвосты равны: $2 : [3] = 3 : [4]$. Ещё раз по (A2) равны головы: $2 = 3$. Но $2 \ne 3$ — противоречие. *Ключ:* в отличие от примера [-@ex:lec03:neq], противоречие даёт не (A1), а неравенство голов; до пустой строки спускаться не нужно.

*Равенство.* Так как $1 + 1 = 2$, по (A2) (направление «$\Leftarrow$», равные головы и хвосты) $(1 + 1) : [\,] = 2 : [\,]$, то есть $[1 + 1] = [2]$. Так как $1 + 2 = 3 = 5 - 2$, ещё раз по (A2): $(1 + 2) : [1 + 1] = (5 - 2) : [2]$, то есть $[1 + 2, 1 + 1] = [5 - 2, 2]$. Индукция здесь не нужна: строки конкретные.
:::

::: {.problem #prob:lec03:app-formal}
Докажите формально, что $\mathrm{app}([1, 3, 2], [3, 2]) = [1, 3, 2, 3, 2]$, указывая, какое правило применяется на каждом шаге.
:::

::: answer
Три применения второго правила, одно — первого, затем раскрытие сокращения $[\dots]$.
:::

::: solution
$$\begin{aligned}
\mathrm{app}(1 : [3, 2], [3, 2]) &= 1 : \mathrm{app}(3 : [2], [3, 2]) && \text{правило 2: } x = 1,\ s = [3, 2],\ t = [3, 2]\\
&= 1 : (3 : \mathrm{app}(2 : [\,], [3, 2])) && \text{правило 2: } x = 3,\ s = [2]\\
&= 1 : (3 : (2 : \mathrm{app}([\,], [3, 2]))) && \text{правило 2: } x = 2,\ s = [\,]\\
&= 1 : (3 : (2 : [3, 2])) && \text{правило 1}\\
&= 1 : (3 : (2 : (3 : (2 : [\,])))) && \text{раскрыли } [3, 2]\\
&= [1, 3, 2, 3, 2] && \text{сокращение } [x_1, \dots, x_n].
\end{aligned}$$
*Ключ:* второй аргумент $[3, 2]$ ни разу не раскрывается — рекурсия идёт только по первому.
:::

::: {.problem #prob:lec03:rev-lh}
Докажите, что $\mathrm{lh}(\mathrm{rev}(s)) = \mathrm{lh}(s)$ для всех $s \in S(A)$.
:::

::: answer
Индукция по $s$ с утверждением [-@prop:lec03:lh-app] в переходе.
:::

::: solution
*База:* $\mathrm{lh}(\mathrm{rev}([\,])) = \mathrm{lh}([\,])$, так как $\mathrm{rev}([\,]) = [\,]$. *Переход:* пусть $\mathrm{lh}(\mathrm{rev}(s)) = \mathrm{lh}(s)$. Тогда
$$\mathrm{lh}(\mathrm{rev}(x : s)) = \mathrm{lh}(\mathrm{app}(\mathrm{rev}(s), [x])) = \mathrm{lh}(\mathrm{rev}(s)) + \mathrm{lh}([x]) = \mathrm{lh}(s) + 1 = \mathrm{lh}(x : s).$$
*Ключ:* не раскрывать $\mathrm{app}(\mathrm{rev}(s), [x])$ по определению (первый аргумент $\mathrm{rev}(s)$ неизвестен), а сразу применить утверждение [-@prop:lec03:lh-app] о длине конкатенации. Здесь $\mathrm{lh}([x]) = 1 + \mathrm{lh}([\,]) = 1$.
:::

::: {.problem #prob:lec03:init}
a) Дайте рекурсивное определение функции $\mathrm{init}$, удаляющей последний символ строки: $\mathrm{init}([\,]) = [\,]$, $\mathrm{init}([1, 2, 3]) = [1, 2]$;
b) докажите, что $\mathrm{init}(\mathrm{app}(s, [x])) = s$ для всех $s \in S(A)$ и $x \in A$.
:::

::: answer
a) $\mathrm{init}([\,]) = [\,]$, $\mathrm{init}(x : [\,]) = [\,]$, $\mathrm{init}(x : (y : s)) = x : \mathrm{init}(y : s)$;
b) индукция по $s$; в переходе нужна лемма [-@lem:lec03:app-empty], чтобы увидеть, что $\mathrm{app}(s, [x])$ непуста.
:::

::: solution
a) Последний символ строки $x : s$ зависит от того, пуст ли хвост: если $s = [\,]$, удалять нужно саму голову; иначе голова остаётся, а удаляется последний символ хвоста. Отсюда три правила из ответа: каждая строка ровно одного из видов $[\,]$, $x : [\,]$, $x : (y : s)$ по (A1), (A2), так что определение однозначно. Проверка: $\mathrm{init}([1, 2, 3]) = 1 : \mathrm{init}([2, 3]) = 1 : (2 : \mathrm{init}([3])) = 1 : (2 : [\,]) = [1, 2]$.

b) Фиксируем $x$, индукция по $s$. *База:* $\mathrm{init}(\mathrm{app}([\,], [x])) = \mathrm{init}(x : [\,]) = [\,]$. *Переход:* пусть $\mathrm{init}(\mathrm{app}(s, [x])) = s$. По определению $\mathrm{app}(y : s, [x]) = y : \mathrm{app}(s, [x])$. Чтобы применить третье правило $\mathrm{init}$, нужно, чтобы $\mathrm{app}(s, [x])$ была непустой. *Ключ:* если бы $\mathrm{app}(s, [x]) = [\,]$, то по лемме [-@lem:lec03:app-empty] было бы $[x] = [\,]$, что противоречит (A1). Значит, $\mathrm{app}(s, [x]) = z : u$ для некоторых $z$, $u$, и
$$\mathrm{init}(y : (z : u)) = y : \mathrm{init}(z : u) = y : \mathrm{init}(\mathrm{app}(s, [x])) = y : s.$$
:::

::: {.problem #prob:lec03:cancel-right}
Докажите сокращение справа: если $\mathrm{app}(t, s) = \mathrm{app}(r, s)$, то $t = r$ — без явной индукции, с помощью уже доказанных утверждений.
:::

::: answer
Применить $\mathrm{rev}$ к обеим частям, утверждение [-@prop:lec03:rev-app], сокращение слева (лемма [-@lem:lec03:cancel-left]) и следствие [-@cor:lec03:rev-rev].
:::

::: solution
*Ключ:* переворот превращает правый конец строки в левый, а сокращать слева мы уже умеем. Из $\mathrm{app}(t, s) = \mathrm{app}(r, s)$ следует $\mathrm{rev}(\mathrm{app}(t, s)) = \mathrm{rev}(\mathrm{app}(r, s))$ (от равных аргументов функция принимает равные значения). По утверждению [-@prop:lec03:rev-app] это $\mathrm{app}(\mathrm{rev}(s), \mathrm{rev}(t)) = \mathrm{app}(\mathrm{rev}(s), \mathrm{rev}(r))$. По лемме [-@lem:lec03:cancel-left] $\mathrm{rev}(t) = \mathrm{rev}(r)$. Применив $\mathrm{rev}$ ещё раз и следствие [-@cor:lec03:rev-rev], получаем $t = \mathrm{rev}(\mathrm{rev}(t)) = \mathrm{rev}(\mathrm{rev}(r)) = r$. Индукция спрятана внутри использованных утверждений, но сама по себе в этом доказательстве не нужна.
:::

::: {.problem #prob:lec03:ind-var}
Пусть функция $\mathrm{sum}$ на строках над $\N$ задана правилами $\mathrm{sum}([\,]) = 0$, $\mathrm{sum}(x : s) = x + \mathrm{sum}(s)$. Докажите, что $\mathrm{sum}(\mathrm{app}(s, t)) = \mathrm{sum}(s) + \mathrm{sum}(t)$. По какой переменной вести индукцию?
:::

::: answer
По $s$ — первому аргументу $\mathrm{app}$; при фиксированном $t$.
:::

::: solution
*Ключ:* обе функции раскрываются только на строке, начинающейся с конструктора, а в левой части с конструктора можно начать только $s$ (замечание [-@rem:lec03:which-var]). *База:* $\mathrm{sum}(\mathrm{app}([\,], t)) = \mathrm{sum}(t) = 0 + \mathrm{sum}(t)$. *Переход:* если $\mathrm{sum}(\mathrm{app}(s, t)) = \mathrm{sum}(s) + \mathrm{sum}(t)$, то
$$\begin{aligned}\mathrm{sum}(\mathrm{app}(x : s, t)) &= \mathrm{sum}(x : \mathrm{app}(s, t)) = x + \mathrm{sum}(\mathrm{app}(s, t))\\ &= x + \mathrm{sum}(s) + \mathrm{sum}(t) = \mathrm{sum}(x : s) + \mathrm{sum}(t).\end{aligned}$$
Индукция по $t$ застряла бы в переходе на выражении $\mathrm{app}(s, x : t)$, для которого правила нет. Это доказательство дословно повторяет доказательство утверждения [-@prop:lec03:lh-app]: $\mathrm{lh}$ — это $\mathrm{sum}$ строки, в которой каждый символ заменён на $1$.
:::

# Итоги

- Строка задаётся не тем, что она такое, а тем, как она строится: из $[\,]$ конструктором $x : s$; аксиомы (A1), (A2) гарантируют, что непустая строка однозначно разбирается на голову и хвост, и поэтому рекурсивные определения функций корректны.
- Принцип индукции не выводится из (A1), (A2): он и есть формальное «других строк нет», исключающее бесконечные объекты вида $\omega = 1 : \omega$.
- Доказательство по индукции — это база $P([\,])$ и импликация $P(s) \to P(x : s)$ для произвольных $s$, $x$; предполагать в переходе $\forall s\, P(s)$ нельзя, а предикат $P$ должен быть достаточно общим, чтобы предположение индукции подошло на месте применения.
- Индукцию ведут по тому аргументу, по которому идёт рекурсия: ассоциативность $\mathrm{app}$ доказывается индукцией по первому аргументу и застревает при индукции по второму.
- Если про хвост ничего знать не нужно, хватает разбора случаев «$[\,]$ или $x : r$» (так доказано, что из $\mathrm{app}(s, t) = [\,]$ следует $s = t = [\,]$); если нужно — требуется индукция.
- Конкатенация ассоциативна, имеет единицу $[\,]$ с обеих сторон и допускает сокращение, но не коммутативна; для опровержения «для всех» хватает одного контрпримера $[1, 2] \ne [2, 1]$.
- $\mathrm{rev}(\mathrm{app}(s, t)) = \mathrm{app}(\mathrm{rev}(t), \mathrm{rev}(s))$ и $\mathrm{rev}(\mathrm{rev}(s)) = s$, откуда сокращение справа получается без новой индукции.

# Глоссарий

Строка над алфавитом $A$, $S(A)$
:   объект, построенный из пустой строки $[\,]$ конечным числом применений конструктора $x : s$; $S(A)$ — множество всех строк над $A$; [-@def:lec03:string].

Алфавит
:   фиксированный набор символов, из которых строятся строки; [-@def:lec03:string].

$\lbrack\,\rbrack$ (пустая строка)
:   строка без символов, один из двух конструкторов; [-@def:lec03:string].

$x : s$; голова, хвост
:   строка, полученная приписыванием символа $x$ слева к строке $s$; $x$ — голова, $s$ — хвост; [-@def:lec03:string].

$\lbrack x_1, \dots, x_n\rbrack$
:   сокращение для $x_1 : (x_2 : (\dots : (x_n : [\,]) \dots))$; [-@def:lec03:string].

Индуктивное определение
:   определение объектов через правила их построения из исходных конструкторов; [-@def:lec03:string].

Аксиомы (A1), (A2)
:   $[\,] \ne x : s$; $x : s = y : t \iff x = y \wedge s = t$; [-@ax:lec03:a1a2].

Принцип индукции для строк (ПИ)
:   $P([\,]) \wedge \forall s\, \forall x\, (P(s) \to P(x : s)) \to \forall s\, P(s)$; [-@ax:lec03:induction].

База, переход (шаг), предположение индукции
:   $P([\,])$; $\forall s\, \forall x\, (P(s) \to P(x : s))$; посылка $P(s)$ при выводе $P(x : s)$; [-@ax:lec03:induction].

Рекурсивное определение функции
:   задание значения на $[\,]$ и выражение значения на $x : s$ через значение на $s$; [-@def:lec03:lh].

$\mathrm{lh}(s)$
:   длина строки: $\mathrm{lh}([\,]) = 0$, $\mathrm{lh}(x : s) = 1 + \mathrm{lh}(s)$; в листках $\mathrm{len}$; [-@def:lec03:lh].

$\mathrm{app}(s, t)$ (конкатенация)
:   $\mathrm{app}([\,], t) = t$, $\mathrm{app}(x : s, t) = x : \mathrm{app}(s, t)$; [-@def:lec03:app].

$\mathrm{rev}(s)$ (переворот)
:   $\mathrm{rev}([\,]) = [\,]$, $\mathrm{rev}(x : s) = \mathrm{app}(\mathrm{rev}(s), [x])$; [-@def:lec03:rev].

Доказательство от противного
:   вывод противоречия из отрицания доказываемого утверждения; [-@ex:lec03:neq].

Доказательство разбором случаев
:   отдельное доказательство для каждого из исчерпывающих случаев, например $s = [\,]$ и $s = x : r$; [-@lem:lec03:app-empty].

# Самопроверка

1. Запишите строку $[\text{s}, \text{u}, \text{n}]$ над латинским алфавитом через конструкторы и вычислите по определению $\mathrm{lh}$ и $\mathrm{rev}$ этой строки.
2. Над алфавитом $S(\N)$ равны ли строки $[\,]$ и $[[\,]]$? Чему равны их длины? Ответ обоснуйте аксиомами.
3. Пусть $\mathrm{dup}([\,]) = [\,]$, $\mathrm{dup}(x : s) = x : (x : \mathrm{dup}(s))$. Вычислите $\mathrm{dup}([1, 2])$ и докажите, что $\mathrm{lh}(\mathrm{dup}(s)) = 2\, \mathrm{lh}(s)$ для всех $s$.
4. Нужно доказать $\mathrm{lh}(\mathrm{app}(s, \mathrm{app}(t, r))) = \mathrm{lh}(s) + \mathrm{lh}(t) + \mathrm{lh}(r)$. Нужна ли здесь новая индукция? Если да, то по какой переменной; если нет, то почему.
5. Докажите, что $\mathrm{lh}(s) = 0$ тогда и только тогда, когда $s = [\,]$.
6. Докажите без индукции: если $\mathrm{app}(s, t) = s$, то $t = [\,]$.
7. Найдите ошибку в «доказательстве» коммутативности $\mathrm{app}$ индукцией по $s$: «База: $\mathrm{app}([\,], t) = t = \mathrm{app}(t, [\,])$ по лемме [-@lem:lec03:app-nil]. Переход: $\mathrm{app}(x : s, t) = x : \mathrm{app}(s, t) = x : \mathrm{app}(t, s) = \mathrm{app}(t, x : s)$».
8. Над алфавитом $\{0, 1\}$ найдите две различные непустые строки $s$, $t$ с $\mathrm{app}(s, t) = \mathrm{app}(t, s)$ и две строки, для которых это равенство неверно.

::: answers
1. $\text{s} : (\text{u} : (\text{n} : [\,]))$; $\mathrm{lh} = 1 + (1 + (1 + 0)) = 3$; $\mathrm{rev} = \mathrm{app}(\mathrm{rev}([\text{u}, \text{n}]), [\text{s}]) = \mathrm{app}([\text{n}, \text{u}], [\text{s}]) = [\text{n}, \text{u}, \text{s}]$.
2. Нет: $[[\,]] = [\,] : [\,]$, и по (A1) $[\,] \ne [\,] : [\,]$. Длины $0$ и $1 + \mathrm{lh}([\,]) = 1$.
3. $\mathrm{dup}([1, 2]) = [1, 1, 2, 2]$. Индукция по $s$: база $0 = 2 \cdot 0$; переход $\mathrm{lh}(x : (x : \mathrm{dup}(s))) = 2 + \mathrm{lh}(\mathrm{dup}(s)) = 2 + 2\, \mathrm{lh}(s) = 2\, \mathrm{lh}(x : s)$.
4. Не нужна: дважды применить утверждение [-@prop:lec03:lh-app] — сначала к $s$ и $\mathrm{app}(t, r)$, затем к $t$ и $r$.
5. «$\Leftarrow$» — определение $\mathrm{lh}$. «$\Rightarrow$» — разбор случаев: если $s = x : r$, то $\mathrm{lh}(s) = 1 + \mathrm{lh}(r) \ge 1 \ne 0$; значит, остаётся $s = [\,]$.
6. $\mathrm{app}(s, t) = s = \mathrm{app}(s, [\,])$ по лемме [-@lem:lec03:app-nil], и по лемме [-@lem:lec03:cancel-left] $t = [\,]$.
7. Неверен последний шаг $x : \mathrm{app}(t, s) = \mathrm{app}(t, x : s)$: по определению $x : \mathrm{app}(t, s) = \mathrm{app}(x : t, s)$, а символ $x$ нельзя «занести» во второй аргумент. Пример: $t = [2]$, $s = [\,]$, $x = 1$ даёт $[1, 2] \ne [2, 1]$.
8. Например, $s = [0]$, $t = [0, 0]$: обе склейки равны $[0, 0, 0]$. Неравенство: $s = [0]$, $t = [1]$, склейки $[0, 1] \ne [1, 0]$ по (A2), так как $0 \ne 1$.
:::
