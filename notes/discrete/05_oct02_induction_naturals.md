В лекции 3 строки были заданы правилами построения, и утверждения обо всех строках доказывались принципом индукции (аксиома [-@ax:lec03:induction]). # Теория

## Натуральные числа и их главное свойство {#sec:lec05:naturals}

Множество натуральных чисел $\N = \{0, 1, 2, \dots\}$ в курсе не определяется формально. Мы пользуемся привычными свойствами: $0 \ne 1$, $2 < 3$, $3 + 2 = 5$, законы сложения и умножения, «между $n$ и $n + 1$ нет натуральных чисел». Главное же свойство $\N$, которого не видно из таблицы сложения, — индукция. Чтобы понять, зачем она нужна, посмотрим, чем опасна проверка на примерах.

::: {.example #ex:lec05:euler}
Верно ли, что число $n^2 + n + 41$ простое при всех $n \in \N$?

*Ответ:* нет, хотя при $n = 0, 1, \dots, 39$ оно простое.

*Решение.* Значения $41, 43, 47, 53, 61, 71, \dots, 1601$ при $n \le 39$ — простые числа (это можно проверить перебором делителей). Но при $n = 40$ получаем $40^2 + 40 + 41 = 40 \cdot 41 + 41 = 41^2 = 1681$ — составное число.
:::

Сорок подтверждений подряд ничего не доказывают: утверждение «для всех $n$» говорит о бесконечном множестве случаев, а проверить можно только конечное число. Нужен способ одним рассуждением охватить все $n$. Для строк его дал принцип индукции; натуральное число строится так же, как строка над алфавитом $\{1\}$: из $0$ применением операции «$+1$».

::: {.axiom #ax:lec05:induction title="принцип математической индукции (ПМИ)"}
Для любого предиката $\varphi$ с предметной областью $\N$:
$$\Bigl(\varphi(0) \wedge \forall n \in \N\, \bigl(\varphi(n) \to \varphi(n + 1)\bigr)\Bigr) \to \forall n \in \N\ \varphi(n).$$
Равносильная форма через множества: для любого $X \subseteq \N$, если $0 \in X$ и для каждого $n \in \N$ из $n \in X$ следует $n + 1 \in X$, то $X = \N$.
:::

Утверждение $\varphi(0)$ называется *базой индукции* (base step), утверждение $\forall n\, (\varphi(n) \to \varphi(n + 1))$ — *индукционным переходом* (inductive step), а посылка $\varphi(n)$, из которой в переходе выводят $\varphi(n + 1)$, — *предположением индукции* (inductive hypothesis). Те же слова, что для строк (аксиома [-@ax:lec03:induction]): при отождествлении $0 \leftrightarrow [\,]$ и $n + 1 \leftrightarrow 1 : s$ из замечания [-@rem:lec03:naturals] принцип для строк над $\{1\}$ превращается в ПМИ.

Две формы равносильны, потому что предикаты и подмножества $\N$ переводятся друг в друга. По предикату $\varphi$ строим множество $X = \{n \in \N \mid \varphi(n)\}$, тогда $\varphi(n)$ равносильно $n \in X$ и $\forall n\, \varphi(n)$ равносильно $X = \N$. Наоборот, по множеству $X$ берём предикат «$n \in X$». Форма с множествами короче, когда нужно рассуждать о самих принципах (раздел [-@sec:lec05:equiv]); форма с предикатами привычнее в задачах.

::: {.remark #rem:lec05:nat tag="соглашение курса"}
В курсе $0 \in \N$ (замечания [-@rem:lec01:nat] и [-@rem:lec03:nat]), поэтому база ПМИ — $\varphi(0)$. В курсе математического анализа $\N = \{1, 2, \dots\}$, и там та же аксиома записывается с базой $\varphi(1)$. Утверждения «для всех $n \ge 1$» в нашем курсе доказываются индукцией с базой $1$ (утверждение [-@prop:lec05:shifted] ниже).
:::

Сначала — метод целиком на простом утверждении. Суммы нечётных чисел: $1 = 1$, $1 + 3 = 4$, $1 + 3 + 5 = 9$, $1 + 3 + 5 + 7 = 16$. Похоже, сумма первых $n$ нечётных чисел — это $n^2$.

::: {.example #ex:lec05:odd}
Докажите, что для всех $n \in \N$
$$1 + 3 + \dots + (2n - 1) = \sum_{k=0}^{n-1} (2k + 1) = n^2.$$

*Ответ:* индукция по $n$ с базой $n = 0$.

*Решение.* Предикат $\varphi(n)$: «$\sum_{k=0}^{n-1} (2k + 1) = n^2$».

*База:* $\varphi(0)$. Слева сумма без слагаемых, она равна $0$; справа $0^2 = 0$.

*Переход.* Возьмём произвольное $n \in \N$ и предположим $\varphi(n)$. Тогда
$$\sum_{k=0}^{n} (2k + 1) = \sum_{k=0}^{n-1} (2k + 1) + (2n + 1) = n^2 + 2n + 1 = (n + 1)^2.$$
Во втором равенстве применено предположение индукции. Получено $\varphi(n + 1)$; так как $n$ произвольно, переход доказан, и по ПМИ $\varphi(n)$ верно для всех $n \in \N$.
:::

::: {.remark #rem:lec05:empty-sum tag="корнер-кейс"}
При $n = 0$ в сумме нет слагаемых. *Пустая сумма* по определению равна $0$, а *пустое произведение* — $1$: тогда правила $\sum_{k=0}^{n} a_k = \sum_{k=0}^{n-1} a_k + a_n$ и $\prod_{k=0}^{n} a_k = \bigl(\prod_{k=0}^{n-1} a_k\bigr) \cdot a_n$ верны и при $n = 0$. Так же $\mathrm{lh}([\,]) = 0$ для строк. Если пустая сумма смущает, базу можно взять при $n = 1$ ($1 = 1^2$), но тогда случай $n = 0$ остаётся недоказанным и требует отдельной фразы.
:::

Обе части принципа необходимы, и каждую легко «забыть».

::: {.remark #rem:lec05:both-parts title="без базы и без перехода"}
*Без базы.* Предикат $\varphi(n)$: «$n = n + 1$». Переход верен: если $n = n + 1$, то, прибавив $1$, получаем $n + 1 = n + 2$. Но $\varphi(0)$, то есть $0 = 1$, ложно, и ложно $\varphi(n)$ при всех $n$. Переход доказывает лишь «если верно для $n$, то верно и для $n + 1$», а для какого-то $n$ утверждение должно быть верно «с самого начала».

*Без перехода.* Предикат $\varphi(n)$: «$n < 5$». База $0 < 5$ верна, переход нарушается при $n = 4$, и $\varphi(5)$ ложно. Переход должен быть доказан для *каждого* $n$; если он не проходит хотя бы при одном $n$, цепочка $\varphi(0) \Rightarrow \varphi(1) \Rightarrow \varphi(2) \Rightarrow \dots$ рвётся (рис. [-@fig:lec05:chains]).
:::

Порочного круга в индукции нет: переход доказывает импликацию, а не $\varphi(n)$ (замечание [-@rem:lec03:circle]). Ошибки в доказательствах по индукции обычно прячутся в другом месте — в переходе, который работает не при всех $n$.

::: {.remark #rem:lec05:horses tag="подводный камень"}
«Докажем, что в любом табуне из $n \ge 1$ лошадей все лошади одной масти. База $n = 1$: одна лошадь одной масти с собой. Переход: возьмём табун из $n + 1$ лошадей и пронумеруем их $1, \dots, n + 1$. Лошади $1, \dots, n$ образуют табун из $n$ лошадей, по предположению индукции они одной масти; лошади $2, \dots, n + 1$ — тоже. Эти две группы пересекаются, поэтому все $n + 1$ лошадей одной масти».

Вывод ложен, значит, ошибка есть. База верна. Переход проходит при $n \ge 2$: тогда лошадь номер $2$ входит в обе группы и «склеивает» их масти. Но при $n = 1$ группы $\{1\}$ и $\{2\}$ не пересекаются, и из «каждая лошадь одной масти с собой» не следует, что две лошади одной масти. Переход $\varphi(1) \to \varphi(2)$ не доказан, цепочка рвётся на первом же звене. Мораль: проверяя переход, нужно пройти по нему при самом маленьком допустимом $n$ — именно там чаще всего ломаются рассуждения вида «возьмём элемент, который есть в обеих частях».
:::

::: {.remark #rem:lec05:check tag="частое заблуждение"}
«*Проверили для $n = 1, 2, 3, 4, 5$ — работает, значит, верно для всех $n$*». Нет: пример [-@ex:lec05:euler] выдерживает сорок проверок и ломается на сорок первой. Проверка малых случаев полезна, чтобы угадать ответ и найти базу, но доказательством «для всех $n$» не является. Другой пример: $2^n > n^2$ верно при $n = 0, 1$, неверно при $n = 2, 3, 4$ и снова верно при всех $n \ge 5$ (самопроверка).
:::

## Индукция с произвольной базой {#sec:lec05:shifted}

Часто утверждение верно не с нуля, а начиная с некоторого $n_0$. Формально ПМИ говорит о всех $n \in \N$, но это не мешает.

::: {.proposition #prop:lec05:shifted title="индукция с базой $n_0$"}
Пусть $n_0 \in \N$, верно $\varphi(n_0)$ и для каждого $n \ge n_0$ из $\varphi(n)$ следует $\varphi(n + 1)$. Тогда $\varphi(n)$ верно для всех $n \ge n_0$.
:::

::: proof
*Идея:* обычная индукция для утверждения «$n \ge n_0 \to \varphi(n)$», которое при $n < n_0$ истинно автоматически.

Применим ПМИ к предикату $\psi(n)$: «$n \ge n_0 \to \varphi(n)$». *База:* если $n_0 = 0$, то $\psi(0)$ — это $\varphi(0)$, оно дано; если $n_0 > 0$, то посылка $0 \ge n_0$ ложна и $\psi(0)$ истинно. *Переход:* пусть $\psi(n)$, докажем $\psi(n + 1)$, то есть выведем $\varphi(n + 1)$ из $n + 1 \ge n_0$. Если $n + 1 = n_0$, то $\varphi(n_0)$ дано. Если $n + 1 > n_0$, то $n \ge n_0$, по $\psi(n)$ верно $\varphi(n)$, а по условию из $\varphi(n)$ при $n \ge n_0$ следует $\varphi(n + 1)$. По ПМИ $\psi(n)$ верно при всех $n$, то есть $\varphi(n)$ верно при всех $n \ge n_0$.
:::

Другой способ: применить ПМИ к $\chi(k) := \varphi(n_0 + k)$. Оба способа годятся; первый интересен тем, что при $n < n_0$ утверждения $\psi(n)$ — пустые истины (определение [-@def:lec02:vacuous]): формально база — ноль, а настоящая база — $n_0$. Так устроен следующий пример.

::: {.example #ex:lec05:egyptian}
Докажите, что при каждом натуральном $n \ge 3$ найдутся попарно различные $a_1, \dots, a_n \in \N_+$ такие, что
$$1 = \frac{1}{a_1} + \frac{1}{a_2} + \dots + \frac{1}{a_n}.$$

*Ответ:* индукция с базой $n_0 = 3$: $1 = \frac12 + \frac13 + \frac16$; переход — разделить разложение пополам и добавить $\frac12$.

*Решение.* Для $n = 4$ работает $1 = \frac12 + \frac14 + \frac16 + \frac1{12}$ — это и есть «половина» разложения для $n = 3$ плюс $\frac12$. Обобщим.

*База* $n = 3$: $\frac12 + \frac13 + \frac16 = \frac{3 + 2 + 1}{6} = 1$.

*Переход.* Пусть $n \ge 3$ и $1 = \frac1{a_1} + \dots + \frac1{a_n}$ с попарно различными $a_i \in \N_+$. Умножим равенство на $\frac12$ и прибавим $\frac12$:
$$1 = \frac12 + \frac12 = \frac12 + \frac1{2a_1} + \dots + \frac1{2a_n}.$$
Это $n + 1$ слагаемое со знаменателями $2, 2a_1, \dots, 2a_n$. Числа $2a_i$ попарно различны, так как различны $a_i$. Осталось проверить, что $2 \ne 2a_i$ ни при каком $i$. Если $2 = 2a_i$, то $a_i = 1$ и слагаемое $\frac1{a_i}$ уже равно $1$, а остальные $n - 1 \ge 2$ слагаемых положительны — сумма больше $1$, противоречие. По утверждению [-@prop:lec05:shifted] разложение существует при всех $n \ge 3$.
:::

::: {.remark #rem:lec05:egyptian-small tag="корнер-кейс"}
При $n = 1$ утверждение верно ($1 = \frac11$), при $n = 2$ — нет: из $\frac1a + \frac1b = 1$ при $a \ne b$, скажем $a < b$, следует $\frac1a > \frac12$, то есть $a = 1$ и $\frac1b = 0$, что невозможно. Переход из примера при $n = 1$ даёт $1 = \frac12 + \frac12$ — знаменатели совпали. Это ровно то место, где в доказательстве понадобилось $n \ge 3$ (на самом деле достаточно $n \ge 2$). Поэтому база — $3$, а не $1$: переход из $\varphi(1)$ в $\varphi(2)$ неверен, ведь $\varphi(2)$ ложно.
:::

Ещё одна типичная трудность — переход «не проходит», хотя утверждение верно. Тогда помогает доказать *более сильное* утверждение: предположение индукции станет сильнее, и его хватит.

::: {.example #ex:lec05:strengthen}
Докажите, что $1 + \frac14 + \frac19 + \dots + \frac1{n^2} < 2$ при всех $n \ge 1$.

*Ответ:* индукцией доказывается более сильное неравенство $\sum_{k=1}^{n} \frac1{k^2} \le 2 - \frac1n$.

*Решение.* Прямая попытка застревает: из $S_n < 2$ нельзя получить $S_{n + 1} = S_n + \frac1{(n+1)^2} < 2$ — предположение не говорит, *насколько* $S_n$ меньше $2$, а запас мог кончиться. *Ключ:* хранить запас в самом утверждении. Пусть $\varphi(n)$: «$S_n \le 2 - \frac1n$». *База* $n = 1$: $1 \le 2 - 1$. *Переход:* при $n \ge 1$ по предположению индукции
$$S_{n+1} \le 2 - \frac1n + \frac1{(n+1)^2} \le 2 - \frac1n + \frac1{n(n+1)} = 2 - \frac1n + \Bigl(\frac1n - \frac1{n+1}\Bigr) = 2 - \frac1{n+1}.$$
Здесь использовано $(n + 1)^2 > n(n + 1)$. По утверждению [-@prop:lec05:shifted] $S_n \le 2 - \frac1n < 2$ при всех $n \ge 1$.
:::

Это продолжение наблюдения из лекции 3: предикат индукции должен быть достаточно общим, чтобы предположение индукции подошло на месте применения. Парадоксально, но более сильное утверждение доказать проще.

## Сильная индукция {#sec:lec05:strong}

В ПМИ для вывода $\varphi(n + 1)$ разрешено опираться только на $\varphi(n)$. Иногда этого мало. Пусть известно, что $a + \frac1a$ — целое число. Тогда целое и $a^2 + \frac1{a^2} = \bigl(a + \frac1a\bigr)^2 - 2$. А $a^3 + \frac1{a^3}$? Формула
$$a^n + \frac1{a^n} = \Bigl(a + \frac1a\Bigr)\Bigl(a^{n-1} + \frac1{a^{n-1}}\Bigr) - \Bigl(a^{n-2} + \frac1{a^{n-2}}\Bigr)$$ {#eq:lec05:recur}
(раскройте скобки) выражает очередное значение через *два* предыдущих. Для таких рассуждений удобна сильная индукция: в переходе разрешено пользоваться всеми предыдущими случаями сразу.

Сформулируем её через множества. Запись $\forall m < n\ \varphi$ — ограниченный квантор, как в определении [-@def:lec04:bounded]: она означает $\forall m\, (m < n \to \varphi)$, где $m$ пробегает $\N$.

::: {.definition #def:lec05:progressive title="прогрессивное множество"}
Множество $X \subseteq \N$ называется *прогрессивным* (progressive), если для каждого $n \in \N$
$$\forall m < n\ (m \in X) \to n \in X,$$
то есть $n$ попадает в $X$, как только в $X$ попали все меньшие числа. Обозначение: $\mathrm{Prog}(X)$.
:::

Образно: прогрессивное множество «взбирается» по $\N$, захватывая очередное число, как только захвачены все предыдущие (рис. [-@fig:lec05:chains]). Например, $\N$ прогрессивно, а $\{0, 1, 2\}$ — нет: все числа меньше $3$ в нём лежат, а $3$ — нет.

::: {.proposition #prop:lec05:strong title="принцип сильной индукции (ПСИ)"}
Если $X \subseteq \N$ прогрессивно, то $X = \N$. В форме с предикатом: если для каждого $n \in \N$ из истинности всех $\varphi(0), \dots, \varphi(n - 1)$ следует $\varphi(n)$, то $\varphi(n)$ верно при всех $n \in \N$.
:::

Доказательство — в разделе [-@sec:lec05:equiv] (теорема [-@thm:lec05:equiv]): ПСИ выводится из ПМИ. А пока — как им пользоваться.

Справа: ПСИ — в $n$ ведут стрелки от всех меньших чисел; при $n = 0$ стрелок нет, и условие прогрессивности само требует $0 \in X$"}

\end{tikzpicture}
```

На первый взгляд у ПСИ нет базы. Это не так: база спрятана в условии прогрессивности.

::: {.lemma #lem:lec05:prog-zero title="база сильной индукции"}
Если $X$ прогрессивно, то $0 \in X$.
:::

::: proof
Подставим в определение прогрессивности $n = 0$: из $\forall m < 0\ (m \in X)$ следует $0 \in X$. Посылка $\forall m\, (m < 0 \to m \in X)$ истинна как пустая истина: $m < 0$ ложно для всех натуральных $m$ (определение [-@def:lec02:vacuous]). Значит, $0 \in X$.
:::

На практике это означает: проверяя прогрессивность, при $n = 0$ нельзя опереться ни на одно предыдущее значение, и $\varphi(0)$ приходится доказывать «с нуля». То же относится ко всем малым $n$, для которых нужных предыдущих значений ещё нет.

::: {.example #ex:lec05:inverse}
Пусть $a \in \R$, $a \ne 0$ и $a + \frac1a \in \Z$. Докажите, что $a^n + \frac1{a^n} \in \Z$ для всех $n \in \N$.

*Ответ:* сильная индукция по формуле [-@eq:lec05:recur]; случаи $n = 0$ и $n = 1$ разбираются отдельно.

*Решение.* Докажем, что множество $X = \{n \in \N \mid a^n + \frac1{a^n} \in \Z\}$ прогрессивно. Возьмём произвольное $n$ и предположим, что все $m < n$ лежат в $X$.

Если $n \ge 2$, то $n - 1$ и $n - 2$ — натуральные числа, меньшие $n$, поэтому лежат в $X$. По формуле [-@eq:lec05:recur] число $a^n + \frac1{a^n}$ — разность произведения двух целых чисел и целого числа, то есть целое. Значит, $n \in X$.

Если $n = 0$: $a^0 + \frac1{a^0} = 2 \in \Z$. Если $n = 1$: $a + \frac1a \in \Z$ по условию. В обоих случаях предположение не понадобилось (при $n = 1$ формула [-@eq:lec05:recur] требовала бы $n - 2 = -1 \notin \N$).

Итак, $\mathrm{Prog}(X)$, и по ПСИ $X = \N$. Пример: при $a = 2 + \sqrt3$ имеем $\frac1a = 2 - \sqrt3$ и $a + \frac1a = 4$; по формуле [-@eq:lec05:recur] $a^2 + \frac1{a^2} = 4 \cdot 4 - 2 = 14$, $a^3 + \frac1{a^3} = 4 \cdot 14 - 4 = 52$ — целые числа, хотя само $a$ иррационально.
:::

::: {.remark #rem:lec05:small-cases tag="подводный камень"}
«Докажем сильной индукцией, что $2^n = 1$ при всех $n \in \N$. База: $2^0 = 1$. Переход: пусть $2^m = 1$ при всех $m < n$; тогда
$$2^n = \frac{2^{n-1} \cdot 2^{n-1}}{2^{n-2}} = \frac{1 \cdot 1}{1} = 1.$$
»
Тождество $2^n = 2^{n-1} \cdot 2^{n-1} / 2^{n-2}$ верно, но при $n = 1$ в нём участвует $2^{-1}$, а $-1 \notin \N$: предположение индукции про $m = n - 2$ при $n = 1$ ничего не говорит. Переход не доказан для $n = 1$, и действительно, $2^1 \ne 1$. В примере [-@ex:lec05:inverse] тот же случай разобран отдельно, поэтому доказательство верно. Правило: если переход опирается на $\varphi(n - k)$, то случаи $n < k$ доказываются без этой опоры.
:::

Сильная индукция особенно удобна, когда задача сводится к *меньшему* случаю, но не обязательно к $n - 1$.

::: {.example #ex:lec05:binary}
Докажите, что каждое $n \in \N_+$ — сумма нескольких различных степеней двойки (например, $13 = 8 + 4 + 1$).

*Ответ:* сильная индукция; чётное $n = 2k$ сводится к $k$, нечётное $n = 2k + 1$ — тоже к $k$.

*Решение.* Пусть $X$ — множество тех $n \in \N$, для которых верно «$n = 0$ или $n$ — сумма различных степеней двойки». Включение $n = 0$ нужно, чтобы утверждение было вида «для всех $n \in \N$». Докажем $\mathrm{Prog}(X)$. Пусть все $m < n$ лежат в $X$. Если $n = 0$, то $n \in X$ по определению $X$. Если $n = 1 = 2^0$, тоже. Пусть $n \ge 2$; каждое натуральное число чётно или нечётно, то есть $n = 2k$ или $n = 2k + 1$, причём $1 \le k < n$. По предположению $k = 2^{e_1} + \dots + 2^{e_s}$ с различными $e_i$. Тогда
$$2k = 2^{e_1 + 1} + \dots + 2^{e_s + 1}, \qquad 2k + 1 = 2^{e_1 + 1} + \dots + 2^{e_s + 1} + 2^0,$$
и все показатели различны: $e_i + 1$ различны между собой и все $\ge 1$, то есть отличны от $0$. Значит, $n \in X$, и по ПСИ $X = \N$.

*Ключ:* предположение понадобилось для $k \approx n/2$, а не для $n - 1$; с одним только $\varphi(n)$ переход от $n$ к $n + 1$ потребовал бы разбирать «перенос разряда».
:::

## Принцип наименьшего числа {#sec:lec05:lnp}

Третья форма индукции говорит не о «переходах», а о наименьших элементах.

::: {.proposition #prop:lec05:lnp title="принцип наименьшего числа (ПНЧ)"}
Каждое непустое множество $X \subseteq \N$ имеет наименьший элемент $\min X$. В символах (для фиксированного $X$):
$$\exists m\, (m \in X) \to \exists n\, \bigl(n \in X \wedge \forall m\, (m < n \to m \notin X)\bigr).$$
:::

Доказательство — в разделе [-@sec:lec05:equiv]. Пример: $X = \{n \in \N \mid n^2 > 50\}$ непусто ($10 \in X$), $\min X = 8$, так как $7^2 = 49 \le 50 < 64 = 8^2$.

::: {.remark #rem:lec05:lnp-why title="почему $\N$, почему непустое"}
Оба условия существенны. Пустое множество наименьшего элемента не имеет — элементов нет вообще. Для подмножеств $\Z$ принцип неверен: у самого $\Z$ (и у множества отрицательных чисел) нет наименьшего элемента, ведь для любого $x$ число $x - 1$ меньше. Для $\Q$ и $\R$ он неверен даже среди неотрицательных чисел: множество $\{x \in \Q \mid x > 0\}$ непусто, но для каждого его элемента $x$ число $\frac{x}{2}$ меньше и тоже лежит в нём. ПНЧ — свойство именно $\N$: в $\N$ нельзя бесконечно спускаться вниз.
:::

Главное применение ПНЧ — *метод минимального контрпримера*. Чтобы доказать $\forall n\, \varphi(n)$, предполагаем, что контрпримеры («плохие» числа) есть. По ПНЧ среди них есть наименьший $n$, и все меньшие числа «хорошие». Остаётся из этого получить противоречие: построить по $n$ ещё меньший контрпример или показать, что $n$ на самом деле хороший. Вариант, когда противоречие — меньший контрпример, называют *бесконечным спуском*: если бы контрпримеры были, из каждого получался бы меньший, и натуральные числа бесконечно убывали бы, что запрещает ПНЧ.

::: {.example #ex:lec05:descent}
Найдите все целочисленные решения уравнения $8a^4 + 4b^4 + 2c^4 = d^4$.

*Ответ:* только $a = b = c = d = 0$.

*Решение.* Набор $(0, 0, 0, 0)$ — решение. Если $(a, b, c, d)$ — решение в целых числах, то $(|a|, |b|, |c|, |d|)$ — тоже (четвёртые степени не меняются), поэтому достаточно доказать, что нет ненулевых решений в $\N$. Предположим противное: множество
$$Y = \{(a, b, c, d) \in \N^4 \mid 8a^4 + 4b^4 + 2c^4 = d^4 \wedge a + b + c + d > 0\}$$
непусто. Тогда непусто и $X = \{a + b + c + d \mid (a, b, c, d) \in Y\} \subseteq \N_+$. *Ключ:* «размер» решения измеряем натуральным числом $a + b + c + d$ и берём по ПНЧ решение наименьшего размера: $x = \min X = a + b + c + d$ для некоторой $(a, b, c, d) \in Y$.

Число $d^4$ чётно, а квадрат и четвёртая степень нечётного числа нечётны, поэтому $d = 2\delta$, $\delta \in \N$. Подставим и сократим на $2$: $4a^4 + 2b^4 + c^4 = 8\delta^4$. Отсюда $c^4$ чётно и $c = 2\gamma$; подставив и сократив на $2$: $2a^4 + b^4 + 8\gamma^4 = 4\delta^4$, откуда $b = 2\beta$; ещё раз: $a^4 + 8\beta^4 + 4\gamma^4 = 2\delta^4$, откуда $a = 2\alpha$. Подставив $a = 2\alpha$ и сократив на $2$, получаем
$$8\alpha^4 + 4\beta^4 + 2\gamma^4 = \delta^4.$$
Значит, $(\alpha, \beta, \gamma, \delta)$ — снова решение, причём $2(\alpha + \beta + \gamma + \delta) = x > 0$, то есть $0 < \alpha + \beta + \gamma + \delta < x$. Это решение лежит в $Y$, и его размер меньше $\min X$ — противоречие.
:::

Метод минимального контрпримера — это та же индукция, только записанная от противного. Вот одно и то же утверждение двумя способами. Если бы равенство из примера [-@ex:lec05:odd] нарушалось, по ПНЧ нашлось бы наименьшее плохое $n$. $n \ne 0$, так как база верна; значит, $n = m + 1$, и $m$ хорошее. Но тогда выкладка из перехода показывает, что $n = m + 1$ хорошее, — противоречие. Каждый шаг совпадает с шагом обычной индукции, только снаружи стоит «предположим противное». Это наблюдение и есть ядро следующей теоремы.

## Равносильность трёх принципов {#sec:lec05:equiv}

::: {.theorem #thm:lec05:equiv title="равносильность принципов индукции"}
Следующие утверждения равносильны:

1. принцип сильной индукции (ПСИ);
2. принцип наименьшего числа (ПНЧ);
3. принцип математической индукции (ПМИ).

В частности, так как ПМИ принят как аксиома (аксиома [-@ax:lec05:induction]), ПСИ и ПНЧ верны.
:::

Доказываем по кругу ПСИ $\Rightarrow$ ПНЧ $\Rightarrow$ ПМИ $\Rightarrow$ ПСИ (рис. [-@fig:lec05:cycle]): трёх импликаций достаточно, чтобы из любого принципа получить любой другой. Обозначим $\overline{X} = \N \setminus X$ — дополнение до $\N$.

```{.tikz #fig:lec05:cycle caption="Схема доказательства теоремы [-@thm:lec05:equiv]: у каждой стрелки — множество, к которому применяется исходный принцип"}
\begin{tikzpicture}[pr/.style={draw, thick, rounded corners, minimum width=1.9cm, minimum height=0.8cm, fill=nbblue!10}, ar/.style={-{Stealth}, very thick}]
  \node[pr] (si) at (0,3) {ПСИ};
  \node[pr] (ln) at (4.6,0) {ПНЧ};
  \node[pr] (mi) at (-4.6,0) {ПМИ};
  \draw[ar] (si) -- (ln) node[pos=0.45, anchor=south west, align=left, font=\small, xshift=4pt] {ПСИ для $\overline{X}$:\\ нет минимума у $X$\\ $\Rightarrow$ $\overline{X}$ прогрессивно};
  \draw[ar] (ln) -- (mi) node[midway, below=5pt, align=center, font=\small] {ПНЧ для $\overline{X}$: $n = \min \overline{X}$, $n = m + 1$, $m \in X$};
  \draw[ar] (mi) -- (si) node[pos=0.55, anchor=south east, align=right, font=\small, xshift=-4pt] {ПМИ для\\ $Y = \{n \mid \forall m < n\ (m \in X)\}$};
\end{tikzpicture}
```

::: proof
*ПСИ $\Rightarrow$ ПНЧ.* Пусть $X \subseteq \N$ не имеет наименьшего элемента; докажем, что $X = \varnothing$ (это контрапозиция ПНЧ). Проверим, что $\overline{X}$ прогрессивно. Пусть все $m < n$ лежат в $\overline{X}$, то есть не лежат в $X$. Если бы $n \in X$, то $n$ было бы наименьшим элементом $X$, а его нет. Значит, $n \in \overline{X}$. По ПСИ $\overline{X} = \N$, то есть $X = \varnothing$.

*ПНЧ $\Rightarrow$ ПМИ.* Пусть $0 \in X$ и для всех $n$ из $n \in X$ следует $n + 1 \in X$. Предположим, что $\overline{X} \ne \varnothing$. По ПНЧ есть $n = \min \overline{X}$. Так как $0 \in X$, имеем $n \ne 0$, поэтому $n = m + 1$ для некоторого $m \in \N$. Поскольку $m < n$ и $n$ — наименьший элемент $\overline{X}$, получаем $m \notin \overline{X}$, то есть $m \in X$. По условию тогда $n = m + 1 \in X$ — противоречие с $n \in \overline{X}$. Значит, $\overline{X} = \varnothing$ и $X = \N$.

*ПМИ $\Rightarrow$ ПСИ.* *Идея:* сильное предположение «все $m < n$ в $X$» само становится предикатом для обычной индукции. Пусть $X$ прогрессивно. Положим
$$Y = \{n \in \N \mid \forall m < n\ (m \in X)\}.$$
*База:* $0 \in Y$, так как $\forall m < 0\ (m \in X)$ — пустая истина. *Переход:* пусть $n \in Y$, то есть все $m < n$ лежат в $X$. По прогрессивности $n \in X$. Если $m < n + 1$, то $m < n$ или $m = n$; в обоих случаях $m \in X$. Значит, $n + 1 \in Y$. По ПМИ $Y = \N$. Наконец, для любого $n$ имеем $n + 1 \in Y$ и $n < n + 1$, откуда $n \in X$. Итак, $X = \N$.
:::

::: {.remark #rem:lec05:why-axiom title="почему индукция — аксиома"}
ПМИ не следует из «арифметических» свойств вроде $0 \ne 1$ и законов сложения: он и есть формальное «других натуральных чисел нет», как принцип индукции для строк запрещал объект $\omega$ (замечание [-@rem:lec03:ip-axiom]). Например, в множестве $[0, +\infty)$ неотрицательных вещественных чисел тоже есть $0$, операция $+1$ и те же законы арифметики, но множество $X = \N$ содержит $0$ и замкнуто относительно $+1$, а всего $[0, +\infty)$ не исчерпывает. Для неотрицательных вещественных чисел ПМИ, а вместе с ним по теореме [-@thm:lec05:equiv] ПСИ и ПНЧ, неверны: $\{x \in \R \mid x > 0\}$ не имеет наименьшего элемента.
:::

## Какой принцип выбрать {#sec:lec05:choose}

Все три принципа равносильны, поэтому любое доказательство можно переписать в любой из форм. Но длина и прозрачность доказательства от выбора зависят.

| Принцип | Когда удобен | Типичная задача | На чём ошибаются |
|:--|:--|:--|:--|
| ПМИ | $\varphi(n + 1)$ получается из одного $\varphi(n)$ | суммы, неравенства, формулы для $n$-го члена | непроверенная база; переход не работает при малом $n$; слишком слабое $\varphi$ |
| ПСИ | нужны несколько предыдущих случаев или случай $\approx n/2$ | рекуррентности по двум членам, разложение на «меньшие части» | малые $n$, для которых нужных предыдущих значений нет |
| ПНЧ | удобно рассуждать от противного: «возьмём наименьший контрпример» | несуществование решений (спуск), существование и единственность разложений | спуск должен давать *натуральное* число, строго меньшее минимума |

В лекции 6 ПНЧ даст деление с остатком (наименьшее $s$ с $a < bs$) и обе половины основной теоремы арифметики (наименьшее число без разложения на простые и наименьшее число с двумя разными разложениями).

# Практика

::: {.problem #prob:lec05:squares}
Докажите, что для каждого натурального $n \ge 1$
$$1^2 + 2^2 + \dots + n^2 = \frac{n(n + 1)(2n + 1)}{6}.$$
:::

::: answer
Индукция по $n$; переход сводится к тождеству $\frac{n(n+1)(2n+1)}{6} + (n + 1)^2 = \frac{(n+1)(n+2)(2n+3)}{6}$.
:::

::: solution
*База* $n = 1$: $1 = \frac{1 \cdot 2 \cdot 3}{6}$. Можно взять и базу $n = 0$: обе части равны $0$ (пустая сумма, замечание [-@rem:lec05:empty-sum]), тогда формула доказана для всех $n \in \N$.

*Переход.* Пусть формула верна для $n$. Тогда
$$\begin{aligned}\sum_{k=1}^{n+1} k^2 &= \frac{n(n+1)(2n+1)}{6} + (n+1)^2 = \frac{(n+1)\bigl(n(2n+1) + 6(n+1)\bigr)}{6}\\ &= \frac{(n+1)(2n^2 + 7n + 6)}{6} = \frac{(n+1)(n+2)(2n+3)}{6}.\end{aligned}$$
*Ключ:* вынести общий множитель $n + 1$, а не раскрывать всё; правая часть — это формула при $n + 1$, так как $(n + 1) + 1 = n + 2$ и $2(n + 1) + 1 = 2n + 3$. По утверждению [-@prop:lec05:shifted] формула верна при всех $n \ge 1$.
:::

::: {.problem #prob:lec05:half}
Докажите, что для каждого натурального $n > 1$
$$\frac1{n+1} + \frac1{n+2} + \dots + \frac1{2n} > \frac{13}{24}.$$
:::

::: answer
Последовательность сумм $S_n$ возрастает, а $S_2 = \frac7{12} = \frac{14}{24}$; индукция с базой $n = 2$.
:::

::: solution
Обозначим левую часть $S_n$. *База* $n = 2$: $S_2 = \frac13 + \frac14 = \frac7{12} = \frac{14}{24} > \frac{13}{24}$. При $n = 1$ неравенство неверно: $S_1 = \frac12 = \frac{12}{24}$, поэтому база действительно $2$.

*Переход.* При переходе от $S_n$ к $S_{n+1}$ слева уходит слагаемое $\frac1{n+1}$, а справа добавляются $\frac1{2n+1}$ и $\frac1{2n+2}$:
$$S_{n+1} - S_n = \frac1{2n+1} + \frac1{2n+2} - \frac1{n+1} = \frac1{2n+1} - \frac1{2n+2} > 0.$$
*Ключ:* сравнивать не $S_{n+1}$ с $\frac{13}{24}$, а $S_{n+1}$ с $S_n$; тогда из $S_n > \frac{13}{24}$ сразу получаем $S_{n+1} > S_n > \frac{13}{24}$.
:::

::: {.problem #prob:lec05:stamps}
Докажите, что любую сумму $n \ge 8$ рублей можно набрать марками по $3$ и $5$ рублей, то есть $n = 3a + 5b$ при некоторых $a, b \in \N$. Проведите доказательство двумя способами: сильной индукцией и обычной.
:::

::: answer
ПСИ: три базы $8 = 3 + 5$, $9 = 3 \cdot 3$, $10 = 5 \cdot 2$ и сведение $n$ к $n - 3$. ПМИ: от $n$ к $n + 1$ заменой одной пятирублёвой марки на две трёхрублёвые или трёх трёхрублёвых на две пятирублёвые.
:::

::: solution
*Сильная индукция.* Пусть $\varphi(n)$: «$n < 8$ или $n = 3a + 5b$ при некоторых $a, b \in \N$»; докажем, что множество таких $n$ прогрессивно. При $n < 8$ доказывать нечего. При $n = 8, 9, 10$ представления $8 = 3 + 5$, $9 = 3 \cdot 3$, $10 = 5 \cdot 2$ выписаны явно. При $n \ge 11$ число $n - 3 \ge 8$ меньше $n$, по предположению $n - 3 = 3a + 5b$, и $n = 3(a + 1) + 5b$. *Ключ:* шаг назад на $3$ требует трёх баз подряд — иначе $n = 10$ сводилось бы к $7$, а $7$ не представляется.

*Обычная индукция* с базой $8 = 3 \cdot 1 + 5 \cdot 1$. Пусть $n \ge 8$ и $n = 3a + 5b$. Если $b \ge 1$, заменим одну марку в $5$ рублей двумя по $3$: $n + 1 = 3(a + 2) + 5(b - 1)$. Если $b = 0$, то $n = 3a \ge 8$, откуда $a \ge 3$; заменим три марки по $3$ двумя по $5$: $n + 1 = 3(a - 3) + 5 \cdot 2$. *Ключ:* разбор случаев по тому, какие марки есть в представлении.

Сравнение: в первом способе переход однороден, но баз три; во втором база одна, но переход требует разбора случаев. Это типичная развилка между ПСИ и ПМИ.
:::

::: {.problem #prob:lec05:tournament}
В стране конечно много городов (хотя бы один), и любые два различных города соединены дорогой с односторонним движением. Докажите, что есть город, из которого можно добраться по дорогам в любой другой.
:::

::: answer
Индукция по числу городов $n \ge 1$: убрать один город $v$, найти для остальных город $u$, из которого достижимы все остальные, и разобрать направление дороги между $u$ и $v$.
:::

::: solution
Пусть $\varphi(n)$: «в любой стране с $n$ городами, где каждые два различных города соединены односторонней дорогой, есть город, из которого достижимы все остальные». Предикат говорит обо *всех* таких странах — иначе предположение индукции не к чему было бы применить. При $n = 0$ утверждение ложно (городов нет), поэтому база — $n = 1$, и работает утверждение [-@prop:lec05:shifted].

*База* $n = 1$: единственный город подходит — «остальных» нет, и утверждение о них — пустая истина.

*Переход.* Возьмём произвольную страну с $n + 1 \ge 2$ городами и любой её город $v$. Остальные $n \ge 1$ городов с дорогами между ними образуют страну, к которой применимо предположение индукции: есть город $u \ne v$, из которого по этим дорогам достижимы все города, кроме $v$. Если дорога идёт из $u$ в $v$, то из $u$ достижимы все. Если из $v$ в $u$, то из $v$ можно попасть в $u$, а оттуда — в любой другой город, так что подходит $v$.

*Ключ:* начинать переход с произвольной страны из $n + 1$ города и *убирать* из неё город. Если, наоборот, взять страну из $n$ городов и добавить город, придётся отдельно объяснять, почему так получается любая страна из $n + 1$ города.
:::

::: {.problem #prob:lec05:railway}
На круговой железной дороге $n \ge 1$ станций. На каждой станции лежит запас угля, на каждом перегоне между соседними станциями поезд тратит фиксированное количество угля, и суммарного запаса хватает на весь круг. Поезд начинает путь пустым, на каждой станции забирает весь её уголь и вмещает сколько угодно. Докажите, что найдётся станция, начав с которой, поезд объедет весь круг.
:::

::: answer
Индукция по $n$: найдётся станция, запаса которой хватает на следующий за ней перегон; её можно «слить» со следующей станцией и применить предположение индукции к кругу из $n$ станций.
:::

::: solution
Пронумеруем станции по ходу движения $1, \dots, n$ (по кругу: после $n$ идёт $1$); на станции $i$ лежит $c_i$ угля, перегон от $i$ до следующей станции стоит $d_i$, и $\sum c_i \ge \sum d_i$. Поезд объезжает круг, если при движении от стартовой станции запас угля ни на одном перегоне не становится отрицательным.

*База* $n = 1$: одна станция, на ней весь уголь, $c_1 \ge d_1$ — поезд объезжает круг.

*Переход.* Пусть утверждение верно для $n$ станций, рассмотрим круг из $n + 1$ станции. *Ключ:* есть станция $i$ с $c_i \ge d_i$ — иначе $\sum c_i < \sum d_i$. Сольём станцию $i$ со следующей за ней станцией $j$ в одну станцию с запасом $c_i + c_j$ и перегоном до станции после $j$ стоимостью $d_i + d_j$. Получился круг из $n$ станций с теми же суммами, и по предположению индукции на нём есть подходящая стартовая станция $s$. На исходном круге стартуем с той же станции (если $s$ — слитая станция, то со станции $i$). Вне пары $i, j$ поезд ведёт себя одинаково на обоих кругах. Подъехав к $i$ с запасом $f \ge 0$, на исходном круге он берёт $c_i \ge d_i$ и доезжает до $j$ с запасом $f + c_i - d_i \ge 0$, там берёт $c_j$ и имеет $f + c_i + c_j - d_i$; на слитом круге он смог проехать $d_i + d_j$ с запасом $f + c_i + c_j$, поэтому $f + c_i + c_j - d_i \ge d_j$, и до станции после $j$ поезд доезжает с тем же запасом, что и на слитом круге. Значит, исходный круг поезд тоже объезжает.
:::

::: {.problem #prob:lec05:harmonic}
Докажите, что для каждого $n \in \N$ найдётся $k \in \N_+$ такое, что $1 + \frac12 + \frac13 + \dots + \frac1k \ge n$.
:::

::: answer
Индукцией по $j$ доказывается $H_{2^j} \ge 1 + \frac{j}{2}$, где $H_k = \sum_{i=1}^{k} \frac1i$; подходит $k = 2^{2n}$.
:::

::: solution
*Ключ:* индукцию ведём не по $n$, а по вспомогательной переменной $j$, для которой есть удобная оценка. Пусть $H_k = 1 + \frac12 + \dots + \frac1k$ и $\varphi(j)$: «$H_{2^j} \ge 1 + \frac{j}{2}$».

*База:* $H_1 = 1 \ge 1$.

*Переход.* $H_{2^{j+1}} = H_{2^j} + \sum_{i = 2^j + 1}^{2^{j+1}} \frac1i$. В последней сумме $2^j$ слагаемых, и каждое не меньше $\frac1{2^{j+1}}$, поэтому сумма не меньше $\frac{2^j}{2^{j+1}} = \frac12$. По предположению индукции $H_{2^{j+1}} \ge 1 + \frac{j}{2} + \frac12 = 1 + \frac{j+1}{2}$.

Теперь при $k = 2^{2n}$ получаем $H_k \ge 1 + n \ge n$.
:::

::: {.problem #prob:lec05:sqrt2}
Докажите методом минимального контрпримера, что уравнение $a^2 = 2b^2$ не имеет решений в положительных натуральных числах (то есть $\sqrt2$ иррационально).
:::

::: answer
Возьмём решение с наименьшим $b$; тогда $a = 2c$ и $(b, c)$ — решение с $c < b$.
:::

::: solution
Предположим, что решения есть. Тогда множество $X = \{b \in \N_+ \mid \exists a \in \N_+\ a^2 = 2b^2\}$ непусто, и по ПНЧ в нём есть наименьший элемент $b$; пусть $a^2 = 2b^2$. Число $a^2$ чётно, а квадрат нечётного числа нечётен, поэтому $a = 2c$ для некоторого $c \in \N_+$. Тогда $4c^2 = 2b^2$, то есть $b^2 = 2c^2$. Значит, $c \in X$ (свидетель — $b$). Но $c^2 = \frac{b^2}{2} < b^2$, откуда $c < b = \min X$ — противоречие. *Ключ:* новое решение получается перестановкой ролей: старое $b$ становится новым «$a$». В лекции 6 то же утверждение получится в одну строку из основной теоремы арифметики.
:::

# Итоги

- ПМИ — аксиома о $\N$: из $\varphi(0)$ и $\forall n\, (\varphi(n) \to \varphi(n + 1))$ следует $\forall n\, \varphi(n)$; формы с предикатом и с множеством равносильны, так как $\varphi$ задаёт множество $\{n \mid \varphi(n)\}$.
- Ни базу, ни переход нельзя опустить: «$n = n + 1$» имеет верный переход без базы, «$n < 5$» — базу без перехода; переход надо проверять и при самом маленьком $n$, где ломаются рассуждения вроде «лошадей одной масти».
- Утверждения «для $n \ge n_0$» доказываются индукцией с базой $n_0$; малые $n$ проверяются отдельно, и настоящая база — первое $n$, с которого работает переход и верно утверждение.
- Если переход не проходит, часто помогает усилить утверждение: $\sum_{k=1}^{n} \frac1{k^2} \le 2 - \frac1n$ доказать индукцией проще, чем $< 2$.
- ПСИ позволяет в переходе опираться на все меньшие случаи; его база спрятана в прогрессивности как пустая истина, и случаи, где нужных предыдущих значений нет, разбираются отдельно — иначе «доказывается» $2^n = 1$.
- ПНЧ (у непустого $X \subseteq \N$ есть минимум) неверен для $\Z$ и для положительных рациональных чисел; на нём основаны минимальный контрпример и бесконечный спуск.
- ПСИ $\Rightarrow$ ПНЧ $\Rightarrow$ ПМИ $\Rightarrow$ ПСИ, поэтому все три принципа — разные формы одного свойства $\N$.

# Глоссарий

Принцип математической индукции (ПМИ)
:   $\varphi(0) \wedge \forall n \in \N\, (\varphi(n) \to \varphi(n + 1)) \to \forall n \in \N\ \varphi(n)$; для множеств: $0 \in X$ и замкнутость $X \subseteq \N$ относительно $+1$ дают $X = \N$; [-@ax:lec05:induction].

База, переход, предположение индукции
:   $\varphi(0)$; $\forall n\, (\varphi(n) \to \varphi(n + 1))$; посылка $\varphi(n)$ при выводе $\varphi(n + 1)$; [-@ax:lec05:induction].

Пустая сумма, пустое произведение
:   сумма без слагаемых равна $0$, произведение без множителей равно $1$; [-@rem:lec05:empty-sum].

Индукция с базой $n_0$
:   из $\varphi(n_0)$ и $\varphi(n) \to \varphi(n + 1)$ при всех $n \ge n_0$ следует $\varphi(n)$ при всех $n \ge n_0$; [-@prop:lec05:shifted].

Прогрессивное множество, $\mathrm{Prog}(X)$
:   $X \subseteq \N$, для которого при каждом $n$ из $\forall m < n\ (m \in X)$ следует $n \in X$; [-@def:lec05:progressive].

Принцип сильной индукции (ПСИ)
:   всякое прогрессивное $X \subseteq \N$ равно $\N$; [-@prop:lec05:strong].

Принцип наименьшего числа (ПНЧ)
:   всякое непустое $X \subseteq \N$ имеет наименьший элемент $\min X$; [-@prop:lec05:lnp].

$\min X$
:   наименьший элемент множества $X$: $\min X \in X$ и $\min X \le x$ для всех $x \in X$; [-@prop:lec05:lnp].

Минимальный контрпример, бесконечный спуск
:   доказательство от противного: берём наименьший по ПНЧ контрпример и получаем противоречие, в случае спуска — строя ещё меньший контрпример; [-@ex:lec05:descent].

$\overline{X}$ (для $X \subseteq \N$)
:   дополнение до $\N$: $\N \setminus X$; [-@thm:lec05:equiv].

# Самопроверка

1. Для $X = \{n \in \N \mid 2^n \ge n + 1\}$ выпишите, что нужно проверить в базе и в переходе ПМИ в форме с множествами, и докажите, что $X = \N$.
2. При каких $n \in \N$ верно $2^n > n^2$? Докажите ответ.
3. Найдите ошибку: «Докажем, что $n^2 + n$ нечётно при всех $n \in \N$. Если $n^2 + n$ нечётно, то $(n + 1)^2 + (n + 1) = (n^2 + n) + 2(n + 1)$ — нечётное плюс чётное, то есть нечётно».
4. Последовательность задана так: $a_0 = 2$, $a_1 = 3$, $a_n = 3a_{n-1} - 2a_{n-2}$ при $n \ge 2$. Докажите, что $a_n = 2^n + 1$ при всех $n \in \N$.
5. Числа Фибоначчи: $F_0 = 0$, $F_1 = 1$, $F_n = F_{n-1} + F_{n-2}$ при $n \ge 2$. Найдите ошибку: «Все $F_n$ чётны. База: $F_0 = 0$. Переход сильной индукцией: $F_n = F_{n-1} + F_{n-2}$ — сумма двух чётных по предположению чисел, значит, чётно».
6. Приведите непустое подмножество $\Z$ и непустое подмножество $\{x \in \Q \mid x \ge 0\}$ без наименьшего элемента. Найдите $\min\{n \in \N \mid n^2 > 50\}$.
7. Докажите ПСИ напрямую из ПНЧ (не через ПМИ).
8. Докажите, что каждое $n \in \N_+$ представляется в виде $2^k m$, где $k \in \N$, а $m$ нечётно. Какой из трёх принципов здесь удобнее и почему?

::: answers
1. База: $0 \in X$, то есть $2^0 = 1 \ge 1$. Переход: для каждого $n$ из $2^n \ge n + 1$ вывести $2^{n+1} \ge n + 2$; действительно, $2^{n+1} = 2 \cdot 2^n \ge 2n + 2 \ge n + 2$.
2. При $n = 0, 1$ и при всех $n \ge 5$. Проверка: $1 > 0$, $2 > 1$, $4 = 4$, $8 < 9$, $16 = 16$, $32 > 25$. Индукция с базой $5$: если $2^n > n^2$ и $n \ge 5$, то $2^{n+1} > 2n^2 \ge (n + 1)^2$, так как $n^2 - 2n - 1 = (n - 1)^2 - 2 > 0$ при $n \ge 3$. Переход работает уже с $n = 3$, но при $n = 3$ и $n = 4$ неравенство неверно, поэтому база — $5$.
3. Переход верен, но базы нет, и она ложна: $0^2 + 0 = 0$ чётно. На самом деле $n^2 + n = n(n + 1)$ всегда чётно (замечание [-@rem:lec05:both-parts]).
4. Сильная индукция: $n = 0$: $2 = 2^0 + 1$; $n = 1$: $3 = 2^1 + 1$; при $n \ge 2$ по предположению для $n - 1$ и $n - 2$: $3(2^{n-1} + 1) - 2(2^{n-2} + 1) = 3 \cdot 2^{n-1} - 2^{n-1} + 1 = 2^n + 1$.
5. При $n = 1$ рекуррентная формула неприменима ($n - 2 < 0$), этот случай надо проверять отдельно — и $F_1 = 1$ нечётно (замечание [-@rem:lec05:small-cases]).
6. Например, $\Z$ целиком или $\{x \in \Z \mid x < 0\}$; $\{x \in \Q \mid x > 0\}$ (для $x$ в нём $\frac{x}{2}$ меньше). Минимум равен $8$.
7. Пусть $X$ прогрессивно и $X \ne \N$. По ПНЧ есть $n = \min \overline{X}$. Все $m < n$ лежат в $X$, и по прогрессивности $n \in X$ — противоречие.
8. ПСИ (или ПНЧ): если $n$ нечётно, $n = 2^0 n$; если чётно, $n = 2n'$ с $1 \le n' < n$, по предположению $n' = 2^k m$, и $n = 2^{k+1} m$. Нужен случай $n/2$, а не $n - 1$, поэтому ПМИ неудобен.
:::
