# Контекст

В лекциях 3–4 сходимость доказывалась одним из двух способов: по определению [-@def:lec03:limit], когда предел известен заранее, или по арифметике предела и теореме о двух милиционерах (теоремы [-@thm:lec04:quotient], [-@thm:lec04:squeeze]), когда последовательность собрана из известных. Но про $\left(1 + \frac1n\right)^n$ мы знаем только, что она ограничена (задача [-@prob:lec02:e-bounded]) и, как окажется, возрастает; ни на какое знакомое число её предел не похож. Нужен способ доказать, что предел *существует*, не называя его. Этот способ держится не на технике оценок, а на свойстве самих вещественных чисел — аксиоме непрерывности. Из неё выводятся точные грани множеств и теорема Вейерштрасса о монотонных последовательностях; с её помощью определяется число $e$. В конце лекции появляются подпоследовательности — инструмент для доказательства расходимости и основа лекции 6.

# После прочтения ты сможешь

- объяснить, чем $\R$ отличается от $\Q$, сформулировать аксиому непрерывности и привести пример, где в $\Q$ она нарушается;
- находить $\sup$ и $\inf$ множества, обосновывая обе части («это граница» и «меньше нельзя»), и отличать точную грань от наибольшего элемента;
- объяснять, почему у пустого и у неограниченного множества нет точной грани и зачем эти условия в теореме о существовании точной грани;
- доказывать сходимость монотонной ограниченной последовательности по теореме Вейерштрасса и находить предел рекуррентной последовательности;
- доказывать сходимость $\left(1 + \frac1n\right)^n$ и вычислять пределы вида $\left(1 + \frac kn\right)^n$ и другие неопределённости $1^\infty$;
- проверять, является ли последовательность подпоследовательностью данной, и доказывать расходимость с помощью двух подпоследовательностей.

# Теория

## Зачем нужна аксиома непрерывности {#sec:lec05:motivation}

Рассмотрим последовательность, заданную рекуррентно:
$$x_1 = 2, \qquad x_{n+1} = \frac12\left(x_n + \frac{2}{x_n}\right).$$
Её первые члены — $2$, $\frac32$, $\frac{17}{12}$, $\frac{577}{408} \approx 1{,}41422$. Все члены рациональные: из рационального $x_n$ формула получает рациональное $x_{n+1}$. Последовательность убывает и ограничена снизу. Действительно, все $x_n > 0$, и при каждом $n$
$$x_{n+1}^2 - 2 = \frac14\left(x_n - \frac{2}{x_n}\right)^2 \ge 0, \qquad x_{n+1} - x_n = \frac{2 - x_n^2}{2x_n}.$$
Первое равенство даёт $x_n^2 \ge 2$ при всех $n$ (при $n = 1$ это $4 \ge 2$), поэтому $x_n > 1$, а второе тогда даёт $x_{n+1} \le x_n$.

Предположим, что $x_n \to q$. По следствию [-@cor:lec04:bound-limit] $q \ge 1$. Последовательность $x_{n+1}$ — та же, сдвинутая на один номер, и тоже стремится к $q$ (утверждение [-@prop:lec03:finite-change]). Правая часть рекуррентной формулы по арифметике предела (теоремы [-@thm:lec03:sum], [-@thm:lec04:quotient]) стремится к $\frac12\left(q + \frac2q\right)$. По единственности предела (теорема [-@thm:lec03:uniqueness])
$$q = \frac12\left(q + \frac2q\right), \quad\text{то есть}\quad q^2 = 2.$$
Но рационального числа с квадратом $2$ нет: если $\sqrt2 = \frac pq$ — несократимая дробь, то $p^2 = 2q^2$, значит, $p$ чётно, $p = 2r$, тогда $q^2 = 2r^2$ и $q$ тоже чётно — противоречие.

Получается, что в мире, где есть только рациональные числа, убывающая ограниченная последовательность $(x_n)$ предела не имеет. При этом все доказательства лекций 3–4 используют только арифметические действия и неравенства и дословно переносятся на $\Q$. Значит, никакая техника оценок не докажет утверждение «монотонная ограниченная последовательность сходится»: для этого нужно свойство, которое отличает $\R$ от $\Q$. Его удобно сформулировать на языке множеств.

Пусть $A = \{x > 0 \mid x^2 < 2\}$, $B = \{x > 0 \mid x^2 > 2\}$ (рис. [-@fig:lec05:gap]). Любой элемент $A$ меньше любого элемента $B$: из $0 < a$, $0 < b$, $a^2 < 2 < b^2$ следует $a < b$. В $\R$ между ними стоит число $\sqrt2$: $a \le \sqrt2 \le b$ для всех $a \in A$, $b \in B$. Если же рассматривать только рациональные $x$, то разделяющего рационального $c$ нет. Такое $c$ было бы не меньше $1 \in A$, то есть положительно. Если $c^2 < 2$, то при рациональном $h = \min\left(1, \frac{2 - c^2}{2(2c + 1)}\right) > 0$ имеем $(c + h)^2 \le c^2 + h(2c + 1) < 2$, и элемент $c + h \in A$ больше $c$. Если $c^2 > 2$, то при $h = \frac{c^2 - 2}{2c}$ число $c - h$ положительно, $(c - h)^2 = 2 + h^2 > 2$, и элемент $c - h \in B$ меньше $c$. Остаётся $c^2 = 2$, что невозможно. В $\Q$ на месте $\sqrt2$ «дырка».

## Аксиома непрерывности

::: {.axiom #ax:lec05:continuity title="аксиома непрерывности"}
Пусть $A, B \subseteq \R$, $A \ne \varnothing$, $B \ne \varnothing$ и $\forall a \in A\ \forall b \in B\colon a \le b$. Тогда
$$\exists c \in \R\ \ \forall a \in A\ \ \forall b \in B\colon\ a \le c \le b.$$
:::

Словами: если непустое множество $A$ лежит левее непустого множества $B$, то между ними можно вставить число. Это аксиома: она не доказывается, а входит в описание того, что такое вещественные числа, наряду с правилами арифметики и неравенств. В учебниках её называют также *аксиомой полноты* (completeness axiom). Для $\Q$ аксиома неверна — пример выше. Всё, что в анализе отличает $\R$ от $\Q$, выводится из неё.

::: {.remark #rem:lec05:axiom-conditions tag="корнер-кейс"}
Каждое условие аксиомы существенно.

- *Непустота.* Если $A = \varnothing$, $B = \R$, то условие «$a \le b$ для всех $a \in A$, $b \in B$» выполнено (элементов $a$ нет), а числа $c$ с $c \le b$ для всех $b \in \R$ не существует. Так же для $A = \R$, $B = \varnothing$.
- *Нестрогие неравенства.* Для $A = [0; 1]$, $B = [1; 2]$ годится только $c = 1$, и оно принадлежит обоим множествам. Аксиома с условием $a < c < b$ была бы неверна.
- *Число $c$ не обязано быть единственным:* для $A = [0; 1]$, $B = [2; 3]$ подходит любое $c \in [1; 2]$.
:::

## Ограниченные множества и точные грани {#sec:lec05:sup}

Для последовательностей ограниченность уже определена (определение [-@def:lec02:bounded-above]). Теперь то же для множеств.

::: {.definition #def:lec05:bounded-set title="ограниченное множество"}
Множество $A \subseteq \R$ называется *ограниченным сверху*, если $\exists C \in \R\ \forall a \in A\colon a \le C$, и *ограниченным снизу*, если $\exists C \in \R\ \forall a \in A\colon a \ge C$. Множество, ограниченное и сверху, и снизу, называется *ограниченным*.
:::

::: {.remark #rem:lec05:nonstrict tag="соглашение курса"}
У последовательностей в определении стоит строгое неравенство $a_n < C$, у множеств — нестрогое $a \le C$. На вопрос «ограничено или нет» это не влияет (замечание [-@rem:lec02:strict]): последовательность ограничена сверху тогда и только тогда, когда ограничено сверху множество её значений $\{a_n \mid n \in \N\}$. Но для самих границ нестрогое неравенство удобнее: лучшая граница множества $[0; 1]$ — число $1$, а неравенству $a < 1$ она не удовлетворяет.
:::

::: {.definition #def:lec05:upper-bound title="верхняя грань"}
*Верхней гранью* ограниченного сверху множества $A$ называется любое число $c \in \R$ такое, что $\forall a \in A\colon c \ge a$.
:::

Множество ограничено сверху ровно тогда, когда у него есть хотя бы одна верхняя грань, и тогда их бесконечно много: если $c$ — верхняя грань, то $c + 1$, $c + 2$, … тоже. Например, верхние грани и отрезка $[0; 1]$, и интервала $(0; 1)$ — это все числа $c \ge 1$, то есть луч $[1; +\infty)$ (рис. [-@fig:lec05:sup]). Из всех верхних граней самая информативная — наименьшая.

::: {.definition #def:lec05:sup title="точная верхняя грань"}
*Точной верхней гранью*, или *супремумом* (supremum), ограниченного сверху множества $A$ называется наименьшая из его верхних граней. Обозначение: $\sup(A)$ или $\sup A$.
:::

Итак, $s = \sup A$ означает два условия: (1) $s$ — верхняя грань: $a \le s$ для всех $a \in A$; (2) любая верхняя грань $c$ не меньше $s$. Наименьший элемент множества, если он есть, единственный, поэтому и супремум, если он существует, единственный.

::: {.example #ex:lec05:sup-examples}
Найдём $\sup [0; 1]$, $\sup (0; 1)$ и $\sup (0; \sqrt2)$.

*Ответ:* $\sup [0; 1] = 1 = \sup (0; 1)$, $\sup (0; \sqrt2) = \sqrt2$.

*Решение.* Для $(0; 1)$: число $1$ — верхняя грань. Пусть $c < 1$. Если $c \le 0$, то элемент $\frac12 \in (0; 1)$ больше $c$; если $0 < c < 1$, то элемент $\frac{c + 1}{2} \in (0; 1)$ больше $c$. В обоих случаях $c$ — не верхняя грань, поэтому наименьшая верхняя грань — $1$. Для $[0; 1]$ верхние грани те же, ответ тот же. Для $(0; \sqrt2)$ рассуждение такое же, с элементом $\frac{c + \sqrt2}{2}$.
:::

Обратите внимание: $\sup (0; 1) = 1$, хотя $1 \notin (0; 1)$. У интервала нет наибольшего элемента, а супремум есть.

::: {.proposition #prop:lec05:max title="супремум и максимум"}
Если у множества $A$ есть наибольший элемент $\max A$, то $\sup A = \max A$.
:::

::: proof
Число $m = \max A$ — верхняя грань, так как $a \le m$ для всех $a \in A$. Любая верхняя грань $c$ удовлетворяет $c \ge m$, потому что $m \in A$. Значит, $m$ — наименьшая верхняя грань.
:::

::: {.remark #rem:lec05:sup-not-max tag="частое заблуждение"}
«*Супремум — это наибольший элемент множества*». Нет. У $(0; 1)$ наибольшего элемента нет, а $\sup (0; 1) = 1$ существует и множеству не принадлежит. Верно так: если наибольший элемент есть, он совпадает с супремумом (утверждение [-@prop:lec05:max]), а если нет — супремум его заменяет. Супремум принадлежит множеству ровно тогда, когда он — наибольший элемент.
:::

::: {.remark #rem:lec05:sup-empty tag="корнер-кейс"}
У пустого множества супремума нет. Любое число $c$ — верхняя грань $\varnothing$: условие «$c \ge a$ для всех $a \in \varnothing$» выполнено, потому что проверять нечего. Наименьшего среди всех вещественных чисел нет. У множества, не ограниченного сверху (например, $\N$), нет ни одной верхней грани и тоже нет супремума. Иногда пишут $\sup A = +\infty$ как сокращение для «$A$ не ограничено сверху»; числом это не является.
:::

## Теорема о существовании точной грани

Пример с $\Q$ показывает, что супремум может и не существовать: множество $\{x \in \Q \mid x > 0,\ x^2 < 2\}$ непусто, ограничено сверху числом $2$, но наименьшей рациональной верхней грани у него нет (рассуждение раздела [-@sec:lec05:motivation]). В $\R$ такого не бывает.

::: {.theorem #thm:lec05:sup-exists title="о существовании точной грани"}
Если $A \subseteq \R$, $A \ne \varnothing$ и $A$ ограничено сверху, то $\sup A$ существует.
:::

::: proof
*Идея:* применить аксиому непрерывности к множеству $A$ и множеству его верхних граней.

Пусть $B$ — множество всех верхних граней $A$. Оно непусто, так как $A$ ограничено сверху, и $A$ непусто по условию. По определению верхней грани $a \le b$ для всех $a \in A$, $b \in B$. По аксиоме непрерывности [-@ax:lec05:continuity] найдётся $c \in \R$ с $a \le c \le b$ для всех $a \in A$, $b \in B$. Левое неравенство значит, что $c$ — верхняя грань, то есть $c \in B$. Правое — что $c$ не больше любой верхней грани. Значит, $c$ — наименьшая верхняя грань: $c = \sup A$.
:::

Например, множество $A = \{x \in \R \mid x > 0,\ x^2 < 2\}$ непусто ($1 \in A$) и ограничено сверху числом $2$, поэтому $\sup A$ существует; это $\sqrt2$. В $\Q$ то же множество супремума не имеет, и ровно в этом месте доказательство опирается на аксиому.

Всё сказанное переносится на нижние границы, если поменять знаки неравенств.

::: {.definition #def:lec05:inf title="нижняя грань, точная нижняя грань"}
*Нижней гранью* ограниченного снизу множества $A$ называется любое число $c \in \R$ такое, что $\forall a \in A\colon c \le a$. *Точной нижней гранью*, или *инфимумом* (infimum), называется наибольшая из нижних граней. Обозначение: $\inf(A)$ или $\inf A$.
:::

::: {.corollary #cor:lec05:inf-exists title="о существовании точной нижней грани"}
Если $A \ne \varnothing$ и $A$ ограничено снизу, то $\inf A$ существует, причём $\inf A = -\sup(-A)$, где $-A = \{-a \mid a \in A\}$.
:::

::: proof
Число $c$ — нижняя грань $A$ тогда и только тогда, когда $-c$ — верхняя грань $-A$ (неравенство $c \le a$ равносильно $-c \ge -a$). Множество $-A$ непусто и ограничено сверху, по теореме [-@thm:lec05:sup-exists] у него есть $s = \sup(-A)$. Тогда $-s$ — нижняя грань $A$, и для любой нижней грани $c$ число $-c$ — верхняя грань $-A$, поэтому $-c \ge s$, то есть $c \le -s$. Значит, $-s$ — наибольшая нижняя грань.
:::

Например, $\inf (0; 1] = 0 \notin (0; 1]$, а $\inf [0; 1] = 0 = \min [0; 1]$. Для последовательности пишут $\sup\limits_{n \in \N} a_n$ или $\sup a_n$ вместо $\sup\{a_n \mid n \in \N\}$, так же $\inf a_n$.

## Как найти точную грань (метод, разобранный на семинаре) {#sec:lec05:sup-method}

Определение супремума говорит о всех верхних гранях сразу, и проверять его прямо неудобно. Условие (2) удобнее переписать через $\varepsilon$.

::: {.proposition #prop:lec05:sup-eps title="характеризация точной грани через $\varepsilon$"}
Пусть $A \ne \varnothing$. Число $s$ равно $\sup A$ тогда и только тогда, когда

1. $\forall a \in A\colon a \le s$;
2. $\forall \varepsilon > 0\ \exists a \in A\colon a > s - \varepsilon$.

Аналогично $i = \inf A$ тогда и только тогда, когда $a \ge i$ для всех $a \in A$ и $\forall \varepsilon > 0\ \exists a \in A\colon a < i + \varepsilon$.
:::

::: proof
«$\Rightarrow$». Условие 1 — это то, что $s$ верхняя грань. Если $\varepsilon > 0$, то $s - \varepsilon < s$, и $s - \varepsilon$ не может быть верхней гранью: $s$ — наименьшая. Значит, найдётся $a \in A$ с $a > s - \varepsilon$.

«$\Leftarrow$». По условию 1 $s$ — верхняя грань. Пусть $c$ — верхняя грань и $c < s$. Возьмём $\varepsilon = s - c > 0$: по условию 2 найдётся $a \in A$ с $a > s - \varepsilon = c$, что противоречит тому, что $c$ — верхняя грань. Значит, любая верхняя грань $c \ge s$, и $s = \sup A$. Для инфимума — то же с обратными неравенствами.
:::

Условие 2 говорит: сколь угодно близко к $s$ слева есть элементы множества (рис. [-@fig:lec05:sup]). Отсюда схема поиска точной грани:

1. угадать кандидата $s$, посчитав несколько элементов и посмотрев, как элемент меняется с ростом параметров;
2. доказать неравенство $a \le s$ для всех элементов;
3. либо показать, что $s \in A$ (тогда $s = \max A = \sup A$ по утверждению [-@prop:lec05:max]), либо по произвольному $\varepsilon > 0$ явно предъявить элемент $a > s - \varepsilon$.

  \node[below=3pt, font=\small] at (0,0) {$0$};

  \node[above=4pt, font=\small, nbblue] at (0.4,0) {$A = (0; 1)$};
  \draw[nbred] (0.8,0.12) -- (0.8,-0.12);
  \node[below=3pt, font=\small, nbred] at (0.8,0) {$1 - \varepsilon$};
  \node[dot, nbred] at (0.9,0) {};
  \node[above=4pt, font=\small, nbred] at (0.9,0) {$a \in A$};
\end{tikzpicture}
```

::: {.example #ex:lec05:sup-sequence}
Найдём $\sup X$ и $\inf X$ для $X = \left\{\frac1n \mid n \in \N\right\}$.

*Ответ:* $\sup X = 1 = \max X$; $\inf X = 0$, наименьшего элемента нет.

*Решение.* Все элементы $\frac1n \le 1$, и $1 = \frac11 \in X$, поэтому $1 = \max X = \sup X$. Для инфимума: все $\frac1n > 0$, так что $0$ — нижняя грань. Пусть $\varepsilon > 0$. *Ключ:* предъявить элемент, зависящий от $\varepsilon$: при $n = \left[\frac1\varepsilon\right] + 1 > \frac1\varepsilon$ элемент $\frac1n < \varepsilon = 0 + \varepsilon$. По утверждению [-@prop:lec05:sup-eps] $\inf X = 0$. Сам $0$ в $X$ не лежит.
:::

::: {.remark #rem:lec05:only-bound tag="подводный камень"}
Типичная ошибка — проверить только условие 1. Число $2$ тоже удовлетворяет неравенству $\frac1n \le 2$, но $\sup\left\{\frac1n\right\} = 1$: верхних граней много, а точная — одна. Вторая ошибка — в условии 2 взять конкретное $\varepsilon$ («при $\varepsilon = 0{,}1$ подходит $n = 11$»): нужно показать, что элемент найдётся для *любого* $\varepsilon > 0$, то есть указать его как функцию от $\varepsilon$.
:::

## Теорема Вейерштрасса {#sec:lec05:weierstrass}

Вернёмся к последовательностям. Члены неубывающей ограниченной сверху последовательности поднимаются, но не выше любой верхней границы; естественный кандидат в предел — самое низкое место, выше которого они не поднимаются, то есть супремум множества значений.

::: {.theorem #thm:lec05:weierstrass title="Вейерштрасса"}
Если последовательность $(a_n)$ неубывающая и ограничена сверху, то она сходится, причём $\lim\limits_{n \to \infty} a_n = \sup\limits_{n \in \N} a_n$.
:::

::: proof
*Идея:* после первого члена, попавшего в полосу $(a - \varepsilon; a]$ около супремума $a$, в ней остаются все следующие члены — из-за монотонности.

Множество $A = \{a_1, a_2, a_3, \dots\}$ непусто и ограничено сверху (если $a_n < C$, то $C$ — его верхняя грань). По теореме [-@thm:lec05:sup-exists] существует $a = \sup A$. Докажем, что $a = \lim a_n$, то есть $\forall \varepsilon > 0\ \exists N\ \forall n > N\colon |a_n - a| < \varepsilon$.

Так как $a_n \le a$ при всех $n$, имеем $|a_n - a| = a - a_n$, и неравенство $|a_n - a| < \varepsilon$ равносильно $a_n > a - \varepsilon$. Пусть $\varepsilon > 0$. Если нашёлся номер $N$ с $a_N > a - \varepsilon$, то для всех $n > N$ по монотонности $a_n \ge a_N > a - \varepsilon$, и всё доказано. Если же такого номера нет, то $a_n \le a - \varepsilon$ при всех $n$, то есть $a - \varepsilon$ — верхняя грань $A$, меньшая $a = \sup A$. Это противоречит определению супремума.
:::

::: {.remark #rem:lec05:weierstrass-bounded}
Неубывающая последовательность автоматически ограничена снизу своим первым членом ($a_n \ge a_1$). Поэтому в теореме Вейерштрасса «ограничена сверху» — то же самое, что «ограничена». Монотонность достаточно иметь начиная с некоторого номера: изменение конечного числа членов не влияет на сходимость (утверждение [-@prop:lec03:finite-change]), но тогда предел — супремум «хвоста» $\sup_{n > n_0} a_n$, а не всего множества значений.
:::

::: {.corollary #cor:lec05:weierstrass-dec title="невозрастающая последовательность"}
Если $(a_n)$ невозрастающая и ограничена снизу, то она сходится и $\lim\limits_{n \to \infty} a_n = \inf\limits_{n \in \N} a_n$.
:::

::: proof
Последовательность $b_n = -a_n$ неубывающая и ограничена сверху. По теореме [-@thm:lec05:weierstrass] $b_n \to \sup b_n = -\inf a_n$ (следствие [-@cor:lec05:inf-exists]), и $a_n = -b_n \to \inf a_n$ по теореме [-@thm:lec03:sum].
:::

::: {.example #ex:lec05:heron}
Найдём предел последовательности $x_1 = 2$, $x_{n+1} = \frac12\left(x_n + \frac{2}{x_n}\right)$ из раздела [-@sec:lec05:motivation], теперь в $\R$.

*Ответ:* $\sqrt2$.

*Решение.* Там показано, что $(x_n)$ невозрастающая и $x_n > 1$. По следствию [-@cor:lec05:weierstrass-dec] она сходится к некоторому $q$, а то же вычисление, что в разделе [-@sec:lec05:motivation], даёт $q \ge 1$ и $q^2 = 2$. Значит, $q = \sqrt2$. Вычислительно это очень быстрый способ: $x_4 = \frac{577}{408}$ отличается от $\sqrt2$ меньше чем на $3 \cdot 10^{-6}$.
:::

Ещё пример: $b_n = \frac{n}{n + 1}$ возрастает (пример [-@ex:lec02:monotone]) и ограничена сверху, поэтому сходится к $\sup b_n = 1$.

Монотонная последовательность, не ограниченная с нужной стороны, тоже имеет предел, только бесконечный.

::: {.proposition #prop:lec05:monotone-infinite title="неограниченная монотонная"}
Если $(a_n)$ неубывающая и не ограничена сверху, то $a_n \to +\infty$. Если $(a_n)$ невозрастающая и не ограничена снизу, то $a_n \to -\infty$.
:::

::: proof
Пусть $M > 0$. Число $M$ — не верхняя граница, поэтому найдётся $N$ с $a_N > M$; тогда при $n > N$ имеем $a_n \ge a_N > M$. Это определение [-@def:lec04:infinite-limit] для $+\infty$. Второй случай — то же для $-a_n$.
:::

Итог: у монотонной последовательности предел есть всегда — конечный, если она ограничена, и бесконечный, если нет. Монотонная последовательность сходится тогда и только тогда, когда она ограничена (в одну сторону — теорема Вейерштрасса, в другую — теорема [-@thm:lec03:bounded]).

::: {.remark #rem:lec05:limit-is-sup tag="частое заблуждение"}
«*Если возрастающая последовательность ограничена числом $C$, то она стремится к $C$*». Нет. $\frac{n}{n + 1} < 2$ при всех $n$, а предел равен $1$. Предел монотонной последовательности — *наименьшая* из её верхних границ, а не любая из них. Из $a_n < C$ следует только $\lim a_n \le C$ (следствие [-@cor:lec04:bound-limit]).
:::

::: {.remark #rem:lec05:weierstrass-limits tag="подводный камень"}
Обе гипотезы теоремы нужны: $(-1)^n$ ограничена, но не монотонна и расходится (замечание [-@rem:lec03:bounded-not-convergent]); $n$ монотонна, но не ограничена и стремится к $+\infty$. Кроме того, теорема доказывает существование предела, но не сообщает его значения: в примере [-@ex:lec05:heron] значение пришлось находить отдельно. И теорема держится на аксиоме непрерывности: в $\Q$ та же последовательность $(x_n)$ монотонна, ограничена и не сходится.
:::

Теорема Вейерштрасса — основной способ доказать, что предел существует, когда его значение неизвестно. Сейчас она даст число $e$, а в лекции 6 на ней построится теорема Больцано–Вейерштрасса.

## Рекуррентные последовательности (метод, разобранный на семинаре) {#sec:lec05:recurrent}

Предел рекуррентной последовательности $x_{n+1} = f(x_n)$ обычно находят так: сначала доказывают существование по теореме Вейерштрасса, а потом переходят к пределу в рекуррентном соотношении. Минимальный пример — целиком.

::: {.example #ex:lec05:recurrent}
Докажем, что последовательность $x_1 = 13$, $x_{n+1} = \sqrt{12 + x_n}$ сходится, и найдём её предел.

*Ответ:* $4$.

*Решение.* *Шаг 1: кандидат.* Если предел $L$ существует, то, переходя к пределу в равенстве $x_{n+1}^2 = 12 + x_n$, получим $L^2 = 12 + L$, то есть $L = 4$ или $L = -3$. Первые члены $13$, $5$, $\sqrt{17} \approx 4{,}12$ убывают к $4$.

*Шаг 2: ограниченность* — по индукции: $x_n > 4$ при всех $n$. База: $x_1 = 13 > 4$. Переход: если $x_n > 4$, то $x_{n+1} = \sqrt{12 + x_n} > \sqrt{16} = 4$.

*Шаг 3: монотонность.* Обе части неравенства $x_{n+1} < x_n$ положительны, поэтому оно равносильно $12 + x_n < x_n^2$, то есть $(x_n - 4)(x_n + 3) > 0$, а это верно при $x_n > 4$. Значит, $(x_n)$ убывает.

*Шаг 4: предел.* По следствию [-@cor:lec05:weierstrass-dec] $x_n \to L$. Тогда $x_{n+1} \to L$ (утверждение [-@prop:lec03:finite-change]), и в равенстве $x_{n+1}^2 = 12 + x_n$ левая часть стремится к $L^2$, правая — к $12 + L$ (теоремы [-@thm:lec04:product], [-@thm:lec03:sum]). По единственности предела $L^2 = 12 + L$. Из $x_n > 4$ следует $L \ge 4$ (следствие [-@cor:lec04:bound-limit]), поэтому $L = 4$.
:::

Схема в общем виде:

1. найти кандидатов в предел из уравнения $L = f(L)$ — это необходимое условие, если предел существует;
2. сравнив $x_1$ с кандидатом, угадать направление монотонности и доказать по индукции оценку $x_n < L$ или $x_n > L$;
3. доказать монотонность, сводя $x_{n+1} \gtrless x_n$ к уже доказанной оценке;
4. по теореме Вейерштрасса предел существует; перейти к пределу в рекуррентном соотношении и выбрать корень с помощью оценок из шага 2.

Возведение в квадрат в шаге 4 позволяет не доказывать, что $\sqrt{y_n} \to \sqrt{y}$ (это верно, см. утверждение [-@prop:lec05:root] ниже, но здесь не нужно).

::: {.remark #rem:lec05:recurrent-trap tag="подводный камень"}
Уравнение $L = f(L)$ находит предел, только если он существует. Для $x_1 = 2$, $x_{n+1} = x_n^2$ уравнение $L = L^2$ даёт $L \in \{0, 1\}$, а на самом деле $x_n = 2^{2^{n-1}} \to +\infty$. Для $x_1 = 0$, $x_{n+1} = 1 - x_n$ уравнение даёт $L = \frac12$, а последовательность $0, 1, 0, 1, \dots$ расходится. Поэтому шаги 2–3 нельзя пропускать.
:::

## Число $e$ {#sec:lec05:e}

::: {.theorem #thm:lec05:e title="о числе $e$"}
Последовательность $a_n = \left(1 + \frac1n\right)^n$ сходится.
:::

::: proof
*Идея:* последовательность возрастает и ограничена сверху, остаётся применить теорему Вейерштрасса.

*Возрастание.* Все члены положительны, поэтому достаточно доказать $\frac{a_{n+1}}{a_n} > 1$. Так как $n(n + 2) = (n + 1)^2 - 1$,
$$\frac{a_{n+1}}{a_n} = \left(\frac{n+2}{n+1}\right)^{n+1} \left(\frac{n}{n+1}\right)^n = \frac{n+2}{n+1} \left(\frac{n(n+2)}{(n+1)^2}\right)^n = \frac{n+2}{n+1} \left(1 - \frac{1}{(n+1)^2}\right)^n.$$
*Ключ:* к последнему множителю применим неравенство Бернулли (теорема [-@thm:lec01:bernoulli]) с $x = -\frac{1}{(n+1)^2} \ge -1$:
$$\frac{a_{n+1}}{a_n} \ge \frac{n+2}{n+1} \left(1 - \frac{n}{(n+1)^2}\right) = \frac{(n+2)(n^2 + n + 1)}{(n+1)^3} = \frac{n^3 + 3n^2 + 3n + 2}{n^3 + 3n^2 + 3n + 1} > 1.$$

*Ограниченность.* В задаче [-@prob:lec02:e-bounded] доказано, что $a_n < 3$ при всех $n$: по биному $a_n = \sum_{k=0}^{n} C_n^k \frac{1}{n^k}$, каждое слагаемое не больше $\frac{1}{k!}$, а $\frac{1}{k!} \le \frac{1}{(k-1)k}$ при $k \ge 2$, и телескопическая сумма даёт $a_n \le 3 - \frac1n$.

По теореме [-@thm:lec05:weierstrass] последовательность сходится.
:::

::: {.definition #def:lec05:e title="число $e$"}
$$e = \lim_{n \to \infty} \left(1 + \frac1n\right)^n.$$
:::

  \addplot[densely dotted, nbgray, thick, domain=0:13] {3};
  \addplot[densely dashed, nbgreen!60!black, thick, domain=0:13] {2.71828};
  \addplot[only marks, mark=*, mark size=2pt, nbblue, samples at={1,...,12}] {(1 + 1/x)^x};

Из доказательства получаем оценки. Последовательность возрастает и стремится к своему супремуму, поэтому $a_n < a_{n+1} \le e$ при всех $n$; в частности, $e \ge a_2 = \frac94$. Из $a_n < 3$ следует $e \le 3$ (следствие [-@cor:lec04:bound-limit]). На самом деле $e = 2{,}71828\ldots$ и это иррациональное число (без доказательства). Число $e$ — основание натурального логарифма; оно появится в показательной функции и в производных.

::: {.remark #rem:lec05:one-infinity title="неопределённость $1^\infty$"}
Выражение $(1 + \alpha_n)^{k_n}$, где $\alpha_n \to 0$, а $k_n \to +\infty$, — неопределённость вида $1^\infty$: основание стремится к $1$, но показатель растёт, и ответ зависит от того, кто «быстрее»:
$$\left(1 + \frac1n\right)^n \to e, \qquad \left(1 + \frac{1}{n^2}\right)^n \to 1, \qquad \left(1 + \frac1n\right)^{n^2} \to +\infty.$$
Второй предел: $1 \le \left(1 + \frac{1}{n^2}\right)^n$, а $n$-я степень этого числа равна $a_{n^2} < 3$, поэтому $\left(1 + \frac{1}{n^2}\right)^n < \sqrt[n]{3} \to 1$, и работает теорема о двух милиционерах. Третий: $\left(1 + \frac1n\right)^{n^2} = a_n^n \ge 2^n$, и по замечанию [-@rem:lec04:one-policeman] он равен $+\infty$. Рассуждение «основание стремится к $1$, а $1^n = 1$» неверно (замечание [-@rem:lec04:drop-terms]).
:::

## Подпоследовательности {#sec:lec05:subsequences}

Расходимость $(-1)^n$ в лекции 3 доказывалась перебором всех возможных пределов $a$ (пример [-@ex:lec03:minus-one]). Короче посмотреть отдельно на члены с чётными и с нечётными номерами: первые все равны $1$, вторые все равны $-1$. Такие «прореженные» последовательности называются подпоследовательностями.

::: {.definition #def:lec05:subsequence title="подпоследовательность"}
*Подпоследовательностью* последовательности $(a_n)_{n \in \N}$ называется последовательность $(b_k)_{k \in \N}$ вида $b_k = a_{n_k}$, где $n_1 < n_2 < n_3 < \dots$ — строго возрастающая последовательность натуральных номеров. Обозначение: $(a_{n_k})$.
:::

То есть из последовательности выбирают бесконечно много членов, сохраняя их порядок и не повторяя (рис. [-@fig:lec05:subsequence]).

::: {.example #ex:lec05:subsequences}
Какие из последовательностей — подпоследовательности $(a_n)$: (a) $a_2, a_4, a_6, \dots$; (b) $a_1, a_3, a_5, \dots$; (c) $a_4, a_2, a_8, a_6, \dots$; (d) $a_1, a_1, a_2, a_2, \dots$?

*Ответ:* (a) и (b) — да; (c) и (d) — нет.

*Решение.* (a) $n_k = 2k$; (b) $n_k = 2k - 1$; обе последовательности номеров строго возрастают. (c) $n_1 = 4 > n_2 = 2$ — порядок нарушен. (d) $n_1 = n_2 = 1$ — член выбран дважды. Для $a_n = n^{(-1)^n}$, то есть $1, \frac12, 3, \frac14, 5, \frac16, \dots$, подпоследовательность (a) — это $\frac12, \frac14, \frac16, \dots$, она стремится к $0$, хотя сама последовательность не ограничена. Сама $(a_n)$ — своя подпоследовательность ($n_k = k$), «хвост» $a_6, a_7, \dots$ — тоже ($n_k = k + 5$).
:::

```{.tikz #fig:lec05:subsequence caption="Подпоследовательность $b_k = a_{n_k}$ с номерами $n_1 = 2$, $n_2 = 3$, $n_3 = 5$, $n_4 = 8$: выбранные члены идут в исходном порядке без повторов. Член $b_k$ стоит под $a_{n_k}$, и $k$-й выбранный член не может оказаться левее $k$-го места, поэтому $n_k \\ge k$"}
\begin{tikzpicture}[x=1.15cm, y=1.1cm]
  \foreach \i in {1,...,9} { \node[font=\scriptsize, nbgray] at (\i,1.75) {$\i$}; \node[font=\small] (a\i) at (\i,1) {$a_{\i}$}; }
  \node[font=\small] at (10,1) {$\dots$};
  \foreach \k/\n in {1/2,2/3,3/5,4/8} {
    \draw[nbred, thick] (a\n) circle (0.3cm);
    \node[font=\small, nbred] (b\k) at (\n,0) {$b_{\k}$};
    \draw[<-, nbred] (b\k) -- (\n,0.68);
  }
  \node[font=\small, nbred] at (10,0) {$\dots$};
  \node[font=\small, anchor=east, nbgray] at (0.5,1.75) {номер $n$:};
  \node[font=\small, anchor=east] at (0.5,1) {$(a_n)$:};
  \node[font=\small, anchor=east, nbred] at (0.5,0) {$(b_k)$:};

```

::: {.lemma #lem:lec05:nk title="номера подпоследовательности"}
Если $n_1 < n_2 < n_3 < \dots$ — натуральные числа, то $n_k \ge k$ при всех $k \in \N$.
:::

::: proof
Индукция по $k$. База: $n_1 \ge 1$, так как $n_1 \in \N$. Переход: если $n_k \ge k$, то $n_{k+1} > n_k \ge k$, а $n_{k+1}$ — целое, поэтому $n_{k+1} \ge k + 1$.
:::

::: {.proposition #prop:lec05:subseq-limit title="предел подпоследовательности"}
Если $a_n \to a$, то любая подпоследовательность $a_{n_k} \to a$ при $k \to \infty$.
:::

::: proof
Пусть $\varepsilon > 0$ и $N$ таков, что $a_n \in U_\varepsilon(a)$ при всех $n > N$. Хотим найти $K$, для которого $a_{n_k} \in U_\varepsilon(a)$ при $k > K$. Возьмём $K = N$: при $k > K$ по лемме [-@lem:lec05:nk] $n_k \ge k > N$, поэтому $a_{n_k} \in U_\varepsilon(a)$.
:::

То же доказательство дословно работает для бесконечных пределов: если $a_n \to +\infty$, то и $a_{n_k} \to +\infty$. Например, $\left(1 + \frac{1}{2k}\right)^{2k} \to e$ и $\left(1 + \frac{1}{k^2}\right)^{k^2} \to e$ — это подпоследовательности $(a_n)$ из теоремы [-@thm:lec05:e] с номерами $n_k = 2k$ и $n_k = k^2$.

::: {.corollary #cor:lec05:divergence title="расходимость через подпоследовательности"}
Если у $(a_n)$ есть расходящаяся подпоследовательность или две подпоследовательности с разными пределами, то $(a_n)$ расходится.
:::

::: proof
Если бы $a_n \to a$, то по утверждению [-@prop:lec05:subseq-limit] все подпоследовательности стремились бы к одному числу $a$.
:::

Для $(-1)^n$: $a_{2k} = 1 \to 1$, $a_{2k-1} = -1 \to -1$, пределы разные, значит, $(-1)^n$ расходится. Сравните с перебором всех $a$ в примере [-@ex:lec03:minus-one]: подпоследовательности дают доказательство в одну строку. Для доказательства расходимости это обычно самый короткий путь.

::: {.remark #rem:lec05:subseq-converse tag="подводный камень"}
Обратное к утверждению [-@prop:lec05:subseq-limit] неверно: из сходимости одной подпоследовательности сходимость последовательности не следует — у $(-1)^n$ подпоследовательность $a_{2k}$ сходится. Не следует она и из сходимости бесконечного числа подпоследовательностей: у $(-1)^n$ сходятся все $a_{2k}$, $a_{4k}$, $a_{6k}$, … Но если подпоследовательности чётных и нечётных членов сходятся к *одному и тому же* числу, то сходится и вся последовательность (задача [-@prob:lec05:even-odd]): эти две подпоследовательности вместе исчерпывают все номера.
:::

## Пределы вида $1^\infty$ (метод, разобранный на семинаре) {#sec:lec05:e-limits}

Неопределённость $1^\infty$ раскрывают, сводя выражение к $\left(1 + \frac1n\right)^n$ с помощью подпоследовательностей, арифметики предела и двух утверждений ниже.

::: {.proposition #prop:lec05:e-power title="пределы $\left(1 \pm \frac kn\right)^n$"}
Для любого $k \in \N$
$$\left(1 + \frac kn\right)^n \to e^k, \qquad \left(1 - \frac kn\right)^n \to e^{-k}.$$
:::

::: proof
*Идея:* $1 + \frac kn$ раскладывается в телескопическое произведение $k$ множителей вида $1 + \frac{1}{n + j}$, каждый из которых после возведения в степень $n$ стремится к $e$.

Так как $\prod_{j=0}^{k-1} \frac{n + j + 1}{n + j} = \frac{n + k}{n} = 1 + \frac kn$, имеем
$$\left(1 + \frac kn\right)^n = \prod_{j=0}^{k-1} \left(1 + \frac{1}{n + j}\right)^n, \qquad \left(1 + \frac{1}{n + j}\right)^n = \frac{\left(1 + \frac{1}{n + j}\right)^{n + j}}{\left(1 + \frac{1}{n + j}\right)^j}.$$
При фиксированном $j$ числитель — сдвиг последовательности из теоремы [-@thm:lec05:e] на $j$ номеров, он стремится к $e$ (утверждение [-@prop:lec03:finite-change]); знаменатель — произведение $j$ множителей, стремящихся к $1$, он стремится к $1$ (теорема [-@thm:lec04:product]). По теореме [-@thm:lec04:quotient] каждый из $k$ множителей стремится к $e$, а произведение — к $e^k$.

Для второго предела при $n > k$ перемножим:
$$\left(1 - \frac kn\right)^n \left(1 + \frac kn\right)^n = \left(1 - \frac{k^2}{n^2}\right)^n, \qquad 1 \ge \left(1 - \frac{k^2}{n^2}\right)^n \ge 1 - \frac{k^2}{n}$$
по неравенству Бернулли ($-\frac{k^2}{n^2} \ge -1$ при $n > k$). По теореме о двух милиционерах $\left(1 - \frac{k^2}{n^2}\right)^n \to 1$, и $\left(1 - \frac kn\right)^n = \left(1 - \frac{k^2}{n^2}\right)^n \Big/ \left(1 + \frac kn\right)^n \to \frac{1}{e^k}$.
:::

Например, $\left(1 + \frac2n\right)^n \to e^2 \approx 7{,}39$, $\left(1 - \frac1n\right)^n \to \frac1e$.

Если после преобразований основание имеет вид $1 + \frac{c}{m}$, а показатель — $\frac{m}{2}$ или $\frac{m}{3}$, удобно возвести выражение в квадрат или куб и потом извлечь корень. Для этого нужен факт о корнях.

::: {.proposition #prop:lec05:root title="предел корня"}
Если $y_n \ge 0$ и $y_n \to y$, то $\sqrt[k]{y_n} \to \sqrt[k]{y}$ для любого $k \in \N$.
:::

::: proof
По следствию [-@cor:lec04:bound-limit] $y \ge 0$. Если $y = 0$, то $\sqrt[k]{y_n} < \varepsilon$ равносильно $y_n < \varepsilon^k$, а это верно при $n > N(\varepsilon^k)$. Пусть $y > 0$, $u = \sqrt[k]{y_n}$, $v = \sqrt[k]{y} > 0$. Из $u^k - v^k = (u - v)(u^{k-1} + u^{k-2} v + \dots + v^{k-1})$ и того, что вторая скобка не меньше $v^{k-1} > 0$, получаем
$$\left|\sqrt[k]{y_n} - \sqrt[k]{y}\right| \le \frac{|y_n - y|}{v^{k-1}}.$$
Правая часть меньше $\varepsilon$ при $n > N(\varepsilon v^{k-1})$.
:::

::: {.example #ex:lec05:e-limit}
Найдём $\lim\limits_{n \to \infty} \left(\dfrac{2n + 3}{2n - 1}\right)^n$.

*Ответ:* $e^2$.

*Решение.* Основание $\frac{2n + 3}{2n - 1} = 1 + \frac{4}{2n - 1} \to 1$, показатель растёт — неопределённость $1^\infty$. *Ключ:* обозначить $m = 2n - 1$ и возвести в квадрат, чтобы показатель стал целым кратным $m$:
$$b_n^2 = \left(1 + \frac4m\right)^{2n} = \left(1 + \frac4m\right)^{m} \left(1 + \frac4m\right), \quad m = 2n - 1.$$
Последовательность $c_m = \left(1 + \frac4m\right)^{m + 1}$ стремится к $e^4 \cdot 1$ (утверждение [-@prop:lec05:e-power]), а $b_n^2 = c_{2n-1}$ — её подпоследовательность с номерами $m_n = 2n - 1$, поэтому $b_n^2 \to e^4$ (утверждение [-@prop:lec05:subseq-limit]). Так как $b_n > 0$, по утверждению [-@prop:lec05:root] $b_n \to \sqrt{e^4} = e^2$.
:::

Так же $\left(1 + \frac{1}{kn}\right)^n \to \sqrt[k]{e}$: $k$-я степень этого выражения равна $\left(1 + \frac{1}{kn}\right)^{kn}$ — подпоследовательность $(a_m)$ с номерами $m = kn$.

::: {.remark #rem:lec05:no-real-powers}
Хочется написать $\left(1 + \frac{4}{2n - 1}\right)^n = \left(\left(1 + \frac{4}{2n-1}\right)^{\frac{2n - 1}{4}}\right)^{\frac{4n}{2n - 1}}$ и сослаться на то, что внутренняя скобка стремится к $e$, а показатель к $2$. Но здесь показатели нецелые, а утверждения о пределе $x_n^{y_n}$ у нас пока нет: его можно будет доказать после того, как появятся показательная функция и логарифм. Пока работаем только с целыми степенями, корнями и подпоследовательностями.
:::

# Практика

## Точные грани

::: {.problem #prob:lec05:sup-running}
Найдите $\sup X$ и $\inf X$, где $X = \left\{1 + \frac{(-1)^n}{n} \mid n \in \N\right\}$.
:::

::: answer
$\sup X = \frac32 = \max X$, $\inf X = 0 = \min X$.
:::

::: solution
Члены с чётными номерами равны $1 + \frac1n \le 1 + \frac12 = \frac32$ (так как $n \ge 2$), с нечётными — $1 - \frac1n < 1$. Значит, все элементы не больше $\frac32$, и $\frac32 = x_2 \in X$ — наибольший элемент, он же супремум (утверждение [-@prop:lec05:max]). Снизу: нечётные члены $1 - \frac1n \ge 0$, чётные больше $1$; значение $0 = x_1$ достигается. *Ключ:* если кандидат достигается, вторую часть проверки (через $\varepsilon$) делать не нужно.
:::

::: {.problem #prob:lec05:sup-two}
Найдите супремум и инфимум множества $\left\{\dfrac{m}{n + m} \mid m, n \in \N\right\}$. Ответ обоснуйте.
:::

::: answer
$\sup = 1$, $\inf = 0$; ни одно из них не достигается.
:::

::: solution
Все элементы лежат в $(0; 1)$, так как $0 < m < n + m$. Значит, $1$ — верхняя грань, $0$ — нижняя, и обе не принадлежат множеству. *Ключ:* фиксируем один параметр и устремляем другой. Пусть $\varepsilon > 0$. При $n = 1$ элемент $\frac{m}{m + 1} = 1 - \frac{1}{m + 1}$ больше $1 - \varepsilon$, если $m + 1 > \frac1\varepsilon$, например при $m = \left[\frac1\varepsilon\right]$ (при $\varepsilon \ge 1$ возьмём $m = 1$). При $m = 1$ элемент $\frac{1}{n + 1} < \varepsilon$, если $n = \left[\frac1\varepsilon\right] + 1$. По утверждению [-@prop:lec05:sup-eps] $\sup = 1$, $\inf = 0$.
:::

::: {.problem #prob:lec05:sup-constrained}
Найдите супремум и инфимум множеств
$$\text{(a) } X = \left\{\frac{1 + m}{3 + 2n} \mid m, n \in \N,\ m \le n\right\}; \qquad \text{(b) } Y = \left\{\frac{1 + m}{1 + 2n} \mid m, n \in \N,\ m \le n\right\}.$$
:::

::: answer
(a) $\sup X = \frac12$, $\inf X = 0$, оба не достигаются; (b) $\sup Y = \frac23 = \max Y$ (при $m = n = 1$), $\inf Y = 0$ не достигается.
:::

::: solution
*Ключ:* при фиксированном $n$ дробь растёт с ростом $m$, поэтому наибольший элемент «строки» $n$ получается при $m = n$, наименьший — при $m = 1$; дальше исследуем зависимость от $n$.

(a) Сверху: $\frac{1 + m}{3 + 2n} \le \frac{1 + n}{3 + 2n} = \frac12 - \frac{1}{2(3 + 2n)} < \frac12$. При $m = n$ элемент $\frac12 - \frac{1}{2(3 + 2n)} > \frac12 - \varepsilon$, как только $3 + 2n > \frac{1}{2\varepsilon}$. Снизу: все элементы положительны, а при $m = 1$ элемент $\frac{2}{3 + 2n} < \frac1n < \varepsilon$ при $n > \frac1\varepsilon$.

(b) Сверху: $\frac{1 + m}{1 + 2n} \le \frac{1 + n}{1 + 2n}$, и $\frac{1 + n}{1 + 2n} \le \frac23 \Leftrightarrow 3 + 3n \le 2 + 4n \Leftrightarrow n \ge 1$. Значение $\frac23$ достигается при $m = n = 1$, поэтому это наибольший элемент. Снизу — как в (a): элементы положительны, при $m = 1$ элемент $\frac{2}{1 + 2n} < \frac1n$.
:::

## Монотонные и рекуррентные последовательности

::: {.problem #prob:lec05:kr-recurrent}
Последовательность задана рекуррентно: $x_1 = 3$, $x_{n+1} = \sqrt{2 + 3x_n}$. Докажите, что она сходится, и найдите её предел.
:::

::: answer
$\dfrac{3 + \sqrt{17}}{2} \approx 3{,}56$.
:::

::: solution
*Кандидат:* $L = \sqrt{2 + 3L}$ даёт $L^2 - 3L - 2 = 0$, корни $\frac{3 \pm \sqrt{17}}{2}$; положительный $L = \frac{3 + \sqrt{17}}{2}$. Так как $x_1 = 3 < L$, ожидаем возрастание.

*Оценка* $0 < x_n < L$ — по индукции: $x_1 = 3 < L$; если $0 < x_n < L$, то $0 < x_{n+1} = \sqrt{2 + 3x_n} < \sqrt{2 + 3L} = \sqrt{L^2} = L$.

*Монотонность.* *Ключ:* неравенство $x_{n+1} > x_n$ после возведения в квадрат сводится к оценке: $2 + 3x_n > x_n^2 \Leftrightarrow x_n^2 - 3x_n - 2 < 0 \Leftrightarrow \frac{3 - \sqrt{17}}{2} < x_n < L$, а это верно, так как $0 < x_n < L$.

*Предел.* По теореме Вейерштрасса $x_n \to L'$, и из $x_{n+1}^2 = 2 + 3x_n$ получаем $L'^2 = 2 + 3L'$. Поскольку $x_n \ge 3$, имеем $L' \ge 3$, и $L' = L$.
:::

::: {.problem #prob:lec05:three-starts}
Докажите, что последовательность $x_{n+1} = \frac43 x_n - x_n^2$ сходится, и найдите её предел в трёх случаях: (a) $x_1 = \frac16$; (b) $x_1 = \frac12$; (c) $x_1 = \frac76$.
:::

::: answer
Во всех трёх случаях предел равен $\frac13$.
:::

::: solution
Пусть $f(x) = \frac43 x - x^2$. Кандидаты: $L = f(L) \Leftrightarrow L^2 = \frac L3 \Leftrightarrow L \in \left\{0, \frac13\right\}$. *Ключ:* две тождественные формулы
$$f(x) - x = x\left(\frac13 - x\right), \qquad \frac13 - f(x) = \left(x - \frac13\right)(x - 1)$$
показывают, куда $f$ переводит промежутки $\left(0; \frac13\right)$ и $\left(\frac13; 1\right)$.

Если $x \in \left(0; \frac13\right)$, то $f(x) > x > 0$ и $f(x) < \frac13$: оба множителя во второй формуле отрицательны. Значит, последовательность, попавшая в $\left(0; \frac13\right)$, остаётся в нём и возрастает.

Если $x \in \left(\frac13; 1\right)$, то $f(x) < x < 1$ и $f(x) > \frac13$. Последовательность, попавшая в $\left(\frac13; 1\right)$, остаётся в нём и убывает.

Случай (a): $x_1 = \frac16 \in \left(0; \frac13\right)$, последовательность возрастает, ограничена числом $\frac13$, сходится к $L \in \left\{0, \frac13\right\}$ с $L \ge \frac16$, то есть к $\frac13$. (b) $x_1 = \frac12 \in \left(\frac13; 1\right)$: убывает, ограничена снизу числом $\frac13$, предел $L \ge \frac13$, то есть $\frac13$. (c) $x_2 = f\left(\frac76\right) = \frac76 \cdot \frac16 = \frac{7}{36} \in \left(0; \frac13\right)$; начиная со второго члена последовательность возрастает и ограничена, по утверждению [-@prop:lec03:finite-change] и теореме Вейерштрасса она сходится, и, как в (a), к $\frac13$. Случай (c) показывает, что монотонность может начинаться не с первого члена.
:::

## Число $e$ и неопределённость $1^\infty$

::: {.problem #prob:lec05:kr-e}
Вычислите $\lim\limits_{n \to \infty} \dfrac{\sqrt[n]{4n} + \left(\frac{2n}{2n - 3}\right)^{n+1}}{3\sqrt[n]{4} - 2}$.
:::

::: answer
$1 + e^{3/2}$.
:::

::: solution
Знаменатель $3\sqrt[n]{4} - 2 \to 3 - 2 = 1 \ne 0$ и положителен; $\sqrt[n]{4n} = \sqrt[n]{4} \cdot \sqrt[n]{n} \to 1$ (утверждение [-@prop:lec04:standard]). Остаётся $b_n = \left(\frac{2n}{2n - 3}\right)^{n+1} = \left(1 + \frac{3}{2n - 3}\right)^{n+1}$ при $n \ge 2$. *Ключ:* возвести в квадрат и положить $m = 2n - 3$; тогда $2n + 2 = m + 5$ и
$$b_n^2 = \left(1 + \frac3m\right)^{m + 5} = \left(1 + \frac3m\right)^{m} \left(1 + \frac3m\right)^5.$$
Последовательность $c_m = \left(1 + \frac3m\right)^{m+5}$ стремится к $e^3$ (утверждение [-@prop:lec05:e-power]), $b_n^2 = c_{2n - 3}$ — её подпоследовательность ($m = 1, 3, 5, \dots$), поэтому $b_n^2 \to e^3$, а $b_n \to e^{3/2}$ по утверждению [-@prop:lec05:root]. Числитель стремится к $1 + e^{3/2}$, знаменатель — к $1$.
:::

::: {.problem #prob:lec05:e-limits}
Найдите пределы: (a) $\left(\dfrac{n - 1}{n + 1}\right)^{n^2}$; (b) $\left(\dfrac{n^2 + 1}{n^2 - 2}\right)^{n^2}$; (c) $\left(1 - \dfrac{1}{2n}\right)^{n}$.
:::

::: answer
(a) $0$; (b) $e^3$; (c) $e^{-1/2} = \frac{1}{\sqrt e}$.
:::

::: solution
(a) Основание $1 - \frac{2}{n + 1} \in (0; 1)$ при $n \ge 2$. Последовательность $d_n = \left(1 - \frac{2}{n + 1}\right)^{n + 1}$ — сдвиг $\left(1 - \frac2m\right)^m$, она стремится к $e^{-2} < \frac14$ (так как $e > 2$), поэтому $d_n < \frac12$ при $n > N$. *Ключ:* при основании из $(0; 1)$ степень убывает с ростом показателя, а $n^2 \ge (n + 1)(n - 1)$. Значит, при $n > N$
$$0 < \left(\frac{n - 1}{n + 1}\right)^{n^2} \le d_n^{\,n - 1} < \left(\frac12\right)^{n - 1} \to 0.$$

(b) Основание $1 + \frac{3}{n^2 - 2}$; при $n \ge 2$ положим $m = n^2 - 2$, тогда $n^2 = m + 2$, и выражение равно $c_m = \left(1 + \frac3m\right)^{m + 2}$ с номерами $m = 2, 7, 14, \dots$ — строго возрастающими. Так как $c_m \to e^3$, подпоследовательность тоже стремится к $e^3$.

(c) Квадрат выражения равен $\left(1 - \frac{1}{2n}\right)^{2n}$ — подпоследовательность $\left(1 - \frac1m\right)^m \to e^{-1}$ с номерами $m = 2n$. По утверждению [-@prop:lec05:root] предел равен $\sqrt{e^{-1}}$.
:::

## Подпоследовательности

::: {.problem #prob:lec05:even-odd}
Пусть $a_{2k} \to a$ и $a_{2k-1} \to a$ при $k \to \infty$. Докажите, что $a_n \to a$.
:::

::: answer
Если $K_1(\varepsilon)$, $K_2(\varepsilon)$ — номера для чётной и нечётной подпоследовательностей, то для $(a_n)$ годится $N = \max(2K_1, 2K_2 - 1)$.
:::

::: solution
Пусть $\varepsilon > 0$, $|a_{2k} - a| < \varepsilon$ при $k > K_1$ и $|a_{2k-1} - a| < \varepsilon$ при $k > K_2$. Возьмём $n > N = \max(2K_1, 2K_2 - 1)$. Если $n = 2k$, то $2k > 2K_1$, то есть $k > K_1$. Если $n = 2k - 1$, то $2k - 1 > 2K_2 - 1$, то есть $k > K_2$. В обоих случаях $|a_n - a| < \varepsilon$. *Ключ:* каждый номер $n$ — либо чётный, либо нечётный, поэтому две подпоследовательности покрывают всю последовательность.
:::

# Итоги

- В $\Q$ монотонная ограниченная последовательность может не иметь предела (рекуррентное приближение к $\sqrt2$); в $\R$ это исключает аксиома непрерывности — «между множеством слева и множеством справа есть число».
- Непустое ограниченное сверху множество имеет супремум — наименьшую верхнюю грань; он может не принадлежать множеству ($\sup(0; 1) = 1$), а у пустого множества его нет, потому что верхней гранью $\varnothing$ служит любое число.
- $s = \sup A$ проверяют в две части: $a \le s$ для всех $a \in A$, и для каждого $\varepsilon > 0$ есть элемент больше $s - \varepsilon$; одной верхней границы мало.
- Неубывающая ограниченная сверху последовательность сходится к своему супремуму, а не к произвольной верхней границе; без монотонности ($(-1)^n$) или без ограниченности ($n$) вывод неверен.
- Рекуррентную последовательность сначала исследуют на монотонность и ограниченность, и только потом ищут предел из уравнения $L = f(L)$: для $x_{n+1} = x_n^2$, $x_1 = 2$ уравнение даёт $0$ и $1$, а предел равен $+\infty$.
- $e = \lim\left(1 + \frac1n\right)^n$ существует, потому что последовательность возрастает (Бернулли для отношения соседних членов) и меньше $3$ (бином); $\left(1 + \frac kn\right)^n \to e^k$.
- Все подпоследовательности сходящейся последовательности имеют тот же предел, поэтому две подпоследовательности с разными пределами доказывают расходимость.

# Глоссарий

Аксиома непрерывности
:   если непустые $A, B \subseteq \R$ и $a \le b$ для всех $a \in A$, $b \in B$, то есть $c$ с $a \le c \le b$ для всех таких $a$, $b$; [-@ax:lec05:continuity].

Ограниченное сверху (снизу) множество
:   $\exists C\ \forall a \in A\colon a \le C$ (соответственно $a \ge C$); [-@def:lec05:bounded-set].

Верхняя грань множества
:   число $c$ с $c \ge a$ для всех $a \in A$; [-@def:lec05:upper-bound].

$\sup A$, точная верхняя грань, супремум
:   наименьшая из верхних граней множества $A$; [-@def:lec05:sup].

$\inf A$, точная нижняя грань, инфимум
:   наибольшая из нижних граней множества $A$; [-@def:lec05:inf].

$\sup a_n$, $\inf a_n$
:   супремум и инфимум множества значений $\{a_n \mid n \in \N\}$; [-@cor:lec05:inf-exists].

Теорема Вейерштрасса
:   неубывающая ограниченная сверху последовательность сходится к своему супремуму; [-@thm:lec05:weierstrass].

$e$
:   $\lim\limits_{n \to \infty} \left(1 + \frac1n\right)^n \approx 2{,}718$; [-@def:lec05:e].

Неопределённость $1^\infty$
:   выражение $(1 + \alpha_n)^{k_n}$ с $\alpha_n \to 0$, $k_n \to +\infty$; [-@rem:lec05:one-infinity].

Подпоследовательность, $(a_{n_k})$
:   последовательность $b_k = a_{n_k}$, где $n_1 < n_2 < \dots$; [-@def:lec05:subsequence].

# Самопроверка

1. Запишите кванторами, что множество $A$ *не* ограничено сверху. Ограничено ли сверху пустое множество? Есть ли у него супремум?
2. Покажите, что аксиома непрерывности с условием $a < c < b$ вместо $a \le c \le b$ неверна.
3. Найдите $\sup$ и $\inf$ множества $\left\{(-1)^n + \frac1n \mid n \in \N\right\}$. Достигаются ли они?
4. Верно ли: (a) если $s$ — верхняя грань $A$ и $s \in A$, то $s = \sup A$; (b) если $a < s$ для всех $a \in A$, то $s \ne \sup A$?
5. Докажите, что последовательность $x_1 = \sqrt5$, $x_{n+1} = \sqrt{5x_n}$ сходится, и найдите её предел.
6. Студент ищет предел последовательности $x_1 = 1$, $x_{n+1} = 2x_n$ из уравнения $L = 2L$ и получает $L = 0$. В чём ошибка?
7. Последовательность возрастает, и все её члены меньше $10$. Что можно сказать о её пределе?
8. Найдите $\lim\left(1 + \frac1n\right)^{3n}$, $\lim\left(1 - \frac3n\right)^n$, $\lim\left(1 + \frac{1}{n + 5}\right)^n$.
9. Является ли $a_3, a_5, a_4, a_7, a_9, \dots$ подпоследовательностью $(a_n)$? Докажите с помощью подпоследовательностей, что $a_n = \sin\frac{\pi n}{2} + \frac1n$ расходится.
10. Найдите ошибку: «$1 + \frac1n \to 1$, а $1^n = 1$, поэтому $\left(1 + \frac1n\right)^n \to 1$».
11. Докажите, что $\left(1 + \frac1n\right)^n < e$ при всех $n \in \N$.

::: answers
1. $\forall C \in \R\ \exists a \in A\colon a > C$. Пустое множество ограничено сверху (любым $C$), но супремума у него нет: любое число — его верхняя грань, наименьшей нет (замечание [-@rem:lec05:sup-empty]).
2. Для $A = [0; 1]$, $B = [1; 2]$ условие выполнено, но $c$ с $a < c < b$ при $a = 1 \in A$, $b = 1 \in B$ не существует.
3. $\sup = \frac32$ (достигается при $n = 2$); $\inf = -1$, не достигается: нечётные члены $-1 + \frac1n > -1$ и меньше $-1 + \varepsilon$ при $n > \frac1\varepsilon$, чётные больше $1$.
4. (a) Верно: $s$ — наибольший элемент (утверждение [-@prop:lec05:max]). (b) Неверно: $A = (0; 1)$, $s = 1$.
5. Предел $5$: по индукции $0 < x_n < 5$ ($\sqrt{5x_n} < \sqrt{25}$), $x_{n+1} > x_n \Leftrightarrow 5x_n > x_n^2 \Leftrightarrow x_n < 5$; по Вейерштрассу $x_n \to L$, $L^2 = 5L$, $L \ge \sqrt5$, значит, $L = 5$.
6. Уравнение верно лишь при условии, что предел существует; здесь $x_n = 2^{n-1} \to +\infty$ (замечание [-@rem:lec05:recurrent-trap]).
7. Предел существует, равен $\sup a_n$ и удовлетворяет $a_1 < \lim a_n \le 10$; равенство $10$ не обязательно.
8. $e^3$ (произведение трёх множителей $\left(1 + \frac1n\right)^n$); $e^{-3}$ (утверждение [-@prop:lec05:e-power]); $e$: выражение равно $\left(1 + \frac{1}{n+5}\right)^{n+5} \big/ \left(1 + \frac{1}{n+5}\right)^5$, числитель — сдвиг $(a_n)$, знаменатель стремится к $1$.
9. Нет: номера $3, 5, 4$ не возрастают. $a_{4k} = \frac{1}{4k} \to 0$, $a_{4k+1} = 1 + \frac{1}{4k+1} \to 1$, пределы разные (следствие [-@cor:lec05:divergence]).
10. Предел основания нельзя подставлять в степень с растущим показателем: это неопределённость $1^\infty$; на самом деле $\left(1 + \frac1n\right)^n \ge 2$ и стремится к $e$.
11. Последовательность возрастает и сходится к своему супремуму: $a_n < a_{n+1} \le \sup a_k = e$.
:::
