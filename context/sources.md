# Источники

Всё, что используется для генерации конспектов. В репозитории лежат только ссылки: чужие материалы не коммитятся. Агент скачивает нужное в `sources/<course>/…` (папка в `.gitignore`). Список собран из §11 ТЗ (ссылки проверены 14 октября 2026) и дополнен материалами, которые прислали позже. Разбор, какой источник к какой лекции, — в `context/courses/<course>.md`.

## Как доставать

| Тип | Как |
| --- | --- |
| Публичный GitHub-репозиторий | `./scripts/fetch_sources.sh` (git clone через прокси сессии) |
| Google Drive: файл, папка, таблица | Drive-коннектор: `search_files` с `parentId = '<id папки>'` для содержимого папки, `read_file_content` для текста PDF/Docs/Sheets, `download_file_content` для самого файла. Доступ — по правам аккаунта |
| Веб-страница | WebFetch. Если закрыто для автоматического доступа — отметить в отчёте и идти дальше |
| YouTube-запись | субтитры через `uvx yt-dlp --skip-download --write-auto-subs --sub-langs ru …`, если сеть пропускает; иначе ориентироваться на тезисы лектора |
| Google Calendar «Education» | Calendar-коннектор (`list_events`, `search_events`): сверка дат лекций и переносов |

Темы семинарских листков 2026 (из ТЗ):

1. **Формальная логика и математическая индукция.** Истинность логических высказываний, кванторы ∀, ∃, отрицание утверждений, логическая эквивалентность. Индукция: формулы сумм, неравенства, делимость, явные формулы рекуррентных последовательностей.
2. **Бином Ньютона и последовательности.** Конечные суммы (в том числе тригонометрические), бином Ньютона, коэффициенты многочленов. Последовательности с заданными свойствами, ограниченность и неограниченность строго по определениям.
3. **Определение предела последовательности.** ε–N с явным подбором N(ε), доказательство расходимости, порядок кванторов, контрпримеры. Пределы степенных, корневых и рациональных последовательностей.
4. **Бесконечно большие и бесконечно малые последовательности.** Ограниченные и отделимые от нуля последовательности, неопределённости при сложении, умножении и делении, примеры и контрпримеры, свойства арифметических операций, вычисление пределов.
5. **Подсчёт пределов последовательностей.** Арифметика пределов, старшие степени, преобразование корней, сравнение скоростей роста степеней и факториалов, теорема о двух милиционерах. Супремум и инфимум множеств.
6. **Дополнительный файл calculus_1 (7, 8).** Образцы доказательств индукцией: неравенство с экспонентой и многочленом, явная формула рекуррентной последовательности.
