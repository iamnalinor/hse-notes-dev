### Лекция 1 (04.09) — Истинность, ложность и высказывания. LN гл. 1, с. 3–7

**Порядок материала (по LN):**
1. Высказывание (statement) — модель повествовательного предложения: каждое либо истинно, либо ложно, но не то и другое одновременно. Пример 1.1: самореферентные предложения «это предложение истинно/ложно».
2. Истинностное значение [A] ∈ {0, 1}. Составные высказывания.
3. Логическая связка: истинность составного высказывания зависит только от истинностных значений частей, [F(A₁,…,Aₙ)] = f([A₁],…,[Aₙ]). Пример 1.2: «или» — связка, «каждый студент знает, что …» — нет.
4. Атом (atomic statement).
5. Таблица истинности для ¬, ∧, ∨, →, ↔ (с. 4). Упражнение 1.3.
6. Таблица обозначений и способов выразить связки на естественном языке (с. 4). Обозначения: ¬A или Ā; A ∧ B или A & B; A ∨ B; A → B или A ⇒ B; A ↔ B или A ⇔ B. Необходимое и достаточное условие: «A достаточно для B», «B необходимо для A».
7. Замечание 1.4: [A∧B] = min = произведение; [A∨B] = max; [¬A] = 1 − [A]; [A→B] = 1 ⇔ [A] ≤ [B]; [A↔B] = 1 ⇔ [A] = [B].
8. Формулы. Запись F = F(A₁,…,Aₙ): не все Aᵢ обязаны входить. Правила опускания скобок: ¬ сильнее ∧ и ∨, которые сильнее →; X∧Y∧Z = (X∧Y)∧Z.
9. Логическая эквивалентность F ≡ G. Пример 1.5: A∧B ≡ B∧A; ¬¬A ≡ A; A→B ≡ ¬A∨B; ¬(A→B) ≡ A∧¬B; закон контрапозиции A→B ≡ ¬B→¬A; A→B ≢ B→A.
10. Тавтология. Пример 1.6 — метод «предположим, что формула ложна» на (A→B)→((B→C)→(A→C)). Упражнение 1.7: выполнимость; F — тавтология ⇔ ¬F невыполнима; F ≡ G ⇔ F↔G — тавтология.
11. Корректное (общезначимое) рассуждение (valid argument): посылки A₁,…,Aₙ, вывод C, формула (A₁∧…∧Aₙ) → C. Рассуждение корректно, если эта формула — тавтология (обратное неверно). Примеры «Сегодня четверг…» и (T∧(T→R))→R; пример 1.8 — некорректное рассуждение (R∧(T→R))→T.

**Термины (англ. → рус., по переводу гл. 1):** statement — высказывание (повествовательное предложение); truth value — истинностное значение; compound statement — составное высказывание; (logical) connective — (логическая) связка; atom — атомарное высказывание; negation / conjunction / disjunction / implication / equivalence — отрицание / конъюнкция / дизъюнкция / импликация / эквивалентность; truth table — таблица истинности; formula — формула; logically equivalent — (логически) эквивалентны; tautology — тавтология; law of contraposition — закон контрапозиции; valid argument — корректное (общезначимое) рассуждение; assumptions / conclusion — посылки / вывод; iff — тогда и только тогда, когда. Satisfiable: в переводе термина нет (упражнение 1.7 не нашлось); стандартно — «выполнимая формула».

### Лекция 2 (11.09) — Язык математики. LN гл. 2, с. 7–11

**Порядок материала:**
1. Подлежащее и сказуемое; переменная; n-местный (унарный, бинарный, нульарный) предикат. Предикат (свойство) — выражение, которое после подстановки имён объектов вместо всех переменных превращается в высказывание. Пример 2.1.
2. Предметная область (domain) у каждой переменной.
3. Кванторы. Связанная и свободная переменная. ∃x A(x) — квантор существования, ∀x A(x) — квантор всеобщности; таблица способов выразить их на естественном языке.
4. Пример 2.2: перевод «All roses are red» как ∀x (Rs(x) → Rd(x)); «No rose is red» — четыре равносильные записи; «на далёкой планете» обе формулы истинны; отрицание.
5. ∃x A ≡ ¬∀x ¬A, ∀x A ≡ ¬∃x ¬A. «Существует единственный»: ∃x (A(x) ∧ ∀y (A(y) → y = x)).
6. Пример 2.3: преобразование отрицания.
7. Замечание 2.4: область действия квантора, приоритет квантора выше бинарных связок, переименование связанных переменных. Аналогия с локальной переменной в программировании.

### Лекция 5 (02.10) — Индукция на натуральных числах. LN гл. 5, с. 27–29

**Порядок материала:**
1. ℕ = {0, 1, 2, …} без формального определения. Сноска 5 — модель фон Неймана: 0 = ∅, n+1 = n ∪ {n}, n < m как n ∈ m.
2. Принцип индукции (ПМИ): φ(0) ∧ ∀n ∈ ℕ (φ(n) → φ(n+1)) → ∀n ∈ ℕ φ(n). База, переход, предположение индукции. Форма через множества: 0 ∈ X ∧ ∀n (n ∈ X → n+1 ∈ X) ⇒ X = ℕ.
3. Пример 5.1: для n ≥ 3 число 1 есть сумма n попарно различных аликвотных дробей 1/aᵢ, aᵢ ∈ ℕ₊. Формально база — 0, по сути — 3 (1 = 1/2 + 1/3 + 1/6). Переход: 1 = 1/2 + Σ 1/(2aᵢ).
4. Принцип сильной индукции (ПСИ). Прогрессивное множество: Prog(X) ⇔ ∀n (∀m < n m ∈ X → n ∈ X). Формулировка: Prog(X) ⇒ X = ℕ.
5. Лемма 5.2: Prog(X) ⇒ 0 ∈ X (пустая истина ∀m < 0 …).
6. Пример 5.3: если a + 1/a ∈ ℤ, то aⁿ + 1/aⁿ ∈ ℤ (сильная индукция по двум предыдущим).
7. Принцип наименьшего числа (ПНЧ): непустое X ⊆ ℕ имеет min X. Пример 5.4: 8a⁴ + 4b⁴ + 2c⁴ = d⁴ имеет только нулевое решение (бесконечный спуск через минимальный контрпример).
8. Теорема 5.5: ПСИ ⇒ ПНЧ ⇒ ПМИ ⇒ ПСИ. Схема доказательства: от противного через X̄; через min X̄; вспомогательное Y = {n | ∀m < n m ∈ X}.

### Лекция 7 (16.10) — Несколько классических теорем. LN гл. 7, с. 35–40

**Порядок материала:**
1. НОД: d ∈ ℕ, d | a, d | b, и любой общий делитель делит d; запись gcd(a, b) (в русских текстах НОД(a, b)). Лемма 7.1: существование, единственность, НОД(0, b) = |b|, формула через минимумы степеней. Пример 7.2: НОД(a, b) = 0 ⇔ a = b = 0.
2. НОК (lcm) аналогично. Упражнение 7.3 (НОК через максимумы степеней, lcm(0, a) = 0). Упражнение 7.4 (свойства, gcd·lcm = |ab|).
3. Лемма 7.5: gcd(a, b) = gcd(a + bq, b). Следствие 7.6: gcd(r, b) = gcd(a, b).
4. Взаимно простые числа. Пример 7.7: 0 взаимно просто только с ±1. Лемма 7.8 (четыре равносильных условия). Следствие 7.9: a/gcd и b/gcd взаимно просты.
5. Лемма 7.10: a | bc ∧ gcd(a, b) = 1 ⇒ a | c. Следствие 7.11: сокращение в сравнении на a, взаимно простое с m. Упражнения 7.12, 7.13.
6. Теорема 7.14 (тождество Безу) для взаимно простых: au + bv = 1. Доказательство через ПНЧ — минимальный положительный элемент {as + bt}. Следствие 7.15: au + bv = gcd(a, b). Замечание 7.16: другой порядок построения теории (Безу без ОТА).
7. Лемма 7.17: ax ≡ 1 (mod m) разрешимо ⇔ gcd(a, m) = 1. Следствие 7.18: единственный обратный a⁻¹ ∈ {0,…,m−1}; (a⁻¹)⁻¹ ≡ a. Пример 7.19: 14⁻¹ = 14 по модулю 15.
8. Функция Эйлера φ(m) — количество чисел из {0, 1, …, m−1}, взаимно простых с m (в переводе 2023 — из {1,…,m−1}; при m > 1 это то же самое). Пример 7.20: φ(9) = 6; φ(p) = p − 1.
9. Теорема 7.21 (Эйлер): gcd(a, m) = 1 ⇒ a^{φ(m)} ≡ 1 (mod m). Доказательство: умножение приведённой системы остатков на a.
10. Следствие 7.22 (малая теорема Ферма), замечание 7.23: aᵖ ≡ a.
11. Следствие 7.24: показатели можно брать по модулю φ(m). Пример 7.25: последняя цифра 1234567^N, где N = 11…1 (2019 единиц) — ответ 3.
12. Отрицательные степени a^{−k} := (a⁻¹)^k. Лемма 7.26, следствие 7.27. Пример 7.28: 17⁹⁸ ≡ 36 (mod 101).

**Отличия от перевода 2023:** нумерация с 7.17 сдвинута (Эйлер в 2023 — 7.19, в 2026 — 7.21).

**Термины:** greatest common divisor — наибольший общий делитель (НОД); least common multiple — наименьшее общее кратное (НОК); coprime — взаимно простые; Bézout's Identity — тождество Безу; (multiplicative) inverse modulo m — обратный (по умножению) к a по модулю m; Euler's totient function — функция Эйлера; Euler's Theorem — теорема Эйлера; Fermat's Little Theorem — малая теорема Ферма (МТФ — так в конспекте 2023).

**Практика:**

### Лекция 8 (23.10) — Линейные уравнения и сравнения. LN гл. 8, с. 40–49

**Порядок материала:**
1. Алгоритм Евклида на примере (26, 34). Общая схема a = bq₁ + r₂, b = r₂q₂ + r₃, …. Лемма 8.1 (завершается — через ПНЧ). Лемма 8.2 (последний ненулевой остаток равен НОД, через следствие 7.6).
2. Расширенный алгоритм Евклида: r₀ = a, r₁ = b, r_{k+2} = r_k − r_{k+1}q_{k+1}; u₀ = 1, v₀ = 0, u₁ = 0, v₁ = 1; u_{k+2} = u_k − u_{k+1}q_{k+1} (так же для v); r_k = au_k + bv_k (сильная индукция). Пример: 2 = 26·4 + 34·(−3).
3. Теорема 8.3: ax + by = c (a, b ≠ 0) разрешимо ⇔ d = gcd(a, b) | c. Все решения: (x₀ − b′t, y₀ + a′t), где a′ = a/d, b′ = b/d. Пример 8.4: 45x − 37y = 25, ответ {(350 + 37t, 425 + 45t)}, таблица расширенного алгоритма Евклида.
4. Линейное сравнение ax ≡ c (mod m). Решение по определению LN — **число x₀ с 0 ≤ x₀ < m** (интересуют только остатки). Теорема 8.5: разрешимо ⇔ d = gcd(a, m) | c; ровно d решений x₀, x₀ + m′, …, x₀ + m′(d−1). Пример 8.6: 12x ≡ −15 (mod 9), ответ {1, 4, 7}.
5. Замечание 8.7: полиномиальные сравнения перебором. Пример 8.8: 7x³ − 3x² + x − 4 ≡ 0 (mod 6), ответ x = 2.
6. Системы сравнений. НОК n чисел (упражнение 8.9). Система (5) полиномиальных сравнений; решение — кортеж с 0 ≤ xⱼ < μ = lcm(m₁,…,mₙ). Лемма 8.10, следствие 8.11 (система равносильна дизъюнкции x ≡ xᵢ (mod μ)).
7. Пример несовместности: x ≡ 4 (mod 6), x ≡ 1 (mod 8). Лемма 8.12: для попарно взаимно простых lcm = произведение.
8. Теорема 8.13 (китайская теорема об остатках): единственность и существование индукцией по n; конструктивная формула x₁ = aμu + x₀mv.
