### Лекция 1 — 04.09 — `01_sep04_logic_induction` (basis: lecture)

**Тема:** формальная логика, метод математической индукции, неравенство Бернулли (н1).

**Порядок изложения (по доске 2026):**
1. Вводное: функция $f\colon \R \to \R$ — что будет изучаться в курсе (на доске только схема).
2. Опр. высказывания (утверждение, про которое можно сказать, истинно оно или ложно; обозначения $A, B, C, \dots$). Примеры: «Сегодня четверг» (ложь), «Сегодня пятница» (истина), «Жизнь прекрасна» (не высказывание), $D(x) = «x^2 \ge 4»$ (предикат), $D(3)$ — истинное высказывание.
3. Опр. предиката (утверждение, зависящее от переменных, которое становится высказыванием при любых значениях переменных); $E(x, y) = «x^2 \ge y»$, $F(x) = «x^2 \ge 0»$.
4. Кванторы $\forall$ («для любого», all), $\exists$ («существует», exists); превращение предиката в высказывание: $\forall x \in \R\ x^2 \ge 0$ (И), $\exists y\ y^2 \ge 0$ (И), $\forall x\ x^2 \ge 4$ (Л), $\exists y\ y^2 \ge 4$ (И). Порядок кванторов: $\forall x \forall y\ x^2 \ge y$ против $\forall x \exists y\ x^2 \ge y$.

### Лекция 5 — 02.10 — `05_oct02_supremum_weierstrass` (basis: lecture)

**Тема:** аксиома непрерывности, точные грани, теорема Вейерштрасса, число $e$, подпоследовательности (н5 + часть н6). В тот же день записана «Консультация 02.10» (не просматривалась; вероятно, к Quiz2/КР1).

**Порядок изложения (по доске):**
1. Аксиома непрерывности: $A, B \subset \R$, $A, B \ne \varnothing$, $\forall a \in A\ \forall b \in B\ a \le b$ ⇒ $\exists c \in \R\ \forall a, b\colon a \le c \le b$. Пример: $A = \{x > 0 \mid x^2 < 2\}$, $B = \{x > 0 \mid x^2 > 2\}$ — для $\Q$ неверно. Рисунок.
2. Опр. $A \subset \R$ ограничено сверху: $\exists C \in \R\ \forall a \in A\ a \le C$ (нестрогое!). Верхняя грань: $c \in \R$, $\forall a \in A\ c \ge a$. Точная верхняя грань (супремум) — наименьшая из верхних граней, $\sup(A)$. Примеры: $\sup[0;1] = 1 = \sup(0;1)$, $\sup(0, \sqrt2) = \sqrt2$. Замечание: если $\exists \max A$, то $\sup A = \max A$.
3. Теорема о существовании точной грани: $\varnothing \ne A \subset \R$ ограничено сверху ⇒ $\exists \sup(A)$; доказательство через аксиому непрерывности с $B$ = множество верхних граней.
4. Аналогично: нижняя грань, инфимум $\inf(A)$.
5. Характеризация супремума через $\varepsilon$ ($\forall \varepsilon > 0\ \exists a \in A\colon a > \sup A - \varepsilon$) — явно на кадрах нет, но используется в доказательстве Вейерштрасса и в Сем5 №3 / ДЗ №2 — оформить как утверждение.
6. Теорема Вейерштрасса: $(a_n)$ неубывающая и ограниченная (сверху) ⇒ сходится; доказательство: $a = \sup\{a_1, a_2, \dots\}$, от противного $a - \varepsilon_0$ — верхняя грань. Вариант для невозрастающей — аналогично.
7. Число $e$: теорема — $a_n = (1 + \frac1n)^n$ сходится. (1) возрастание: $\frac{a_{n+1}}{a_n} = \frac{n+2}{n+1}\left(1 - \frac{1}{(n+1)^2}\right)^n \ge \frac{n+2}{n+1}\left(1 - \frac{n}{(n+1)^2}\right) = \frac{n^3+3n^2+3n+2}{n^3+3n^2+3n+1} > 1$ (Бернулли); (2) ограниченность: бином, $a_n \le 2 + \frac1{2!} + \dots + \frac1{n!} \le 2 + \sum \frac{1}{(k-1)k} < 3$. Обозначение $\lim (1 + \frac1n)^n = e$.
8. Подпоследовательность: $(b_k)_{k \in \N}$, $b_k = a_{n_k}$, $n_1 < n_2 < n_3 < \dots$; примеры и не-пример ($a_4, a_2, a_8, a_6$). Свойство $n_k \ge k$.
9. Утв.: $a_n \to a \Rightarrow a_{n_k} \to a$.

**Из семинара в теорию:** нахождение $\sup$/$\inf$ множеств с обоснованием (две части: верхняя грань + «нельзя меньше») — Сем5 №3, ДЗ №2, самост. №2; рекуррентные последовательности: монотонность и ограниченность по индукции → Вейерштрасс → предельный переход в рекуррентном соотношении (КР1 №7; листок 2026 к этой теме не опубликован — 2023/24 `Сем_05` №4, ДЗ №3, самост. №4, `Сем_06` №6); пределы вида $(1 + \frac{k}{n})^n \to e^k$, $(1 - \frac1n)^n \to e^{-1}$ и неопределённость $1^\infty$ через подпоследовательности/арифметику (тема семинара н6 «Число e»; 2023/24 `Сем_07` №1–3; КР1 №5c).

**Практика:** `sem05_computing_limits_sup_inf.md` — Сем5 №3, ДЗ №2, самост. №2; `sem02_binomial_sequences.md` №9*; КР1-демо №5c, №7; листки 2023/24 `Сем_05 - Теорема о зажатой последовательности. Теорема Вейерштрасса. .pdf` (№4, ДЗ 3), `Сем_07 - Число е.pdf` (№1–3).

### Лекция 6 — 09.10 — `06_oct09_subsequences_cauchy` (basis: lecture)

**Тема:** Больцано–Вейерштрасс, критерий Коши, частичные пределы, предельные точки, верхний и нижний пределы (н6).

**Порядок изложения (по доске):**
1. Теорема Больцано–Вейерштрасса: ограниченная последовательность имеет сходящуюся подпоследовательность. Доказательство делением пополам: $B \le a_n \le C$, $[b_1, c_1] = [B, C]$; на одной из половин лежит бесконечно много членов → $[b_{n+1}, c_{n+1}]$; $b_n$ не убывает, $c_n$ не возрастает, ограничены ⇒ по Вейерштрассу $b_n \to b$, $c_n \to c$; $c_n - b_n = \frac{c_1 - b_1}{2^{n-1}} \to 0$ ⇒ $b = c$; выбор $n_1 < n_2 < \dots$ с $a_{n_k} \in [b_k, c_k]$; милиционеры. Рисунок с отрезками.
2. Опр. фундаментальной последовательности (последовательности Коши): $\forall \varepsilon > 0\ \exists N = N(\varepsilon)\ \forall m, n > N\colon |a_m - a_n| < \varepsilon$.
3. Критерий Коши: сходится ⇔ фундаментальна. ⇒: $|a_n - a_m| \le |a_n - a| + |a_m - a|$, $N(\frac\varepsilon2)$. ⇐: (i) ограниченность ($\varepsilon = 1$, $m = N+1$, $M_1 = \min(a_1, \dots, a_N, a_{N+1} - 1)$, $M_2 = \max(\dots, a_{N+1} + 1)$); (ii) Больцано–Вейерштрасс ⇒ $a_{n_k} \to a$; $|a_n - a| \le |a_n - a_{n_k}| + |a_{n_k} - a|$.
4. Опр. частичного предела — предел какой-то подпоследовательности; пример $-1, 1, -1, 1, \dots$.
5. Опр. предельной точки: $a \in \R$, $\forall \varepsilon > 0$ бесконечно много $n$ с $a_n \in U_\varepsilon(a)$.
6. Теорема: $a$ — частичный предел ⇔ $a$ — предельная точка (⇐: $\varepsilon = 1, \frac12, \frac13, \dots$, вложенные окрестности, $a - \frac1k < a_{n_k} < a + \frac1k$).
7. Опр. верхнего (нижнего) предела — наибольший (наименьший) из частичных пределов; обозначения $\overline{\lim}_{n\to\infty} a_n$, $\underline{\lim}_{n\to\infty} a_n$. На этом запись кончается.
8. «Свойства частичных пределов» (таблица н6): существование наибольшего/наименьшего частичного предела у ограниченной последовательности, сходимость ⇔ $\overline{\lim} = \underline{\lim}$ — **неизвестно, было ли в лекции 6 или будет в лекции 7.** Писателю лекции 6: дать определения и, если не было доказательства, отметить «доказательство — в лекции 7» только после того, как это подтвердится; иначе — сформулировать без доказательства.

**Из семинара в теорию:** доказательство расходимости через две подпоследовательности с разными пределами; нахождение множества частичных пределов, $\overline{\lim}$, $\underline{\lim}$, $\sup$, $\inf$ (2023/24 `Сем_05` №2–3, ДЗ №2, самост. №3); сходимость по подпоследовательностям $x_{2k}, x_{2k-1}, x_{3k}$ (2023/24 `Сем_05` самост. №2); неограниченная последовательность содержит подпоследовательность, стремящуюся к $\pm\infty$ (2023/24 `Сем_02` №3); доказательство расходимости через отрицание критерия Коши (например, $\sum \frac1k$ — по программе 2023/24 связано с постоянной Эйлера).

**Практика:** листков 2026 по теме ещё нет (семинар н7 «Предел функции» 21.10 — уже следующая тема). Использовать 2023/24 `Сем_05` №2–3 и задачник Кудрявцева, §8, №116–140 (рекомендован в программе коллоквиума 2023/24 для доп. задачи на верхние/нижние пределы; задачник — ссылка в «Полезных ссылках»).

**Источники:** доска — `boards.md`, «Лекция 6»; 2023/24 — `parts/5_subsequences.tex`: стр. 15 «Частичные пределы и предельная точка», 17 «Определения» (там верхний/нижний предел через $\lim \sup\{a_n\}_{n \ge k}$), 41 «Теорема об эквивалентности определений», 73 «Свойства частичных пределов ч.п.» (без доказательства), 87 «Система вложенных отрезков», 108 «Теорема Больцано-Вейерштрасса», 143 «Дополнительный материал (вне курса)»; `parts/6_fundamental_sequence_and_Cauchy.tex`: стр. 3 «Определение фундаментальной ч.п.», 16 «Критерий сходимости ч.п. по Коши», 61 «Постоянная Эйлера-Маскерони».
