### Лекция 1 — 03.09.2026 — `01_sep03_matrices` — режим `lecture`

Запись: https://youtu.be/A5wW2lfFVx0 (1:20:44).

Порядок в лекции:
1. Организационное (00:00–00:06): канал курса; оценка складывается из КР, экзамена, ИДЗ (с программной частью) и семинаров. Зачем алгебра программистам; план года: в 1 семестре базовые инструменты и ангем, в 3-м модуле общая алгебра, в 4-м прикладные разложения (SVD). В конспект только 1–2 строки.
2. Определение матрицы m×n, элемент a_ij (i — строка, j — столбец), запись [A]_ij, главная диагональ, множество M_mn(R) (00:06–00:12).
3. Частные случаи (00:13–00:22): квадратная матрица порядка n, M_n(R); столбец m×1, строка 1×n, матрица 1×1 = число; нулевая матрица; единичная матрица E (в англоязычной литературе I), символ Кронекера δ. Кванторы ∀, ∃, ∃!.
4. Равенство матриц (00:23–00:25): одинаковый размер и равные соответствующие элементы. Лектор подчёркивает, что все свойства доказываются поэлементно.
5. Сумма матриц, пример (00:25–00:27).
6. Свойства сложения (00:27–00:40): коммутативность (с доказательством), ассоциативность (аналогично), нейтральный элемент (нулевая матрица), противоположная матрица −A. Затем разность A − B := A + (−B) (00:40–00:42). Доказательства начинаются знаком □ и заканчиваются ■.
7. Умножение на число, пример; свойства (00:43–00:54): (λμ)A = λ(μA); (λ+μ)A = λA + μA; λ(A+B) = λA + λB; 1·A = A («унитарность», не во всех источниках).
8. Замечание: 8 свойств — аксиомы линейного пространства, M_mn(R) — линейное пространство; аналогия с геометрическими векторами (00:52–00:57).
9. Умножение матриц: A_{m×n}·B_{n×k} = C_{m×k}, c_ij = Σ_r a_ir b_rj; схема «строка на столбец»; пример (1 2; 3 4; 0 −1)·(1; −2) (00:58–01:08).
10. Свойства умножения, ассоциативность (A·B)·C = A·(B·C) с полным поэлементным доказательством, перестановка порядка суммирования (01:08–01:20). Некоммутативность упомянута устно (01:09). Остальные свойства — в лекции 2.

### Лекция 2 — 09.09.2026 — `02_sep09_gauss_method` — режим `lecture`

Запись: https://youtu.be/-i7b8p-jCfU.

Порядок:
1. Повтор ассоциативности (00:00–00:03).
2. Нейтральный элемент E в M_n(R): AE = EA = A, доказательство через δ (00:03–00:09).
3. Поглощающий элемент: A·O = O·A = O для квадратных матриц (00:09–00:11).
4. Дистрибутивность слева и справа (00:11–00:13).
5. Некоммутативность: пример A = (1 1; 0 0), B = (0 0; 1 1), AB ≠ BA (00:13–00:18).
6. Транспонирование: определение (строки → столбцы с сохранением порядка), [Aᵀ]_ij = [A]_ji, пример 3×2 → 2×3 (00:18–00:22).
7. Свойства транспонирования (00:22–00:30): (Aᵀ)ᵀ = A; (A+B)ᵀ = Aᵀ + Bᵀ; (λA)ᵀ = λAᵀ; (AB)ᵀ = BᵀAᵀ с поэлементным доказательством.
8. Зачем элементарные преобразования: СЛАУ, определители, ранг, обратная матрица (00:32–00:35).
9. Элементарные преобразования строк (00:35–00:42):
   - (1) перестановка двух строк;
   - (2) умножение строки на λ ≠ 0;
   - (3) прибавление к i-й строке k-й строки с коэффициентом λ, k ≠ i (почему k ≠ i: при λ = −1 строка обнулилась бы).
10. Пример на матрице (1 2 3; 2 1 3): II − 2·I, затем ·(−1/3), затем к каноническому виду (00:42–00:46). Об обозначениях преобразований: общепринятой нотации нет, каждый семинарист пишет по-своему (00:44).
11. Замечание 1: у каждого преобразования есть обратное (00:46).
12. Замечание 2: элементарное преобразование строк = умножение слева на матрицу элементарного преобразования, полученную тем же преобразованием из E; пример с S₁, S₂ (00:47–00:57).
13. Замечание 3: преобразования столбцов = умножение справа (00:57–01:00).
14. Ступенчатый вид: ведущие элементы, номера их столбцов строго возрастают, нулевые строки внизу (01:00–01:05). Канонический (улучшенный ступенчатый) вид: ведущие равны 1, в столбце ведущего элемента остальные нули (01:05–01:10). Примеры. Ступенчатых видов бесконечно много (01:10).
15. Теорема о методе Гаусса: любую конечную матрицу элементарными преобразованиями строк можно привести к ступенчатому (каноническому) виду (01:10). Доказательство-алгоритм, шаг 1 полностью (01:11–01:23); шаги 2–3 — в лекции 3.

Из семинаров в теорию: матрицы элементарных преобразований n×n для всех трёх типов (лектор оставил как упражнение, 00:57).

Источники: `lec02.txt`; 2023/24 `algebra-lec02.pdf` стр. 1–5 (там же алгоритм Гаусса целиком, шаги ①–③ и оценка числа шагов); `colloq-defs_1.md` п. 2–4.

### Лекция 3 — 16.09.2026 — `03_sep16_permutations` — режим `lecture`

Запись: https://youtu.be/LqHUQxT-WkM.

Порядок:
1. Окончание доказательства теоремы Гаусса: шаги 2 и 3; процесс завершается за конечное число шагов, так как текущий элемент сдвигается вправо (00:00–00:07). Лектор: на экзамене доказательства потребуются; учить не дословно, но без логических пропусков (00:07).
2. СЛАУ (00:08–00:15): координатная запись; матричная Ax = b (A — матрица системы, x — столбец неизвестных, b — столбец правых частей); расширенная матрица (A|b). Элементарные преобразования строк (A|b) соответствуют преобразованиям уравнений и не меняют множество решений.
3. Пример (00:16–00:20): система x₁ + 2x₂ + 3x₃ = 0, 4x₁ + 5x₂ + 6x₃ = 3, 7x₁ + 8x₂ + 9x₃ = 6 → канонический вид → общее решение; главные и свободные переменные.
