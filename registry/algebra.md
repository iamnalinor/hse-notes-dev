# Соглашения курса и ключевые корнер-кейсы

- Единичная матрица — $E$ ($E_n$), нулевая — $O$ ($O_{m \times n}$); элемент — $a_{ij}$ или $[A]_{ij}$; множества — $M_{m \times n}(\R)$, $M_n(\R)$ [-@rem:lec01:notation].
- Равенство матриц требует совпадения размеров: $O_{2 \times 3} \ne O_{3 \times 2}$; все матричные тождества доказываются поэлементно [-@rem:lec01:elementwise].
- Единичная матрица только квадратная и не состоит из одних единиц [-@rem:lec01:identity-not-ones]; для $A_{m \times n}$: $E_m A = A E_n = A$ [-@rem:lec02:identity-rect].
- Умножение на число — не произведение матриц: $(\lambda)_{1 \times 1} A$ определено, только если у $A$ одна строка [-@rem:lec01:scalar-not-product].
- Умножение матриц некоммутативно: $(A + B)^2 = A^2 + AB + BA + B^2$ [-@rem:lec02:square-formula]; из $AB = O$ не следует $A = O$ или $B = O$ [-@rem:lec02:zero-divisors]; $(AB)^T = B^T A^T$, а не $A^T B^T$ [-@rem:lec02:transpose-trap].
- Запись элементарных преобразований: $(i) \leftrightarrow (k)$, $(i) \to \lambda (i)$, $(i) \to (i) + \lambda (k)$ [-@rem:lec02:notation]; в матрице типа 3 число $\lambda$ стоит в строке $i$, столбце $k$, а в цепочке первое преобразование стоит правее [-@rem:lec02:matrix-traps].
- В методе Гаусса и для систем — только строковые преобразования: столбцовые меняют множество решений [-@rem:lec02:columns-trap].
- «Канонический вид» = «улучшенный ступенчатый»; он единственный, ступенчатых видов бесконечно много [-@rem:lec02:uniqueness].

# Лекция 1 — Матрицы и операции над ними

::: {.definition ref="def:lec01:matrix"}
Матрица $m \times n$ — упорядоченная прямоугольная таблица чисел из $m$ строк и $n$ столбцов; $a_{ij} = [A]_{ij}$ — элемент в $i$-й строке и $j$-м столбце; главная диагональ — элементы $a_{11}, a_{22}, \dots$; $M_{m \times n}(\R)$ — множество вещественных матриц $m \times n$.
:::

::: {.definition ref="def:lec01:special"}
Квадратная матрица порядка $n$ — размера $n \times n$ (множество $M_n(\R)$); столбец — $m \times 1$; строка — $1 \times n$; матрица $1 \times 1$ отождествляется с числом.
:::

::: {.definition ref="def:lec01:zero"}
Нулевая матрица $O$: $[O]_{ij} = 0$ для всех $i, j$.
:::

::: {.definition ref="def:lec01:kronecker"}
Символ Кронекера: $\delta_{ij} = 1$ при $i = j$, $\delta_{ij} = 0$ при $i \ne j$.
:::

::: {.definition ref="def:lec01:identity"}
Единичная матрица порядка $n$: квадратная, $[E]_{ij} = \delta_{ij}$.
:::

::: {.definition ref="def:lec01:equal"}
$A = B$, если матрицы одного размера и $a_{ij} = b_{ij}$ для всех $i, j$.
:::

::: {.definition ref="def:lec01:sum"}
Для $A, B \in M_{m \times n}(\R)$: $[A + B]_{ij} = a_{ij} + b_{ij}$.
:::

::: {.theorem ref="thm:lec01:add-props" status="доказано в лекции 1"}
Сложение коммутативно и ассоциативно, $A + O = A$, для каждой $A$ есть $-A$ с $[-A]_{ij} = -a_{ij}$ и $A + (-A) = O$. *Идея:* поэлементно сводится к свойствам сложения чисел.
:::

::: {.definition ref="def:lec01:difference"}
$A - B := A + (-B)$, то есть $[A - B]_{ij} = a_{ij} - b_{ij}$.
:::

::: {.definition ref="def:lec01:scalar"}
Для $\lambda \in \R$: $[\lambda A]_{ij} = \lambda a_{ij}$.
:::

::: {.theorem ref="thm:lec01:scalar-props" status="доказано в лекции 1"}
$(\lambda \mu) A = \lambda (\mu A)$, $(\lambda + \mu) A = \lambda A + \mu A$, $\lambda (A + B) = \lambda A + \lambda B$, $1 \cdot A = A$. Вместе со свойствами сложения — восемь аксиом линейного пространства; $1 \cdot A = A$ из остальных не следует. *Идея:* поэлементно.
:::

::: {.proposition ref="prop:lec01:zero-times" status="доказано в лекции 1"}
$0 \cdot A = O$. *Идея:* $0 \cdot A = (0 + 0) A = 0 \cdot A + 0 \cdot A$, прибавить $-(0 \cdot A)$ — вывод только из аксиом.
:::

::: {.definition ref="def:lec01:product"}
Для $A \in M_{m \times n}(\R)$, $B \in M_{n \times k}(\R)$: $AB \in M_{m \times k}(\R)$, $[AB]_{ij} = \sum_{r=1}^{n} a_{ir} b_{rj}$ («строка на столбец»). Определено, только если число столбцов $A$ равно числу строк $B$.
:::

::: {.theorem ref="thm:lec01:assoc" status="доказано в лекции 1"}
$(AB)C = A(BC)$ для $A_{m \times n}$, $B_{n \times k}$, $C_{k \times l}$. *Идея:* элемент $(i, j)$ обеих частей — двойная сумма $\sum_{r} \sum_{s} a_{is} b_{sr} c_{rj}$; поменять порядок суммирования и вынести $a_{is}$.
:::

# Лекция 2 — Свойства умножения, транспонирование, элементарные преобразования, метод Гаусса

::: {.theorem ref="thm:lec02:identity" status="доказано в лекции 2"}
$AE = EA = A$ для $A \in M_n(\R)$. *Идея:* $\sum_r a_{ir} \delta_{rj} = a_{ij}$.
:::

::: {.proposition ref="prop:lec02:zero" status="доказано в лекции 2"}
$AO = OA = O$ для $A \in M_n(\R)$.
:::

::: {.theorem ref="thm:lec02:distributive" status="доказано в лекции 2"}
$C(A + B) = CA + CB$ и $(A + B)D = AD + BD$ — два независимых утверждения. *Идея:* поэлементно, дистрибутивность чисел.
:::

::: {.definition ref="def:lec02:transpose"}
$A^T \in M_{n \times m}(\R)$ для $A \in M_{m \times n}(\R)$: $[A^T]_{ij} = [A]_{ji}$ — строки становятся столбцами с сохранением порядка.
:::

::: {.theorem ref="thm:lec02:transpose-props" status="доказано в лекции 2"}
$(A^T)^T = A$, $(A + B)^T = A^T + B^T$, $(\lambda A)^T = \lambda A^T$, $(AB)^T = B^T A^T$. *Идея* для последнего: $[(AB)^T]_{ij} = \sum_r a_{jr} b_{ri} = \sum_r [B^T]_{ir} [A^T]_{rj}$ — переставляются числа, а не матрицы.
:::

::: {.definition ref="def:lec02:elementary"}
Элементарные преобразования строк: (1) $(i) \leftrightarrow (k)$; (2) $(i) \to \lambda (i)$, $\lambda \ne 0$; (3) $(i) \to (i) + \lambda (k)$, $k \ne i$.
:::

::: {.proposition ref="prop:lec02:inverse" status="доказано в лекции 2"}
Каждое элементарное преобразование обратимо преобразованием того же типа: $(i) \leftrightarrow (k)$; $(i) \to \frac1\lambda (i)$; $(i) \to (i) - \lambda (k)$.
:::

::: {.definition ref="def:lec02:elementary-matrix"}
Матрица элементарного преобразования — результат применения этого преобразования к $E_m$.
:::

::: {.proposition ref="prop:lec02:left-mult" status="доказано в лекции 2"}
Элементарное преобразование строк $A \in M_{m \times n}(\R)$ — умножение слева на его матрицу $S$ порядка $m$. *Идея:* $p$-я строка $SA$ равна $\sum_r s_{pr} \cdot (r\text{-я строка } A)$, строки $S$ — «рецепты».
:::

::: {.proposition ref="prop:lec02:columns" status="доказано в лекции 2"}
Элементарное преобразование столбцов $A \in M_{m \times n}(\R)$ — умножение справа на матрицу порядка $n$, полученную тем же преобразованием столбцов из $E_n$.
:::

::: {.definition ref="def:lec02:leading"}
Ведущий элемент строки — её первый ненулевой элемент.
:::

::: {.definition ref="def:lec02:echelon"}
Ступенчатый вид: номера столбцов ведущих элементов строго возрастают сверху вниз, нулевые строки внизу.
:::

::: {.definition ref="def:lec02:canonical"}
Канонический (улучшенный ступенчатый) вид: ступенчатый, все ведущие элементы равны $1$, в столбцах ведущих элементов остальные элементы равны $0$.
:::

::: {.theorem ref="thm:lec02:gauss" status="начало доказательства — в лекции 2, окончание — в лекции 3"}
Любую матрицу элементарными преобразованиями только строк можно привести к ступенчатому и к каноническому виду. *Идея:* алгоритм — текущая позиция идёт из левого верхнего угла; ненулевой текущий элемент объявляется ведущим, преобразованиями $(k) \to (k) - \frac{a_{kj}}{a_{ij}} (i)$ обнуляется столбец под ним (для канонического — и над ним, строка делится на $a_{ij}$), затем сдвиг на $(i + 1, j + 1)$; при нулевом текущем элементе — перестановка строк или сдвиг вправо.
:::

::: {.corollary ref="cor:lec02:product-form" status="доказано в лекции 2"}
Для любой $A$ есть матрицы элементарных преобразований $S_1, \dots, S_p$ с $S_p \cdots S_1 A$ ступенчатого (канонического) вида.
:::
